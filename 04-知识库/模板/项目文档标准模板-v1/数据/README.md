# 结构化数据

本目录初始不放虚假的项目JSON、统计或分数。研究后按平台现行字段合同建数据。

人工维护真源：档案数据.json、主档案结构.json、阅读内容.json、质量评估依据.json、研究日志.json。
生成文件：原子字段档案.json、质量评估.json、阅读统计.json及索引。
按需增加：研究证据.json、匹配知识.json、引擎审计.json；没有研究内容时不为凑目录造空对象。

共享规范位于平台`04-知识库/项目档案标准-v1/`：原子字段字典-v3.json（17实体/233字段）、字段模板.json、深研作业质量与版本规范-v4.md。移动模板后，以所属平台根目录解析这些引用，不复制一套自行变更。

本模板的目录层级尚未接入嫦娥专用构建脚本；新项目接入时须适配路径、实体ID与事实映射，并完成校验，不能简单替换项目名称。
