# 项目文档标准模板 v1.0

复制整个文件夹到项目库，命名为`<稳定项目ID>-<项目简称>`，再填写项目身份和研究范围。ID沿用项目库已有记录；没有ID时先登记，不按文档标题或获奖次数重复建项目。

阅读入口：
- [项目档案](01-项目档案.md)：项目首页与八模块正文。
- [资料与解读](02-资料与解读.md)：理解资料及查阅原始出处。
- [档案评估](03-档案评估.md)：整理情况、质量依据与待补事项。

后台：[数据](数据/README.md)、[来源](来源/README.md)、[版本](版本/README.md)。

模板保留待填提示，没有继承嫦娥的事实、数量、评价或审核状态。各表空行用于研究填写，不代表已经存在一项奖项/成果/试验。未知留空，不填0。

这三份MD目前是研究写作提纲，便于先形成完整文档。结构化入库后，正文与解释进入指定JSON真源，再由平台生成阅读视图；不要两边长期手改。模板尚未接入当前嫦娥专用构建脚本，不承诺复制即生成网站或MCP接口。

固定结构见[文件结构规范](../../项目档案标准-v1/项目文档文件结构规范-v1.md)。共享字段字典和评分政策使用项目平台管理的同一版本，不在每个案例中各改一套。
