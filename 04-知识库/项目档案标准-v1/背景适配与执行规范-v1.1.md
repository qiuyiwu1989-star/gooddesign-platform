# 好设计项目档案：背景适配与执行规范 v1.1

日期：2026-10-19。适用范围：标准定义v1.0及首个公开资料标杆试做。v1.0保留为基线，本文为增补执行条款。不是行业国家标准，也不代表项目方已批准。

## 一、为什么本平台需要这套档案

好设计奖面向创新设计成果。中国机械工程学会2026-02-04官方新闻再次说明奖项始于2015年，并讨论其与双环传动、产业创新的联系。背景来源：https://www.cmes.org/dynamic/ff254150b3e44e5394377c1bc41ed8be.html 。

本平台的方向来自用户明确决策：以创新设计大模型为共享底座，支撑项目库、设计馆、科技教育和企业创新，保持前台结构简单。该产品方向属于平台设计，不等于奖项主办机构已授权或认定的平台方案。

2026-09-01玉环会议原始转写及本地会议梳理，反复涉及设计内容持续更新、呈现设计想法与过程、识别本地企业问题、组织运营与专家资源。档案因此必须同时保存事实、设计过程、迁移边界和后续维护任务。会议中的讨论、拟议合作与预算均不能直接转化为既成事实。

已读取的本地背景：
- 01-原始资料/会议/文字记录：好设计馆落地玉环事宜研讨 2026年9月1日.md（关键主题检索与相关段落核读；非本轮逐字复校全部转写）。
- 00-项目管理/会议脉络与待决事项.md。
- 03-平台规划/奖项作品背景与完善路线-v3.md。
- 03-平台规划/创新设计大模型-定义.html（当前架构以对话确认版本为准）。
- 04-知识库/结构样本-v1/README.md 与项目知识/应用样本。

平台本地目前收录560个项目ID，这是入库数量，不能代替奖项官方累计获奖统计。档案应区分“获奖条目”和“真实项目”，跨届重复、子项目和版本关系后续需核对。

## 二、执行条款

| 编号 | 条款 | 验收方式 |
|---|---|---|
| GD-01 | 项目ID稳定；正式名称、获奖条目与研究边界分开记录 | 能区分获奖系统、整机任务与关联子系统 |
| GD-02 | 关键事实有来源、位置、日期、适用版本及审核状态 | 点击事实可找到原始文献对应段落/页码 |
| GD-03 | 任务总指标、子系统贡献、要求值、仿真值和实测值分开 | 单位/工况/版本不一致时不直接比较 |
| GD-04 | 来源权威性与断言验证程度分开 | 官网的项目自述仍标自述，不能据此宣布完成独立验证 |
| GD-05 | 专利候选、技术相关、项目方确认及型号实施分开 | 专利有独立关系判断，不能由单位/发明人相同直接确证 |
| GD-06 | 公开号/授权号归属于申请；同族口径和状态带日期 | 不把同申请A/B文献重复计为独立发明，不未经查证填同族总量 |
| GD-07 | 机构规范化保留原名、语言、文本版本和证据 | 机器英文机构名与中文原始首页不同时记录冲突，不静默覆盖 |
| GD-08 | 实际事件、未来计划、前期研究和正式承研分开 | 同时间线可表达2009团队研究与2011承研，不错误合并 |
| GD-09 | 档案深度、档案审核状态、项目发展阶段是三个独立轴 | “有深研稿”不显示为“专家已审核”或“项目已产业化” |
| GD-10 | 未取得材料、未公开、未检索到、无适用性分别显示 | 缺口可追踪研究日志与下一步任务 |
| GD-11 | 摘要/片段/部分正文/全文区分，转载合并原始出处 | 摘要论文不标全文核读；转载不算独立核验 |
| GD-12 | 故事基于可定位报道/访谈，分析可生成且有标记 | 不编造台词、心理或失败细节；访谈问题保留为任务 |
| GD-13 | 公开网页可访问性与再发布授权分别记录 | 无授权图片以来源入口呈现，私有材料不进入公开派生内容 |
| GD-14 | 知识与应用回链主档案版本 | 事实修订能列出需复核的展项、教案和企业研究 |
| GD-15 | 全网研究声明边界、渠道、读取范围与截止日 | 本轮不足以证明穷尽时不宣称“全部找齐” |
| GD-16 | 研究自检、领域专家和项目方审核分别留痕 | 没有实际人员审核则姓名/时间为空，状态为待审核 |
| GD-17 | 有负责人和实际进展才称项目协作管理 | 未接入项目方时显示“公开资料发展追踪” |

## 三、数据交付与目录约定

每例至少包含：主档案JSON、可读档案、来源卡目录、研究日志、专利关系、问题/任务、版本记录。阅读HTML由数据生成，可离线检索。大型附件保存在移动硬盘目录；本轮只保存来源元信息、短摘要和链接，不批量镜像第三方全文。

基线模板为字段全集；标杆JSON为研究工作视图，使用id/source_ids等统一引用。两者均属于讨论版，正式开发时需补字段映射及Schema迁移，不宣称已兼容现有API或建成数据库。

建议稳定发布入口仍保留现有项目ID；本轮标杆位于知识库研究目录，尚未替换线上原档案。

## 五、首例状态与审核交接

本轮完成：公开资料研究、原始出处核读、事实口径拆分、候选专利和机制关联、阅读页面、引用与文件结构自检。

待完成：项目方全体完成人/单位分工确认；50件成果完整清单；官方专利状态/权属/同族；独立分项计量及工程参数；专家复核；图片/视频授权；真实访谈与应用试用。

因此状态为“D2候选深研稿，待专业审核”。本轮自检不是D2正式审核通过；D3仍须真实增量更新和持续维护记录。此标杆示范的是研究方法和档案结构，缺口透明也是验收的一部分。
