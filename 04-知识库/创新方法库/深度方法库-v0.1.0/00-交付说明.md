# 产品与机械创新方法库 v0.1.0

本版完成约定研究范围的内容建设：**48项方法档案、12个闻邦椿体系专题、7个任务分类、317个操作环节**。来源总账149条记录、120个不同URL；URL数不是独立研究数量。框架、方法族、工具和理论分别保留类型，不把60份档案说成60个独立原创方法。

## 从哪里开始

- 打开[index.html](index.html)，按问题、方法名与关键词搜索，按分类或专题筛选。
- 用[常用方法路线](常用方法路线.md)了解如何组合，用[闻邦椿体系导览](闻邦椿体系导览.md)了解体系层级。
- 每项档案有方法结构、深度说明、操作指南、JSON、来源核读、输入模板、产物字段模板。输入模板的null都是待填，不是实际执行数据。
- [结构规范](方法库结构规范.md)、[入库依据](入库依据与类型边界.md)、[来源总账](来源总台账.json)和[证据缺口](证据缺口总表.md)可逐条追溯。

## 供创新引擎读取

在本目录执行：

```sh
python3 library_cli.py search --query 形态学
python3 library_cli.py read --id IM-ML-017 --level steps --step-id R17-S01
python3 library_cli.py verify
```

目录、方法、步骤、来源与188条方法关系已结构化。详细匹配逻辑见[引擎接入说明](引擎接入说明.md)：任务匹配方法、步骤匹配证据、产物匹配下一方法。当前检索为关键词检索，关系绑定仍需后续工程化类型检查；本版没有注册到既有运行执行器。

## 验收与修正

60份档案结构、依赖和来源引用检查通过；61个HTML页面的本地链接及锚点无断链；全部60个方法身份与指定步骤通过独立读取工具实读。9项单元测试通过，18项桌面/移动/键盘/打印/离线浏览检查通过。7个既有运行文件指纹一致。复核记录在[复核与验收](复核与验收/浏览验收.json)。

独立交叉抽查13份档案，已修正WB04主要性能分类歧义、WB03直接出处表述，补充矩阵、方法组合、知识任务、中间产物和回返。2003论文图2四种分类视角、1.2节七种代表方向与后来“70多种分七类”自述不直接等同，差异保留在WB12。2008质量评价论文的公式/示例差异保留待核，不启用未经确认的算法。

结构检查保留25项篇幅提醒（主讲解不足1600字符），不把字数当质量得分；这些档案仍含方法特有输入、步骤、产物、例子、误用和来源，已纳入批次内容复核。真实任务反馈可继续推动深化。

## 当前边界

本版是完整范围的研究内容版，尚未专家审定、工程效果验证或生产集成。部分专著与标准只取得公开目录或摘要，逐项标注实际核读范围；相关步骤明确区分原典概念和平台编排。教学例子没有被记成企业采用或实测效果。

原论文及其图像/文本派生仅作内部核读保存，不纳入本原创内容交付包。商业标准、原图、卡组、软件与数据库的权利不因本库收录而转移。后续精确算法需补齐原典、工具、数据及专业审查。

所有新建文件位于移动硬盘。交付版本以发布冻结记录与manifest.json指纹固定；更新请创建新版本。
