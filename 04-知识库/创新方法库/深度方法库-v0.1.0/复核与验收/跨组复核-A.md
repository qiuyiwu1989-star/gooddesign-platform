发现 1 项应在整合前修正的分类歧义，1 项出处追溯缺项，另有 3 项适合补强可跟随性的编辑建议。其余抽样未发现明确概念错误。没有发现这些卡把教学假设写成已取得企业效果；大多较好地保留了原典、专业指南与平台适配的边界。

## 应修问题

### A-01：WB04 的“三大性能”表述会与本卡原典分类冲突

- 位置：WB04 / sections.principle：“技术、经济和社会三大性能与三类设计方法不是同一个分类”。
- 判断：这句话虽试图区分目标与方法，但把“技术、经济和社会”直接冠以“三大性能”，未给出处；本卡 S01 指向的2013论文摘要明确列的是结构性能、使用性能、制造性能三种主要性能。读者很容易把前者误认为该体系的原始三性能分类。
- 实际核验：[机械工程学报2013年第49卷第19期](https://qikan.cmes.org/jxgcxb/CN/Y2013/V49/I19)，闻邦椿、李小彭，77–86页题录后的官方摘要，第③点。实际读取的是摘要，不是全文。
- 建议：改为“结构性能、使用性能、制造性能是体系中的三种主要性能；动态、智能、可视化设计是与之关联的方法方向。经济、社会等价值维度如需引入，另列来源和概念层次”。不要删除对目标与方法的区分，只需换清楚分类。
- 严重程度：整合前应修；否则会污染引擎知识图谱的分类关系。

### A-02：WB03 引用了2008直接出处，但 sources 未收录该文

- 位置：WB03 / identity 首句称7D在2008论文题名和摘要有直接出处；gaps也写2008全文未得。但当前 sources 是2013论文、2017目录、NASA和2016报道，没有2008论文。
- 判断：不是证明这句话错误，而是卡内不能从声称追溯到实际来源记录。2013摘要可以支持7D体系位置，却不能单独支撑“2008题名和摘要”这项历史定位。
- 建议：补入2008《基于系统工程的产品设计7D规划及1+3+X综合设计法》，明确作者、东北大学学报29(9):1217–1223及实际核读范围；或把身份句收窄为当前 sources 已支持的2013/2017证据。不要用尚未取得的全文增强证明力度。
- 严重程度：中，来源完整性修正。

## 已联网验证的疑点与排除结果

### R30 三角设计矩阵是否确有依据：未发现概念错误

本轮实际核读MIT公理化设计组Introduction，支持四域、层级、往返分解、FR独立及信息公理；其文本亦描述解耦方案需要适当调整顺序。为核查“三角矩阵”这个具体表述，又打开MIT OCW讲义：

[Introduction to Axiomatic Design，MIT 2.882（2005）](https://ocw.mit.edu/courses/2-882-system-design-and-analysis-based-on-ad-and-complexity-theories-spring-2005/76f82abf6d0f21c916025c9fd2c79e84_lec202.pdf)，实际读取PDF文本中第51–54页附近设计矩阵、对角/三角图型及过程映射；没有全读90页。

结果：R30的核心表述可以支持，未发现“重排等于消除真实耦合”这类错误。建议将这份讲义作为补充S02，具体定位对角/三角类型；同时保留工作点、未知影响与概率不足的限制。此建议是出处增强，不是阻塞性纠错。

### R43 的IEC编号与范围是否错配：核验通过

实际打开[IEC 62430:2019官方页](https://webstore.iec.ch/en/publication/30879)，可确认该URL确为ECD原则、要求与指南，范围是把环境因素纳入设计开发的组织过程，并不提供单个产品符合性评估要求。R43没有把它冒充LCA计算标准或产品认证，区分适当。实际只读公开摘要，不读付费正文。

### R22 矩阵行列与对称性是否写反：核验通过

实际打开[MATRIZ Contradiction Matrix](https://wiki.matriz.org/docs/triz/problem-solving-tools-5890/contradictions/engineering-contradiction-5995/contradiction-matrix-6026/)，正文明确纵轴为要改善参数、横轴为随措施恶化参数，矩阵不对称，单元格可为空，推荐原理顺序不代表优先。R22所述方向正确，未查具体单元格的边界也准确。可更新来源核读范围为此次主体实际成功打开，不能因此改成已执行单元查询。

### R34 独立零件准则是否被过度绝对化：核验通过

实际读取[Bill Devenish，Product Simplification Using DFMA（2018）](https://www.dfma.com/forum/2018pdf/Devenishpaper.pdf)中第2–4页相关文本。论文确有基件、运动、材料、装配四类最低零件准则，但其具体口径不能直接泛化所有产业。R34使用“候选删除”“功能接替”“生命周期要求”等限制，没有照搬“紧固件必无必要”到工程决策，处理合理。未核其工时数据库或DFA指数实现。
