# 产品与机械创新方法库

打开[index.html](index.html)浏览与搜索。逐方法目录、操作指南、来源核读和JSON在档案目录。

48项方法与12个闻邦椿专题分别计数，不把专题子项计为独立原创方法。

每个档案含方法结构、深度说明、操作指南、原始JSON、来源核读、输入模板和产物字段模板；模板的null均为待填，不代表实测或已执行。

离线读取：在本目录执行 `python3 library_cli.py search --query 形态学` 或 `python3 library_cli.py read --id IM-ML-017 --level steps --step-id R17-S01`。工具只读文件并校验档案指纹，不执行工程求解。

结构验收只证明文件与引用关系可读，不证明方法已专家审核、工程验证或接入生产推理。

详细交付范围、验收和边界见[00-交付说明.md](00-交付说明.md)。整体完整性可执行 `python3 library_cli.py verify`。
