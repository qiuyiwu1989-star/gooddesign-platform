# 深层次动态设计：方法结构

身份：WB09 / IM-WB-009 / 0.1.0

分类：E性能优化与工程实现；类型：专项工程研究专题

本文件定义检索与调用所需结构；完整解释见深度说明，逐步执行见操作指南。

## 任务入口

输入至少包括可疑机制及证据、边界和工况范围、质量刚度阻尼及非线性本构、初始条件、激励和验收量。时变模型要说明哪个参数如何随时间变化；不确定性要区别实测变异与知识缺失。只有一条异常时域曲线不足以断言混沌，也不能把数值积分不稳定当成物理失稳。

## 输入契约

- `anomaly`：动态问题与证据；object；必需=True；缺失=先测量复核
- `physics`：模型物理与参数；object；必需=True；缺失=补物理依据
- `scope`：工况与验收范围；object；必需=True；缺失=明确分析范围
