# 生命周期评价与生态设计：方法结构

身份：R43 / IM-ML-043 / 0.1.0

分类：E性能优化与工程实现；类型：method_family

本文件定义检索与调用所需结构；完整解释见深度说明，逐步执行见操作指南。

## 任务入口

适合材料、工艺、结构、维修策略和商业服务方案的环境比较，以及设计早期热点筛查。早期可使用适当代表性二手数据形成方向判断，但应披露不确定性。公开比较或对外环境声明可能有独立审查与方法要求；若两方案功能、寿命或边界不等效，不能直接排列高低。安全和必要性能依旧先满足，不为环境得分牺牲基本要求。

## 输入契约

- `comparison_goal`：决策目的与受众；object；必需=True；缺失=ask_or_stop
- `functional_service`：等效功能与寿命；object；必需=True；缺失=ask_or_stop
- `product_inventory`：产品与过程资料；object；必需=False；缺失=mark_unknown
- `lca_resources`：数据和模型资源；object；必需=False；缺失=mark_unknown

## 评估情境

- 输入足够的研究任务 → 产生ecodesign_dossier，每项判断保留依据、假设和适用范围
- 缺少comparison_goal → 追问目标与边界，停止确定性分析，不编造输入
- 候选违反明确硬约束 → 排除并解释，不用总分或统计指标抵消要求
- 实际数据、测量或分析工具不可用 → 只保存研究/验证计划，不填造实际结果、通过或风险降低
