# 物场分析与标准解：方法结构

身份：R25 / IM-ML-025 / 0.1.0

分类：C技术发明与矛盾求解；类型：tool_family

本文件定义检索与调用所需结构；完整解释见深度说明，逐步执行见操作指南。

## 任务入口

输入需要作用载体、作用对象、期望参数变化、实际缺陷与允许引入或改变的资源。对于检测问题，应说明被测量、可接近性、分辨率、响应时间和环境，避免套用只关心加工效率的模型。资源限制可引导查第五类实施建议；安全、污染和材料兼容性仍是约束，不因标准名称而自动满足。

## 输入契约

- `interaction`：关键相互作用；object；必需=True；缺失=先做功能分析
- `defect`：作用缺陷；object；必需=True；缺失=补问题定位
- `resources`：约束与资源；array；必需=True；缺失=确认边界

先按任务与适用条件筛选，再检查输入是否足够；步骤查询来源，产物按绑定关系交给下一方法。当前只提供内容与读取接口，未注册既有运行执行器。
