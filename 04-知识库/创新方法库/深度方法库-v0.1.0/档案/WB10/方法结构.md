# 设计质量检验与综合评价：方法结构

身份：WB10 / IM-WB-010 / 0.1.0

分类：F方案决策与验证评价；类型：lineage_topic

本文件定义检索与调用所需结构；完整解释见深度说明，逐步执行见操作指南。

## 任务入口

适合方案比较、质量薄弱项诊断和设计复审，前提是评价对象、条件、指标、量表和数据来源可审。定性等级与定量性能可分别建合适映射，不应由AI即兴填隶属度。样本不足或权重未定时可整理评价计划，不能强出排名。正式产品检验、安全和法规符合性仍需工程证据与责任流程，综合评价不代替。

## 输入契约

- `quality_objective`：评价目的与对象；object；必需=True；缺失=ask_or_stop
- `quality_criteria`：指标与硬要求；array；必需=True；缺失=ask_or_stop
- `assessment_evidence`：数据与等级映射；object；必需=False；缺失=mark_unknown
- `assessment_policy`：模型与赋权政策；object；必需=False；缺失=mark_unknown

## 步骤与产物流

| 步骤 | 依赖 | 输入 | 输出 |
|---|---|---|---|
| WB10-S01 界定评价和硬要求 | 入口 | quality_objective、quality_criteria | quality_scope |
| WB10-S02 建立分层指标与证据 | WB10-S01 | quality_scope、quality_criteria、assessment_evidence | quality_indicator_model |
| WB10-S03 选择模型和权重规则 | WB10-S02 | quality_indicator_model、assessment_policy | quality_assessment_plan |
| WB10-S04 校核并执行分层分析 | WB10-S03 | quality_assessment_plan、assessment_evidence | quality_analysis_record |
| WB10-S05 解释薄弱项与敏感性 | WB10-S04 | quality_analysis_record、quality_indicator_model | quality_findings |
| WB10-S06 衔接检验与设计迭代 | WB10-S05 | quality_findings、quality_scope | generalized_quality_dossier |

## 最终产物与判读

- `generalized_quality_dossier`：广义质量评价专题档案；字段：scope、hard_requirements、indicator_model、model_policy、weights、evidence、intermediate_results、findings、sensitivity、validation、gaps；条件性综合评价，不是质量认证或实际合格率

## 引擎边界

先按任务与适用条件筛选，再检查输入是否足够；步骤查询来源，产物按绑定关系交给下一方法。当前只提供内容与读取接口，未注册既有运行执行器。

## 评估情境

- 输入足够的专题研究任务 → 产生generalized_quality_dossier，区分谱系来源与平台适配
- 缺少quality_objective → 追问目标与边界，不由目录生成算法或数据
- 候选违反明确硬约束 → 排除并说明，综合效益不可抵消
- 模型、工具或实际证据不可用 → 保留计划和缺口，不宣称原论文复现或工程通过
