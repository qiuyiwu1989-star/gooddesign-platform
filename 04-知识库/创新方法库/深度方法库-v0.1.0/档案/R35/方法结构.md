# 拓扑优化：方法结构

身份：R35 / IM-ML-035 / 0.1.0

分类：E性能优化与工程实现；类型：computational_method

本文件定义检索与调用所需结构；完整解释见深度说明，逐步执行见操作指南。

## 任务入口

适用于已知设计包络、支承、载荷及主要性能目标的材料分布探索，尤其是结构概念与轻量化。需要区分设计区、保留区和禁止区，并说明载荷工况、材料模型与最小尺度。若载荷来源不明、支承被简化得不合理、运动或接触使线弹性模型失效，先修正模型。对疲劳、屈曲、频率、热或多工况要求，应选择相应约束与算法，不能把教育代码直接作为生产求解器。

## 输入契约

- `structural_task`：结构设计任务；object；必需=True；缺失=ask_or_stop
- `load_cases`：载荷与支承工况；array；必需=True；缺失=ask_or_stop
- `material_model`：材料与本构模型；object；必需=True；缺失=ask_or_stop
- `solver_context`：计算与制造条件；object；必需=True；缺失=ask_or_stop

先按任务与适用条件筛选，再检查输入是否足够；步骤查询来源，产物按绑定关系交给下一方法。当前只提供内容与读取接口，未注册既有运行执行器。

## 评估情境

- 输入足够的概念研究 → 产生topology_dossier并保留每个判断的依据、假设与未覆盖条件
- 缺少structural_task → 追问对象与目标，停止给出确定方案，不用生成数据补齐
- 候选违反任务明确硬约束 → 排除该方向并写冲突依据，不让综合优势抵消硬约束
- 必要计算、成本数据或试验工具不可用 → 保留研究计划与待验证项，不标计算完成、工程有效或收益成立
