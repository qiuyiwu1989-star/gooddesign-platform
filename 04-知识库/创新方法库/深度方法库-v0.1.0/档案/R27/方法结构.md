# 功能导向检索与科学效应：方法结构

身份：R27 / IM-ML-027 / 0.1.0

分类：C技术发明与矛盾求解；类型：method_family

本文件定义检索与调用所需结构；完整解释见深度说明，逐步执行见操作指南。

## 任务入口

输入至少包括功能对象、期望改变的参数、数量级、工况和约束。检索可以沿技术路线、科学效应、领域专家、专利、论文或供应商展开，各证据角色不同。专利可表明公开方案，不直接证明有效；供应商资料可显示规格，不替代独立试验；效应的物理定律有成立边界，需要额外工程资料说明尺度与材料条件。

## 输入契约

- `function`：待实现功能；object；必需=True；缺失=先做功能定义
- `parameters`：功能参数与工况；object；必需=True；缺失=补数量级
- `evidence`：现有技术线索；array；必需=False；缺失=可从公开检索开始
