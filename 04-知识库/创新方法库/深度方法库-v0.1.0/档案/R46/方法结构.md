# 专利景观与技术路线分析：方法结构

身份：R46 / IM-ML-046 / 0.1.0

分类：A问题发现与需求定义；类型：method_family

本文件定义检索与调用所需结构；完整解释见深度说明，逐步执行见操作指南。

## 任务入口

适合早期技术扫描、研发对标、合作对象寻找、技术路线和信息监测。需要明确主题、可用数据库覆盖与导出能力、领域知识及检索分析能力。某些领域名称随时间变化，单一产品名会漏早期方案；应补同义词和分类。若用户要判断侵权或上市自由实施，须另定地区、时间、产品和权利要求分析，由有能力专业人员承担，本卡不能自动给可实施结论。

## 输入契约

- `patent_question`：研究问题与用途；object；必需=True；缺失=ask_or_stop
- `search_scope`：时间地域和数据范围；object；必需=True；缺失=ask_or_stop
- `seed_terms`：种子和词表；array；必需=False；缺失=mark_unknown
- `patent_data`：实际检索数据与工具；object；必需=False；缺失=mark_unknown

## 引擎边界

先按任务与适用条件筛选，再检查输入是否足够；步骤查询来源，产物按绑定关系交给下一方法。当前只提供内容与读取接口，未注册既有运行执行器。

## 评估情境

- 输入足够的研究任务 → 产生patent_landscape_dossier，每项判断保留依据、假设和适用范围
- 缺少patent_question → 追问目标与边界，停止确定性分析，不编造输入
- 候选违反明确硬约束 → 排除并解释，不用总分或统计指标抵消要求
- 实际数据、测量或分析工具不可用 → 只保存研究/验证计划，不填造实际结果、通过或风险降低
