# 稳健参数与公差设计：方法结构

身份：R39 / IM-ML-039 / 0.1.0

分类：E性能优化与工程实现；类型：method_family

本文件定义检索与调用所需结构；完整解释见深度说明，逐步执行见操作指南。

## 任务入口

适合存在可识别噪声、功能响应可测且设计有可调参数的产品或过程。需要说明噪声覆盖的现实范围、输入分布或边界及相互关系。若失效来自错误原理、结构断裂或未知根因，先修正基本方案。几何装配公差还需接触、基准与尺寸链模型；不适合用一个通用均方根公式处理所有情况。安全关键尾部事件应另按可靠性和危险分析要求评估。

## 输入契约

- `robustness_goal`：功能目标与失效边界；object；必需=True；缺失=ask_or_stop
- `control_factors`：控制因素与备选设置；array；必需=True；缺失=ask_or_stop
- `noise_factors`：噪声因素及证据；array；必需=True；缺失=ask_or_stop
- `model_or_data`：模型与试验数据；object；必需=False；缺失=mark_unknown
