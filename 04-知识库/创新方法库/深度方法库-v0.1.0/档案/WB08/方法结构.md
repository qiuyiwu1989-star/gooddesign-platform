# 面向制造性能的可视化设计：方法结构

身份：WB08 / IM-WB-008 / 0.1.0

分类：E性能优化与工程实现；类型：lineage_topic

本文件定义检索与调用所需结构；完整解释见深度说明，逐步执行见操作指南。

## 任务入口

适合复杂零件加工、零件多/顺序复杂的装配、昂贵样机或维护拆卸难题；需要模型版本、工艺、工具夹具、顺序和实际能力边界。目标简单且人工检查足够时无需搭完整仿真。若问题实为结构疲劳、材料去除机理或控制稳定性，应另接相应方法，不能用几何动画作替代。软件按任务能力选择，2007论文列举产品和语言具有年代性，不作为当前采购推荐。

## 输入契约

- `manufacturing_question`：制造与装拆任务；object；必需=True；缺失=ask_or_stop
- `product_geometry`：产品与接口模型；object；必需=True；缺失=ask_or_stop
- `process_resources`：过程与工艺资源；object；必需=False；缺失=mark_unknown
- `simulation_capability`：仿真与验证能力；object；必需=False；缺失=mark_unknown
