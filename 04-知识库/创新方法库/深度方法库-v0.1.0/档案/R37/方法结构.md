# 多准则权衡分析：方法结构

身份：R37 / IM-ML-037 / 0.1.0

分类：F方案决策与验证评价；类型：method_family

本文件定义检索与调用所需结构；完整解释见深度说明，逐步执行见操作指南。

## 任务入口

适用于真实取舍存在、候选可描述且足以比较的方案选择；分析精度应与决策后果相称。若只有一个可行方案，可记录为什么其他方向被排除而不凑伪候选。若重要要求未知，先澄清任务；若数据尚不能支持量化，可进行有依据的定性权衡。高风险决策需要领域人员、符合性和安全验证，多准则分析本身不成为许可或安全认证。

## 输入契约

- `decision_task`：决策问题与权限；object；必需=True；缺失=ask_or_stop
- `alternatives`：候选方案；array；必需=True；缺失=ask_or_stop
- `criterion_data`：准则与支持数据；array；必需=True；缺失=ask_or_stop
- `preferences`：偏好与模型；object；必需=False；缺失=mark_unknown

- `decision_dossier`：多准则权衡决策档案；字段：boundary、criteria、data、preferences、model、sensitivity、recommendation、unknowns；支持有责任的选择，不是工程或商业结果保证

## 引擎边界

先按任务与适用条件筛选，再检查输入是否足够；步骤查询来源，产物按绑定关系交给下一方法。当前只提供内容与读取接口，未注册既有运行执行器。

## 评估情境

- 输入足够的研究任务 → 产生decision_dossier，每项判断保留依据、假设和适用范围
- 缺少decision_task → 追问目标与边界，停止确定性分析，不编造输入
- 候选违反明确硬约束 → 排除并解释，不用总分或统计指标抵消要求
- 实际数据、测量或分析工具不可用 → 只保存研究/验证计划，不填造统计结果、有效性或风险降低
