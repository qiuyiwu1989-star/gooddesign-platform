# 失效模式与影响分析：方法结构

身份：R40 / IM-ML-040 / 0.1.0

分类：F方案决策与验证评价；类型：method

本文件定义检索与调用所需结构；完整解释见深度说明，逐步执行见操作指南。

## 任务入口

适合新设计、设计变更、工艺开发或旧系统用于新环境时。前提是边界、功能、工况和责任清楚，通常需要设计、制造、维护、质量及使用方共同参与。资料不足时可列潜在模式与补证问题，但不猜概率。对系统级危险、复杂多故障、共因或控制交互，还需其他安全和可靠性方法；不能仅靠单模式表替代完整机械风险评估。

## 输入契约

- `system_scope`：系统边界与功能；object；必需=True；缺失=ask_or_stop
- `operating_conditions`：工况与要求；object；必需=True；缺失=ask_or_stop
- `failure_evidence`：失效与控制资料；array；必需=False；缺失=mark_unknown
- `rating_policy`：评价与行动规则；object；必需=False；缺失=mark_unknown

- 输入足够的研究任务 → 产生fmea_dossier，每项判断保留依据、假设和适用范围
