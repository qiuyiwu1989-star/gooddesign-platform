# 功能裁剪：方法结构

身份：R26 / IM-ML-026 / 0.1.0

分类：C技术发明与矛盾求解；类型：tool

本文件定义检索与调用所需结构；完整解释见深度说明，逐步执行见操作指南。

## 任务入口

输入需要边界一致的功能模型、全部有用及有害作用、成本或其他目标参数、关键缺陷和硬约束。部分裁剪可只删除一个功能、结构段或工艺环节，但应说明剩余载体为何仍存在。工艺过程需先区分生产性、支持、运输、测量和纠正等步骤，核验相应规则；减少检验、纠正或物流步骤要证明上游或系统变化使其不再必要。

## 输入契约

- `function_model`：现有功能模型；object；必需=True；缺失=先建立功能模型
- `goal`：裁剪目标与缺陷；object；必需=True；缺失=明确目标
- `constraints`：必须保留条件；array；必需=True；缺失=确认边界

- `trimming_validation`：功能裁剪档案；字段：目标载体、原功能、去向表、裁剪模型、裁剪问题、接管证据、全成本；模型与实现状态分开登记。
