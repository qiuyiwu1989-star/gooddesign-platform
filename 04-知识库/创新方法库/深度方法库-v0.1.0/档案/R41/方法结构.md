# 机械风险评估与风险降低：方法结构

身份：R41 / IM-ML-041 / 0.1.0

分类：F方案决策与验证评价；类型：method

本文件定义检索与调用所需结构；完整解释见深度说明，逐步执行见操作指南。

## 任务入口

适合新机械、新工艺、机构变更、使用环境变更及阶段性设计复审。需要足够的结构、动力、控制、人员任务和现场边界资料，并由具备机械安全与行业知识的人参与。早期可识别危险与设计替代，但不能在无实物、无控制数据时认定剩余风险可接受。特定机械、地区及产品法规可能有更具体要求，必须另外识别适用版本。

## 输入契约

- `machine_scope`：机械边界与版本；object；必需=True；缺失=ask_or_stop
- `lifecycle_tasks`：人员与生命周期任务；array；必需=True；缺失=ask_or_stop
- `risk_policy`：适用要求与评价政策；object；必需=False；缺失=mark_unknown
- `safety_evidence`：已有安全证据；array；必需=False；缺失=mark_unknown

## 步骤与产物流

| 步骤 | 依赖 | 输入 | 输出 |
|---|---|---|---|
| R41-S01 确定机械限制与生命周期 | 入口 | machine_scope、lifecycle_tasks | safety_scope |
| R41-S02 识别危险情境和事件 | R41-S01 | safety_scope、safety_evidence | hazard_register |
| R41-S03 估计并评价风险 | R41-S02 | hazard_register、risk_policy | risk_decisions |
| R41-S04 按优先顺序设计降低措施 | R41-S03 | risk_decisions、machine_scope | reduction_plan |
| R41-S05 规划并取得措施验证 | R41-S04 | reduction_plan、safety_evidence | safety_verification |
| R41-S06 记录剩余风险与复评条件 | R41-S05 | safety_verification、hazard_register | machinery_safety_dossier |

## 最终产物与判读

- `machinery_safety_dossier`：机械风险与降低档案；字段：limits、tasks、hazards、risk_basis、measures、verification、residual_risks、open_items；是风险管理研究记录，不是产品安全认证

## 引擎边界

先按任务与适用条件筛选，再检查输入是否足够；步骤查询来源，产物按绑定关系交给下一方法。当前只提供内容与读取接口，未注册既有运行执行器。

## 评估情境

- 输入足够的研究任务 → 产生machinery_safety_dossier，每项判断保留依据、假设和适用范围
- 缺少machine_scope → 追问目标与边界，停止确定性分析，不编造输入
- 候选违反明确硬约束 → 排除并解释，不用总分或统计指标抵消要求
- 实际数据、测量或分析工具不可用 → 只保存研究/验证计划，不填造实际结果、通过或风险降低
