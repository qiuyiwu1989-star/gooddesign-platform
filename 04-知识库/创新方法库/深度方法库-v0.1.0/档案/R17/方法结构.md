# 形态学分析：方法结构

身份：R17 / IM-ML-017 / 0.1.0

分类：B功能分析与概念生成；类型：method

本文件定义检索与调用所需结构；完整解释见深度说明，逐步执行见操作指南。

## 任务入口

适合已能说明目标功能、允许更换技术路线、又存在若干可选原理的概念阶段。至少要知道哪些功能不可丢失、系统内外边界和关键接口。对于只需调整一个已成熟机构尺寸的任务，应先考虑分析和优化。若材料、尺度、动力或安全要求未知，仍可做初步概念枚举，但兼容结论必须写成待验证；若对象和目标都未知，应返回问题定义，不用随机组合制造热闹。

## 输入契约

- `task`：问题简报；object；必需=True；缺失=ask_or_stop
- `functions`：必要子功能；array；必需=True；缺失=ask_or_stop
- `options`：已知候选原理；array；必需=False；缺失=mark_unknown
- `conditions`：工况与资源；object；必需=False；缺失=concept_only

## 最终产物与判读

- `option_matrix`：功能解法表；字段：function、principle、interfaces、source_or_hypothesis；解释组合空间，不证明可行。
- `concept_set`：候选原理路线；字段：function_allocation、interfaces、tradeoffs、unknowns；仅概念层保留。
- `handoff`：比较与验证输入；字段：criteria、baseline、validation_questions；衔接后续，不是结果。

先按任务与适用条件筛选，再检查输入是否足够；步骤查询来源，产物按绑定关系交给下一方法。当前只提供内容与读取接口，未注册既有运行执行器。

## 评估情境

- 功能和选项充分且一组明显冲突 → 保留相容候选并说明被排除组合的依据。
- 动力条件未知 → 气动等路线标条件未知，不当已可行。
- 已定机构仅需公差调整 → 指出本法不是首选，转参数/公差分析。
