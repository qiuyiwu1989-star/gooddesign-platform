# 人机工程与人本设计：方法结构

身份：R13 / IM-ML-013 / 0.1.0

分类：A问题发现与需求定义；类型：method_family

本文件定义检索与调用所需结构；完整解释见深度说明，逐步执行见操作指南。

## 任务入口

适合概念设计、样机布局、控制界面、装配维护、岗位改造及新任务引入。应纳入正常、启动、停机、故障和应急情景，并包括操作、清洁、维修和支持人员。只有用户口头偏好、没有实际任务或目标人群时，可以规划研究，不能给出尺寸、操作力或安全合格结论。

## 输入契约

- `users`：人员与差异；object；必需=True；缺失=ask_or_stop
- `tasks`：任务与情景；array；必需=True；缺失=ask_or_stop
- `evidence`：现有证据；array；必需=True；缺失=ask_or_stop

- `human_factors_plan`：人因设计与验证包；字段：任务模型、用户覆盖、设计要求、验证情景、残余问题；仅为待验证工程输入

## 引擎边界

先按任务与适用条件筛选，再检查输入是否足够；步骤查询来源，产物按绑定关系交给下一方法。当前只提供内容与读取接口，未注册既有运行执行器。

## 评估情境

- 用户只提供平均身高 → 应要求目标人群及姿态数据，不直接输出设备尺寸
- 自动化后工人仅监视报警 → 应分析低负荷、诊断和异常接管任务
