# 集合式并行工程：方法结构

身份：R47 / IM-ML-047 / 0.1.0

分类：D机构架构与系统设计；类型：framework

本文件定义检索与调用所需结构；完整解释见深度说明，逐步执行见操作指南。

## 任务入口

适合架构、机构、材料工艺或接口耦合强、早期不确定性大且还可改变方案的任务。需跨专业共享知识、测试/分析能力及管理决策时机的资源。对于简单成熟件、已无选择空间或必须立即交付的紧急任务，维护复杂集合可能不划算。若企业实际只允许一个方案秘密推进，名称换成SBCE也不会带来可行集学习。

## 输入契约

- `sbce_targets`：目标与不可变约束；object；必需=True；缺失=ask_or_stop
- `domain_options`：跨专业选项与知识；array；必需=True；缺失=ask_or_stop
- `interface_conditions`：接口与兼容关系；array；必需=False；缺失=mark_unknown
- `learning_capacity`：学习资源与决策时点；object；必需=False；缺失=mark_unknown

| 步骤 | 依赖 | 输入 | 输出 |

## 最终产物与判读

- `sbce_dossier`：集合式开发档案；字段：targets、design_sets、tradeoffs、compatibility、learning、elimination、commitments、open_parameters；集合与证据逐步收敛，不保证全局最优或零返工

## 引擎边界

先按任务与适用条件筛选，再检查输入是否足够；步骤查询来源，产物按绑定关系交给下一方法。当前只提供内容与读取接口，未注册既有运行执行器。

## 评估情境

- 输入足够的研究任务 → 产生sbce_dossier，每项判断保留依据、假设和适用范围
- 缺少sbce_targets → 追问目标与边界，停止确定性分析，不编造输入
- 候选违反明确硬约束 → 排除并解释，不用总分或统计指标抵消要求
- 实际数据、测量或分析工具不可用 → 只保存研究/验证计划，不填造实际结果、通过或风险降低
