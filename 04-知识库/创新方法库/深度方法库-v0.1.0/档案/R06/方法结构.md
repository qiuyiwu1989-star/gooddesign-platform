# 阶段门：方法结构

身份：R06 / IM-ML-006 / 0.1.0

分类：G全流程规划与创新管理；类型：framework

本文件定义检索与调用所需结构；完整解释见深度说明，逐步执行见操作指南。

## 任务入口

适合资源随阶段显著增加、多项目竞争预算、需要市场/技术/制造共同参与的开发。研究探索尚不能提出可靠商业预测时，应设计与探索目标相符的小额关口，而不是逼出虚假销售额。个人低成本试验可使用轻量版本。必要输入包括决策权限、阶段学习目标、证据要求与可承诺资源，否则关口会变成没有真实决定的会议。

## 输入契约

- `initiative`：创新项目简报；object；必需=True；缺失=ask_or_stop
- `governance`：关口与资源规则；object；必需=True；缺失=ask_or_stop

## 步骤与产物流

| 步骤 | 依赖 | 输入 | 输出 |
|---|---|---|---|
| R06-S01 定义下一阶段学习与承诺 | 入口 | initiative、governance | stage_charter |
| R06-S02 组织跨职能证据活动 | R06-S01 | stage_charter | stage_evidence |
| R06-S03 按条件审视而非按材料厚度打分 | R06-S02 | stage_evidence、governance | gate_assessment |
| R06-S04 作出关口决定并承诺资源 | R06-S03 | gate_assessment、stage_charter | gate_decision |
| R06-S05 复查判断并调整流程 | R06-S04 | gate_decision、stage_evidence | stage_gate_record |

## 最终产物与判读

- `stage_gate_record`：阶段关口证据与决策包；字段：stages、evidence、criteria、decisions、resources、learning；支持投资治理，不能替代技术/市场验证

## 引擎边界

先按任务与适用条件筛选，再检查输入是否足够；步骤查询来源，产物按绑定关系交给下一方法。当前只提供内容与读取接口，未注册既有运行执行器。

## 评估情境

- 关键需求未证实 → 关口建议补证，不编销售额
- 无资源决策权 → 只能准备审议材料
- 安全硬门槛失败 → 禁止综合分抵消
