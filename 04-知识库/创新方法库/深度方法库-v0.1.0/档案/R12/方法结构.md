# 质量功能展开：方法结构

身份：R12 / IM-ML-012 / 0.1.0

分类：A问题发现与需求定义；类型：method

本文件定义检索与调用所需结构；完整解释见深度说明，逐步执行见操作指南。

## 任务入口

适合需要把多样顾客要求转成产品参数、过程要求或职能行动的项目。需求尚无证据时先做用户研究；只有一个明确工程约束的简单任务不必建立大矩阵。不同顾客群和使用情境应分开，否则重要度相互抵消。安全法规等硬约束不靠需求权重决定是否满足。标准公开范围不足以执行全部标准条款，具体变体应单独确定。

## 输入契约

- `customer_needs`：顾客需要及来源；array；必需=True；缺失=ask_or_stop
- `technical_context`：技术与组织条件；object；必需=True；缺失=ask_or_stop

## 步骤与产物流

| 步骤 | 依赖 | 输入 | 输出 |
|---|---|---|---|
| R12-S01 确认顾客需要与分群 | 入口 | customer_needs | need_structure |
| R12-S02 提出可行动的技术响应 | R12-S01 | need_structure、technical_context | technical_responses |
| R12-S03 评估需求—响应关系及冲突 | R12-S02 | need_structure、technical_responses | relationship_model |
| R12-S04 确定目标依据与对标问题 | R12-S03 | relationship_model、technical_context | target_evidence_map |
| R12-S05 部署行动并建立验证追溯 | R12-S04 | target_evidence_map、relationship_model | qfd_deployment_package |

## 最终产物与判读

- `qfd_deployment_package`：QFD需求部署包；字段：needs、responses、relations、targets、owners、verification、unknowns；支持需求转译与行动部署，不是性能或满意度保证

## 引擎边界

先按任务与适用条件筛选，再检查输入是否足够；步骤查询来源，产物按绑定关系交给下一方法。当前只提供内容与读取接口，未注册既有运行执行器。

## 评估情境

- 需求未证实 → 保留假设先补研究
- 关系未知 → 不填默认强相关
- 目标无依据 → 不生成精确阈值
- 总分高但硬约束失败 → 不能通过
