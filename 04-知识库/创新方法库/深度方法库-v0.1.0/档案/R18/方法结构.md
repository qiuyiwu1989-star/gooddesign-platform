# 仿生设计：方法结构

身份：R18 / IM-ML-018 / 0.1.0

分类：B功能分析与概念生成；类型：method_family

本文件定义检索与调用所需结构；完整解释见深度说明，逐步执行见操作指南。

## 任务入口

适用前提是已明确目标功能、成功准则和不可改变条件，并能接触可靠生物学资料或专家。若只是要给产品做动物造型，它属于形式设计任务，不能以本方法证明性能。若生物机制尚有争议，应保留多个解释，不把科普比喻当事实。缺少材料、尺度或介质条件时，可提出探索路线；一旦要求性能承诺，就必须补工程模型和实验。

## 输入契约

- `challenge`：设计挑战；object；必需=True；缺失=ask_or_stop
- `context`：作用环境；object；必需=True；缺失=concept_only
- `biology`：生物资料；array；必需=False；缺失=mark_unknown

| 步骤 | 依赖 | 输入 | 输出 |

## 最终产物与判读

- `abstracted_mechanisms`：自然机制抽象；字段：strategy、mechanism、conditions、evidence；为工程探索提供机制，不证明目标有效。
- `engineering_concepts`：迁移概念；字段：implementation、differences、tradeoffs、unknowns；条件性方向。
- `evaluation_plan`：适配验证计划；字段：questions、baseline、measures、environmental_questions；未执行的验证安排。

## 引擎边界

先按任务与适用条件筛选，再检查输入是否足够；步骤查询来源，产物按绑定关系交给下一方法。当前只提供内容与读取接口，未注册既有运行执行器。

## 评估情境

- 目标功能明确但缺生物机制证据 → 输出研究与策略线索，不生成确定工程参数。
- 仅给动物造型图片 → 澄清是否形式设计，不能声称性能仿生。
- 策略需要违反目标材料约束 → 排除该迁移或重新定义任务，不用创意价值覆盖限制。
