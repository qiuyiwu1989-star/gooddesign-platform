# 价值工程：方法结构

身份：R45 / IM-ML-045 / 0.1.0

分类：F方案决策与验证评价；类型：method

本文件定义检索与调用所需结构；完整解释见深度说明，逐步执行见操作指南。

## 任务入口

适合概念、设计优化、工艺、服务或既有产品改进，尤其成本结构清楚且还有设计自由度时。应由设计、制造、采购、使用维护与质量等角色协作，需要功能目标与可靠成本口径。定型后变更也可做，但认证、工装和库存等转换成本会改变收益。若成本和功能都不明，先调查，不对节约比例作承诺。

## 输入契约

- `value_target`：价值任务与功能要求；object；必需=True；缺失=ask_or_stop
- `cost_baseline`：成本与资源基线；object；必需=True；缺失=ask_or_stop
- `design_options`：现设计和可变项；array；必需=False；缺失=mark_unknown
- `value_resources`：团队与分析资源；object；必需=False；缺失=mark_unknown

## 最终产物与判读

- `ve_dossier`：价值工程档案；字段：functions、cost_baseline、cost_mapping、alternatives、evaluation、proposal、implementation、verification、actual_vs_estimate；降价并非必然提高价值；收益须由实施证据支持

## 引擎边界

先按任务与适用条件筛选，再检查输入是否足够；步骤查询来源，产物按绑定关系交给下一方法。当前只提供内容与读取接口，未注册既有运行执行器。

## 评估情境

- 输入足够的研究任务 → 产生ve_dossier，每项判断保留依据、假设和适用范围
- 缺少value_target → 追问目标与边界，停止确定性分析，不编造输入
- 候选违反明确硬约束 → 排除并解释，不用总分或统计指标抵消要求
- 实际数据、测量或分析工具不可用 → 只保存研究/验证计划，不填造实际结果、通过或风险降低
