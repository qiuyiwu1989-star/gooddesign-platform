# 六西格玛设计：方法结构

身份：R07 / IM-ML-007 / 0.1.0

分类：G全流程规划与创新管理；类型：framework

本文件定义检索与调用所需结构；完整解释见深度说明，逐步执行见操作指南。

## 任务入口

适合新产品、重要改型或现有过程必须根本重构的任务，且能够定义质量特性、获取测量和调动工程专业知识。已有过程的局部持续改善往往先考虑DMAIC。早期未知技术可先用概念探索，不能为了填DMADV各阶段而伪造量测。ASQ课程对能力和工具有要求，本平台不能将一张卡视为获得专业资格或无需统计人员。

## 输入契约

- `design_project`：设计任务与需求；object；必需=True；缺失=ask_or_stop
- `measurement_context`：测量和工程资源；object；必需=True；缺失=ask_or_stop

## 步骤与产物流

| 步骤 | 依赖 | 输入 | 输出 |
|---|---|---|---|
| R07-S01 定义设计项目与质量问题 | 入口 | design_project | dfss_charter |
| R07-S02 把需求转成可测特性 | R07-S01 | dfss_charter、measurement_context | ctq_measure_plan |
| R07-S03 分析概念与影响关系 | R07-S02 | ctq_measure_plan | concept_factor_model |
| R07-S04 设计参数与稳健路径 | R07-S03 | concept_factor_model、measurement_context | design_quality_plan |
| R07-S05 验证并形成质量交接 | R07-S04 | design_quality_plan、ctq_measure_plan | dfss_quality_package |

## 最终产物与判读

- `dfss_quality_package`：DFSS质量设计包；字段：ctq、measurement、concepts、parameters、verification、control、unknowns；连通质量目标与设计证据，不能从流程完整推出质量保证

## 引擎边界

先按任务与适用条件筛选，再检查输入是否足够；步骤查询来源，产物按绑定关系交给下一方法。当前只提供内容与读取接口，未注册既有运行执行器。

## 评估情境

- 无测量数据 → 只交特性与试验计划
- 量具不足辨别变化 → 先检查测量系统
- 局部现有过程改善 → 说明DMAIC替代适用性
