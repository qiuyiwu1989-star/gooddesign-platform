# 创新方法库

当前已整理3张可执行的平台方法卡：问题定义、功能分析、矛盾分析；共16步骤。原典概念与平台操作改编分开，方法的结构与调用可测试，不代表专家认证或企业工程有效性已验证。

- [问题定义](方法/IM-PD-001/1.0.0/方法说明.md)：把愿望转成有对象、边界、成功口径和待确认事项的问题简报。
- [功能分析](方法/IM-FA-001/1.0.0/方法说明.md)：说明主体对什么对象产生何种作用，以及功能、接口与潜在失效的关系。
- [矛盾分析](方法/IM-CA-001/1.0.0/方法说明.md)：核对改善与恶化的关联，检查物理矛盾候选，形成条件性方向与验证计划。

浏览器入口：http://127.0.0.1:8776/methods/ 。可阅读三种方法、嫦娥双库联动过程、企业建议与证据；支持重放固定示例。

## 两个库如何分工

项目库保存真实项目、机制、指标、证据与边界。方法库保存分析步骤、输入输出、检查和停止条件。引擎按任务选择/组合二者，应用运行记录独立保存，不覆盖源项目事实。

方法卡：[规范v1](方法卡规范-v1.md)；[历史v0.1设计](方法卡规范-v0.1.md)；[目录](方法目录.json)。每个方法以稳定ID和版本读取；目录保存文件SHA256，步骤有稳定ID、依赖、产物、知识查询和检查条件。

## 本次联动的实际边界

[模拟任务](联动示例/模拟企业需求.json)为平台编写的工业颗粒材料分层取样需求，没有真实企业访谈、实测基线和目标阈值。执行器通过官方SDK实际读取方法和嫦娥数据，再保存本轮Codex编写的16步分析结果。重放是固定场景的检索与验证，不是对任意企业需求的通用自动LLM推理，也没有自动使用矛盾矩阵。

运行：`.runtime/pipeline/bin/python scripts/run_method_case_demo.py`。输出到外置盘`output/innovation-runs/<run_id>/`，含run.json、报告HTML/Markdown、样式和脚本、manifest.json；固定项目/方法/证据版本。各次运行不可覆盖，latest.json仅为导航。

本轮读者报告中的方法解释是平台重构，不认定嫦娥研发团队实际使用过这些方法。原项目事实、0.6.1人工底稿及55分自评不变。

## 读取接口

原项目只读MCP新增gd_search_methods、gd_read_method、gd_read_innovation_run，合计11工具。来源、步骤、输入输出可分层读；运行概览与阶段/证据分开。方法检索当前为目录关键词（含TRIZ等检索词），不是语义自动选择。

后台新增/api/methods、/api/method、/api/innovation-run；/api/method-demo是CSRF保护的固定示例重放，不允许提交任意企业任务假装已自动研究。
