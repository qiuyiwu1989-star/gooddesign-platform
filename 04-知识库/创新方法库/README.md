# 创新方法库

创新引擎背后的独立方法知识库：提供可检查的分析过程、问题转换方式、知识调用规则、输出要求和验证标准。与项目档案数据库共同支撑引擎，保持现有“项目档案数据库—设计创新引擎—应用能力”三板块产品架构；方法库归设计创新引擎的基础资源，不增加一个独立应用板块。

- 项目知识库：真实项目、问题、设计机制、指标、证据和适用边界。
- 创新方法库：什么情况下使用某方法、需要什么输入、如何开展分析、怎样调用项目知识、怎样评价输出。
- 创新引擎：理解需求，选择/组合方法，检索项目知识，形成推演、追问和验证方案。
- 应用研究记录：保存某次需求、实际使用的方法/知识版本、生成的假设、人工判断与实验反馈。

阅读：[方法卡规范-v0.1](方法卡规范-v0.1.md)；模板：[方法卡](模板/方法卡.json)；目录：[方法目录](方法目录.json)。

当前：规范骨架v0.1，已入库正式方法0项；模板非实际方法。现有InnoLab/TRIZ研究等是待筛选整理的来源资源，没有自动导入，也未实现方法MCP/自动方法调度。原项目只读MCP保持现状。

建议按任务组织首批方法：理解需求、定义问题、系统与功能分析、矛盾与原理探索、方案组合、评价验证。一个方法可以适用于多个阶段，别名与相近方法保留出处，不仅按作者或流派分类。先选三种不同作用的方法，用同一真实需求验证可协作性，再扩充内容数量。
