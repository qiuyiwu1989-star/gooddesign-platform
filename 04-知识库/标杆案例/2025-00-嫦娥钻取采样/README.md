# 嫦娥钻取采样｜标准项目主档案 v2.0

研究资料截至2026-10-19。主档案已经按维度整合成文；资料充分度、项目方确认与领域专业审核仍待补，保持D2候选状态。

## 主入口

- `档案.html`：默认阅读标准正文，另有字段与标签索引、证据资料附录。
- `档案.md`：同一主档案的分层文本导出。
- `主档案结构.json`：人工整合正文真源，12维度、49字段、22标签。
- `字段索引.json`：字段路径、类型、值、口径、标签和证据。
- `来源反向索引.json`：资料到使用字段的反查关系。

## 研究依据

- `档案数据.json`：20条事实、专利/论文/机制/事件/故事/任务的研究台账。
- `研究台账.html`、`研究台账.md`：保留原证据优先的研究视图，供审计。
- `研究日志.json`、`来源卡/`：检索范围、20张来源卡和核读边界。
- `主档案验收.json`、`主档案浏览器验收-v2.md`：结构、索引与浏览器自检。

## 维护

正文只编辑主档案结构.json；事实或来源修订先编辑档案数据.json并同步受影响字段。生成视图不另行人工编辑。项目根执行 `python3 scripts/build_benchmark_dossier.py`，不会覆盖人工主档案结构。

稳定引用示例：`2025-00:F020` → `validation.subsystem_results` → C06/C07 → S02及原文定位。章节显示序号05.01不是永久ID。

规范：`../../项目档案标准-v1/主档案层级与索引规范-v1.2.md`。本轮未追加全网研究或专业审核，未替换生产站点。
