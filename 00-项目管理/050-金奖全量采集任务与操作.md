## 原件与清洗
下载复用现有public_url/跳转检查/30MB限制；原件、来源URL/时间、SHA、可读MD与chunks进入相应项目“来源”目录。新件**先待确认**，不是项目归属已审核，不进入事实发布/评分。整届名单、相关团队、后续型号、宣传数据、论文/专利采用须后续核定；原件保存与全文核读分开。

首次4份原件已实际核字节、SHA、可读稿和pending归属（output/research-050/首批原件验收.json）。批次最初沿用默认未核项目提交后立刻设pending；后补initial_scope=pending让后续新件的第一份入库快照即冻结待核范围，旧快照不改。相同内容或已存在URL只复用，不改既有归属；既有复用是按来源登记与文件存在判断，不冒称每次重新下载或全量SHA复验。

缺少正文、反爬页面、错链接、证书/403/404、付费等保留原状态和原因，不绕过。下载失败不会变成“查无资料”。机器文字转换不算核读，更不算专家审核。

## 本轮后台采集
已启动本机独立采集进程，运行身份见output/research-050/worker.json，逐项日志collector.log。本轮最多1000个队列项、最长3600秒，先到即停止，剩余留队。无模型调用；不是全天候自动Deep Research Agent，不恢复旧automation。电脑睡眠/外置盘离线会中断，须从持久任务接续，不写系统盘替代库。

中断任务有10分钟租约，重新运行时回收过期运行项；不要同时启动多个采集者。修改源码或维护进程前先核对PID/命令并取得库锁，保留任务和原件。当前worker与本机8776/云端服务互不依赖。

接续命令（在好设计平台根目录）：

```sh
.runtime/pipeline/bin/python scripts/gold_research_task.py status
.runtime/pipeline/bin/python scripts/gold_research_task.py run --limit 1000 --max-seconds 3600
```

补充检索用search输入数组：project_id、dimension、query、searched_at、status、results[{title,url}]。没有实际检索不要登记成已搜索。

```sh
.runtime/pipeline/bin/python scripts/gold_research_task.py search --input 新检索结果.json
```
