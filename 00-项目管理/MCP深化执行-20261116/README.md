执行顺序：先T01，随后T02/T03/T06/T07/T08可在各自文件范围推进；T04依赖认证诊断，T05依赖客户端验收，T09使用封存集，最后T10。任务并行不等于已启动多Agent；本次先拆解，不宣称已运行。

每项完成必须附真实产物、正反例、实际调用和未结项；部署采用新release及回滚，不在current直接编辑，不将其他会话未提交改动打包。生产凭据只在受控配置中处理，报告仅记凭据ID和状态。

当前技术证据、客户恢复、内容语义正确、领域适用与工程有效分别验收，不合并成“全部通过”。外部客户或专家未配合时，继续其他可做工作，保留该项待验状态。

首个交付是T01生产基线差异清单，第二个交付是T02认证诊断及T04客户端脱敏验收。每批汇报完成项、失败项、上线版本与回滚，不用测试数量代表知识质量。
