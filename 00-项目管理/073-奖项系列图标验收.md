# 073 奖项系列图标验收

2026-11-03。奖项系列图标已完成并接入真实项目卡片，未部署生产。

## 图标家族

用户认为旧图标太丑，因此星芒、灯泡、书签、桂冠等装饰性方案已废弃。最终采用更少元素、更轻线宽的几何系统：

| 奖项 | 最终形状 | 文件 |
|---|---|---|
| 金奖 | 单一菱形与中心几何点 | `awards/gold.svg` |
| 银奖 | 双圆环与单一横向结构线 | `awards/silver.svg` |
| 铜奖 | 简洁六边形与中心短线 | `awards/bronze.svg` |
| 创意奖 | 三个相连几何节点 | `awards/creative.svg` |
| 提名奖 | 开放圆环与中心点 | `awards/nominee.svg` |
| 菁英奖 | 四个有序几何节点 | `awards/elite.svg` |

统一 48×48 画布、14px 圆角底、1.5-1.7px 轮廓线宽和低饱和底色。六枚图标轮廓不同，不是简单换色。所有图标保留文字标签，不使用 Emoji 或文字缩写。

创意奖、提名奖、菁英奖使用独立形状，没有统一改称铜奖。图标不用于制造无依据的项目评分或排名。最终总览已在真实浏览器中人工查看。

## 实际接入

- `extensions/design-system/portal.js` 按 `project.award` 映射 SVG，并保留年份与奖项文字。
- 项目卡片显示“图标 + 年份 + 奖项 + 阅读状态”。
- `scripts/build_gooddesign_site.py` 将六枚图标复制到 `/inno/portal/awards/`。
- 全站走查页新增六枚图标展示区，生产服务同步支持白名单资源。
