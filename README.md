# 好设计平台

项目工作区 · 建立于 2026-09-05 · 当前阶段：独立站已上线，讨论下一阶段知识与应用建设。

以“好设计”奖项为起点，整合科技与创新设计知识，逐步形成可持续服务企业、设计师与教育场景的创新设计智能平台。这是本次用户明确的方向；具体产品、预算与实施顺序仍在讨论。

## 文件区域

| 区域 | 用途 |
|---|---|
| 00-项目管理 | 来源索引、讨论记录、待决问题与进度 |
| 01-原始资料 | 原始 ZIP、9 月 1 日会议、两份分享网页和可检索文本 |
| 02-研究 | 外部调研、证据与可借鉴机制 |
| 03-平台规划 | 平台定位、知识结构、产品路线 |
| 04-知识库 | 后续经过溯源与核验的知识条目 |
| 05-产品原型 | 后续深化开发规划；首发网站见site/ |
| 99-历史项目快照 | ZIP 完整解压，保留原有代码、内容、会议和项目管理文件 |

后续会议继续放入原始资料区，再更新会议脉络和待决事项。旧稿中的“已完成”“上线”和截止日期属于当时记录，不代表当前运行状态。分享页里的 AI 建议、人名推断和行动指令属于参考材料，不自动成为项目决策。
