# GoodDesign 网站信息架构 v2

2026-11-04。用于095统一封版，取代v1中的旧栏目、旧路由和旧实施状态。本文是当前主项目区结构，095及其路由、项目介绍、应用中心和统一登录已经上线。

## 1. 产品定位

以真实项目为知识起点，形成“发现项目 → 学习方法 → 定义需求 → 执行验证 → 查看资产 → 开发接入”的完整创新路径。

统一不意味着所有页面使用同一种布局，而是统一栏目职责、唯一URL、导航、权限、组件契约和研究边界。

## 2. 七大产品区域

| 区域 | 回答的问题 | 核心对象 | 主要产物或下一步 |
|---|---|---|---|
| 项目库 | 别人如何解决过类似问题 | 项目、事实、证据、研究版本 | 项目档案、机制解释、来源定位 |
| 好设计馆 | 如何看展、学习和理解设计价值 | 展区、项目故事、学习活动 | 项目档案、学习资料、教学参考 |
| 方法库 | 可以采用什么分析路径 | 方法、步骤、适用条件、教学示例 | 方法参考与研究路线 |
| 需求研究 | 我们真正要研究什么 | 真实问题、约束、参考、未知 | 可核对的需求研究简报 |
| 企业创新 | 怎样推进研究和验证 | 研究任务、路线、证据、验证、反馈 | 验证计划、研究记录、回流结果 |
| 数据总览 | 数据资产建设到什么程度 | 覆盖、来源、研究状态、方法分布 | 项目与证据入口、缺口判断 |
| MCP 接入 | Agent怎样读取这些知识 | 配置、8项只读工具、版本化研究包 | 项目/方法读取、证据核对、研究上下文 |

关键边界：需求研究负责“定义清楚”，企业创新负责“研究下去”。MCP提供读取与组包，不替代用户确认、自动研究或工程验证。

## 3. 导航层级

主导航：

`项目库｜好设计馆｜方法库｜应用中心｜需求研究｜企业创新｜数据总览`

认识、开发与管理入口：

`关于｜MCP 接入｜资料管理`

科技教育归入好设计馆，不再形成平行一级栏目。平台使用说明放页脚。移动导航保持自然横向滚动，不压缩成两行或缩小点击区域。

### 项目介绍与大模型定义

“关于”是认识平台的解释层，不是第八个业务栏目。/about回答为什么建设好设计、建设什么、已经形成哪些真实资产、怎样保证可信；/model回答创新设计大模型是什么、怎样工作、能做什么、不能做什么；/guide只承担具体使用说明。

/model复用旧站`original-app/public/model/index.html`中的有效定义、知识主线、四种核心能力、人机分工、研究过程和建设路线，将旧四应用更新为当前七区域和真实能力状态。

创新设计大模型是领域智能系统：利用现有大模型连接真实项目档案、创新方法、研究Agent、MCP和验证反馈，支持理解设计、发现关联、辅助创新和支持验证。它不是已经完成自主训练的基础大模型，也不替代专家审核、企业确认和工程验证。

### 应用中心与案例

应用中心是解决方案目录，不是页面收藏夹。每项应用必须说明目标用户、真实任务、输入、工作流、输出、数据与方法引用、权限、当前状态和真实案例。

应用清单只保存应用定义和关系，不复制既有应用内容。好设计馆作为旗舰应用保留主导航快捷入口；科技教育、企业研究、区域产业、Agent接入等通过应用清单组织，避免形成新的数据孤岛。

应用案例按已上线、试点、规划区分。案例必须连接真实项目ID、研究版本、方法和实际产物；概念方案不得标为已上线应用，验证结果不得用模型生成量代替。

## 5. 核心用户路径

### 发现与阅读

`项目库搜索/筛选 → 项目档案 → 核心章节 → 引用预览 → 相关资料或方法`

引用不再使用字段下方的大块展开。桌面悬浮/聚焦预览、点击固定，移动点击打开底部面板；打印保留来源编号与文末列表。

### 看展与学习

`好设计馆 → 展区或学习活动 → 项目档案 → 方法或学习资料`

展馆保持媒体和互动体验，不强制套用档案阅读布局。

### 需求与验证

`需求研究 → 问题与约束 → 参考项目/方法 → 核对简报 → 企业创新任务 → 证据与验证 → 反馈回流`

项目只能作为参考，方法只能作为候选路径。未经确认的需求、迁移、验证和成果分别标识。

### 数据与管理

`数据总览 → 覆盖/缺口 → 项目或证据 → 授权资料管理`

数量不冒充质量，文件数不冒充研究完成度，未评不画0分。

### Agent接入

`MCP配置 → 搜索项目/方法 → 读取版本与证据 → 组装研究上下文 → 当前客户端保存`

远程只读，不创建源档案、私有历史或收费模型调用。

## 6. 四类页面模板

| 模板 | 适用页面 | 内容重点 |
|---|---|---|
| 展示发现 | 首页、展馆、数据总览 | 图片、案例、图表、筛选与真实数据 |
| 内容阅读 | 项目档案、方法详情 | 阅读宽度、目录、事实、引用与版本 |
| 研究工作台 | 需求研究、企业创新 | 任务步骤、状态、未知、证据、错误恢复 |
| 接入管理 | MCP、资料管理 | 配置、权限、工具、表格与操作反馈 |

四类模板共享品牌、导航、字体、颜色、按钮、表单、对话框和反馈，不共享所有内容密度。

## 7. 组件与交互契约

- 链接负责跳转，按钮负责操作；链接不使用箭头装饰。
- 核心事实直接显示，只有原文、待补、AI和维护信息渐进呈现。
- 筛选与阅读定位写入URL，返回保留项目、筛选和阅读位置。
- 每页一个标准导航和一个标准底部，渲染层同时执行去重。
- 对话框支持键盘、Escape、焦点返回；移动操作目标至少44px。
- 页面必须有加载、空、错误、成功和禁用状态，不只展示成功路径。
- 所有新组件同时验收桌面、移动、深色、打印和减少动态。

## 8. 权限边界

公开阅读：项目库、好设计馆、方法库、需求研究、数据总览、项目介绍、大模型定义、使用指南、MCP说明。

授权访问：企业创新、资料管理、私有原件与内部研究记录。统一登录页取代浏览器原生401，后端权限不变。

独立密钥：MCP API继续使用Bearer，不与网页账号混用。私有原件和待审资料不得因静态发布或COS迁移变成公开URL。

## 9. 首页信息顺序

1. 一句话定位、项目搜索与“了解好设计”入口。
2. 精选真实项目及研究状态。
3. 创新设计大模型的一句话定义、能力架构与边界，链接/model。
4. 七大区域中与当前用户最相关的三个自然入口。
5. 一条完整示范：项目证据如何支持需求研究与企业验证。
6. 真实资产统计、来源范围与最近更新。
7. 项目介绍和使用指南，不把底层数据库和MCP术语堆在首屏。

## 10. 095统一封版范围

封版包含：唯一路由、导航与页脚、项目介绍、大模型定义、使用指南、四类页面模板、引用预览、统一登录说明、旧链接重定向、全站链接图、移动与无障碍回归。

封版不包含：新增产业专区、改变研究事实或评分、开放私有原件、接入自动模型研究、关闭旧站。新增功能不得借封版绕过独立验收。
