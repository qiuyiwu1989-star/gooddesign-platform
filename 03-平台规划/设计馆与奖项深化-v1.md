# 设计馆与奖项深化方案

2026-09-07。当前交付为006本地预览，保留原首页；双环研究交由另一对话推进。

## 两个板块的职责
奖项板块保留作品身份和事实，回答“这是什么、何时获奖、谁完成、依据在哪里”。设计馆将这些事实组织成观众能够理解的参观体验，回答“为什么值得看、有什么难题、怎样突破、还能追问什么”。共享project_id，不复制一套独立作品主数据。

## 奖项结构
奖项背景（现有award.html） → 历届名录（现有laureates.html） → 筛选与作品对照（新增explore/awards.html） → 项目事实档案（现有project/） → 来源与关联应用。

本轮：560项按关键词/年度/奖级/资料情况筛选，最多三项并排对照，支持URL保留筛选和作品选择，原文及已有课例可达。

后续深化顺序：
1. 先选6—10件资料充足作品补齐问题、工况、约束、设计措施、效果、测量条件、适用边界和审核记录。
2. 把当前原文简介对照升级为上述结构化字段对照；无证据就保留未知。
3. 奖项背景增加可核查授奖规则版本、主办方和历史资料来源；征集/申报入口需按当期官方信息核实后建设。
4. 建立内容维护清单：缺文、缺来源、名称冲突、年份/奖级待核实，逐项处理。已发现96条描述缺失；有描述的464条不代表已核实。

## 设计馆结构
原版馆首页与三大展区 → 主题导览 → 单站观察/原文/任务 → 项目档案或课例 → 跨项目对照。

本轮三条平台策展路线：
- 走进未知环境：嫦娥采样、蛟龙号。
- 从部件到系统：CRH380A、白鹤滩相关项目。
- 力量如何变得精确：800MN模锻压机、国和一号屏蔽电机主泵。

每站包含：项目ID、建议观察问题、原文依据与位置、思考任务、追问、完整档案、已有课例。路线时间与适用人群为策展建议，尚未进行用户测试。

下一轮每件展品补齐：
- 一句话讲解：观众能理解的核心难题。
- 3分钟讲解：场景、约束、设计措施和证据。
- 可操作任务：预测—选择—观察—解释，明确模拟与真实工程的边界。
- 分层讲解：公众版、学生版、工程深入版；共享事实来源。
- 反馈：观众在哪里不理解、教师如何改编、哪些原文需要专家解释。

优先深做嫦娥与蛟龙两站，验收观众能否用自己的话说明一个约束和一个设计措施。其后扩充展品，再决定进度记录、路线收藏、线下扫码导览等功能。

## 内容治理
策展提问和分析不得写成项目原团队的陈述；档案历史效果不得自动视为当前指标。企业研究的通用机制须审核并取得公开授权后回流，详见00-项目管理/企业创新协作要求.md。
