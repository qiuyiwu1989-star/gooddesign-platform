# 项目图谱与割胶机器人：一次迁移试读

2026-10-20，迁移演示0.1.0，嫦娥来源内容固定0.4.0。保持项目名称、概述、数据维度与补充情况作为主档案，增加一条把信息关联起来的应用入口。

## 图谱服务什么决策
需求 → 问题/矛盾 → 可借鉴机制 → 原证据与边界 → 目标条件 → 方法/候选方案 → 验证。
档案中的事实、平台机制解读、目标任务假设、方法建议与真实验证分别标记。图谱不自动证明因果，不以获奖等级替代相关度，不把行业相似当工程适用。

## 本次关联判断
- 行业/材料距离大，具体机构和月面参数不直接迁移。
- 接触反馈较值得研究：借鉴随接触状态调整动作的思想，不能推出恒力等于恒割深。
- 多目标取舍可借鉴：先定义有效作业、耗皮、损伤、产胶及成本的评价，再比较设计变量。
- 分层验证可借鉴：末端几何/材料对照、农艺确认后的实树和长期状态分开验证。
- 软袋取芯本次不直接采用：同是采集不足以证明功能、对象与动作相同。

强弱是定性研究判断，没有校准百分比。已有割胶领域视觉/测距和力控研究，本演示不声称这些是我们的原创发明。

## 方法怎样进入
1. 设计思维/质量功能展开：从任务与用户工序出发，定义可测结果和约束，不编造访谈。
2. TRIZ反馈/动态化：将效率与损伤约束形成可讨论矛盾，提出按状态调整与功能分离；未运行矛盾矩阵或专利新颖性评价。
3. 功能分解：定位、姿态、切除量、接触状态、内部余皮依据、异常各有观测与动作。
4. 分层验证/最小原型：先验证末端效果再增加移动/定位与环境因素，不把台架精度当长期树体健康。

## 割胶研究的关键提醒
《天然橡胶割胶机器人视觉伺服控制方法与割胶试验》第4.1节区分切割深度、耗皮量、到形成层距离；外表面几何测量不能自动证明内部余皮厚度（后者是平台据测量差异作出的推论）。TUM机构库的2024研究摘要已涉及割胶力控，并报告姿态对力估计与控制的影响；未全文核读，不采用其中力值作为本方案参数。
