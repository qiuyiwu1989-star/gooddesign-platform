# 专家评审执行与指标口径

性质：平台试点方案，待领域专家标定。这里规定如何记录与复核，不宣称已获得评审结果。

## 评审对象先冻结

每轮先写清领域、交付阶段、可用输入、允许工具、预算与停止条件，再冻结任务、证据、方法和产物版本。方法匹配、概念方案、工程方案分别评审；匹配提案不能替整套引擎的设计质量作证。客户陈述、案例作者报告、平台推断和实测记录分开标注。

任务作者提供事实包及公开评价问题，但不能预先指定唯一正确方案。专家参照允许多种合理路线；出现新路线时按原理、条件和证据判断。若专家自己也需要补充数据，参考答案应包含该限制。

## 角色与顺序

两名具备对应领域经验的评审者独立审阅；登记专业范围、利益关系和资格核验责任人。评审者不应是该份产物的作者。先检查硬门槛，再按八维0—4锚点评判；每一评分都附具体段落、问题或证据位置。

先独立提交，再交换意见。不得先讨论出统一分数后冒充独立一致。严重问题由作者修订，以新版本重评；原意见和旧版本保留。两人对关键机理或用途分歧时，由有相应专业能力的第三人裁决；无法裁决则保持未决，不用平均分消除分歧。

本机必要条件筛查器仅检查提交记录，既不核验真实身份，也不执行上述组织过程。它返回可进入受控发布流程，并不签发专家认证。最终标签应由完成身份核验、独立复核和授权的应用责任流程写入。

这种独立评估、记录测试条件、明确有效范围与测量不确定性的安排，参考[NIST AI RMF Measure](https://airc.nist.gov/airmf-resources/airmf/5-sec-core/)；八维指标和双人门槛是本平台提案，不是NIST制定的机械设计认证标准。

## 指标字典

| 指标 | 分子 / 分母 | 必须同时报告 |
|---|---|---|
| 专家可接受产物比例 | 完成相应独立评审且接受的产物 / 所有分配到该交付等级的任务 | 未运行、失败、待评、合理停止分别计数；不能只用已评分成功项作分母 |
| 发布误标 | 被标为专家级却存在未关闭关键错误的产物 / 所有标为专家级的产物 | 若尚无专家级发布，比例为空，不能报0% |
| 关键错误漏出 | 送出产物后发现关键错误的任务 / 已送出且完成错误复核的任务 | 错误严重度、发现时间和复核覆盖；未复核不能算无错 |
| 合理停止 | 专家判应补证或停止且引擎正确处理的题 / 专家判应补证或停止的全部题 | 误停止可回答题的数量，防止靠全部拒绝取得高分 |
| 关键主张支持 | 经独立语义核对被直接支持的关键主张 / 所有关键主张 | 假设、待核、错引与无来源各计数；有引用不等于被支持 |
| 严重问题关闭 | 新版复核确认关闭的问题 / 全部严重问题 | 新增问题、逾期和无法裁决项，不能只报作者自称已修复 |
| 后续工作可用 | 下游人员实际采用并可执行下一步的产物 / 进入相应下游环节的产物 | 用途、修改量、返工原因；满意度不能代替性能验证 |
| 配对改善 | 同题独立评审偏好引擎 / 已完成配对评审任务 | 普通Agent胜、平局、无法比较；同时列双方严重错误，不能只报偏好 |

上述指标都按领域、阶段和任务难度分层，附原始整数、未完成项和观察期。当前没有专家评分，因此专家相关比例均为空。

小样本的比例需要说明不确定性；[NIST比例区间说明](https://www.itl.nist.gov/div898/software/dataplot/refman1/auxillar/propconf.htm)列出Wilson等方法。但目前12题是作者选取的标定任务，缺乏代表性；即使计算区间，也不能解决选题偏差或宣称总体专家达标率。配对、重复题及相关输出也不能当成独立同分布的工程案例样本。

## 当前对照的适用范围

新增paired-comparison仅对“下一步方法规划”做探索性对照。同题、同上下文、同本机模型读取器、相同超时和推理配置，交替调用顺序；一组使用引擎目录与匹配提示，一组为有同类边界要求的普通方法顾问。它同时改变目录与提示，不能归因到单一组件。每题输出匿名A/B标签，映射另存；措辞仍可能泄露来源，不承诺完全盲法。

这批题已经被开发者看到，不属于留出评测。真实客户任务、专家参照、独立评分和下游验证仍需补齐。只有完成对应环节，才更新该环节状态。
