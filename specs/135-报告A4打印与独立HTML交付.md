# 135 报告 A4 打印与独立 HTML 交付

## 要什么

- 修复打印正文被目录网格挤窄、中文逐字换行、23 页异常膨胀的问题。
- 屏幕报告保留深色工作台；打印转为正式浅色 A4 文档，封面、摘要、章节、表格和附录有稳定版式。
- 提供显式“保存 HTML”按钮，下载自包含的正式报告，而不是保存整个交互应用。
- 下载 HTML 无 JavaScript 依赖、无外部样式依赖，离线打开仍有完整排版；站内链接转为绝对地址。
- 屏幕报告与下载报告使用同一份已装配内容，不另造事实。

## 不做什么

- 不改变报告章节、证据状态、项目映射或研究数据。
- 本轮不宣称服务端生成 PDF；PDF 仍通过浏览器打印保存，但必须验证实际 PDF 输出。
- 不下载运行日志、角色动画、二维码栏或交互按钮。

## 验收清单

- [ ] 打印时 `#report.on` 不再占用 230px 目录网格，正文使用完整 A4 内容宽度。
- [ ] 表格不发生逐字换行；ID、状态列保持合理宽度；长 URL 可断行。
- [ ] 封面独占一页，章节分页、表格行和卡片避免跨页断裂，动画不影响打印可见性。
- [ ] 可下载独立 `.html`；文件含完整报告和内联样式，无脚本、无外部 CSS/图片依赖。
- [ ] 下载文件离线打开显示正常，链接指向 `https://haoshejiguan.com`。
- [ ] 生成实际 PDF 并检查页数、文本与页面渲染；桌面和移动屏幕报告无回归。

## 实现约束

沿用现有 `buildReport` 装配结果；独立 HTML 从同一 DOM 克隆并转换链接。样式打印规则放在最后，明确覆盖 `.on` 等状态选择器。
