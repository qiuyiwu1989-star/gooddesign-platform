# 140 报告全拼链接与浅色双版式

## 要什么

- 报告专属 URL 使用 ASCII 全拼 slug，例如 `?report=yuhuan`、`?report=jiashan`，不出现中文或中文百分号编码；新地方由模型提供经校验的全拼 slug，缺失时使用稳定 ASCII 兜底。
- 旧中文参数链接继续可用；服务端和前端都能按地名或 slug 找到同一份报告。
- 在线报告和下载 HTML 均为浅色阅读版；屏幕报告、下载报告提供明确返回产业研究首页的入口。
- 屏幕阅读与 A4 打印采用不同构图和间距：屏幕有页面容器、宽松章节间距与可滚动目录；打印使用完整 A4 内容宽度、封面独占页和紧凑分页。

## 不做什么

- 不改变报告正文、研究事实与收录数据；slug 只是地址标识。
- 不引入新的拼音依赖；不伪造地名翻译。
- 不让浅色报告样式影响深色首页和运行页。

## 验收清单

- [ ] 新生成报告二维码只含 ASCII URL，解码为 `...?report=yuhuan` 等全拼地址。
- [ ] `?report=yuhuan` 与旧 `?report=玉环` 均能打开玉环报告。
- [ ] 在线报告与下载 HTML 均有返回首页入口。
- [ ] 在线报告为浅色，首页和运行页仍深色。
- [ ] 屏幕与打印间距不同；实际 PDF 封面、表格和项目卡无回归。

## 实现约束

沿用现有静态页与报告 API；slug 仅允许小写字母、数字和连字符，最长 64 字符。
