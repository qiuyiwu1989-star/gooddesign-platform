# 127 应用中心真实产品地图补全

应用中心必须是真实产品地图：已上线或试点的产品面不在注册表中，注册表就不是真源。本规格把两个已经真实存在的产品纳入 gd-app-0.1 Manifest，109 三栏控制台骨架不变。

## 变更

### 1. 新增第七个应用：推理画布（canvas）

- status `pilot` / 受保护试点，runtime `/canvas/`，requires_login=true（与 115 部署一致：匿名 302 到登录页）。
- engine `GD-CRE-0.1` / engine_status `available`（`/api/rc/engine_candidates` 服务冻结割胶样例）。
- 证据案例 rubber-tapping；禁写字段含 recommendations 等全套。
- permissions.tenant_isolation=false 如实标注：当前工作区状态是服务端单库试点，不是租户隔离。

### 2. schema 新增 writes 枚举值 server_workspace_pilot

原有四值（none / client_local / tenant_scoped / tenant_scoped_planned）无法诚实表达画布的"服务端工作区持久化、试点期不做租户隔离"。新增 `server_workspace_pilot`，只追加枚举值，不改其他约束；registry_schema_version 保持 gd-app-registry-0.1。

### 3. regional 更新为已上线产品面：产业创新 Agent

- 标题改「产业创新 Agent」，status planned → pilot（试点运行），runtime `/cases/yuhuan/` → `/expo/`（121v3 + 123 真实后端已在公网运行）。
- summary/outputs 改为真实交付：区域产业调研报告、客户画像、机制映射清单；所有方向标注研究假设。
- tenant_isolation 改 false（公开演示，无租户数据），writes 改 none（不持久化用户数据）。id 保持 regional，registry 身份稳定。

### 4. 渲染器配套（app_center_096.py）

- ICONS/KINDS/JS ICONS 增加 canvas（图标"画"，category innovation）；case_map canvas → rubber-tapping。
- 新增 canvas 色调 #0F6674 深青（含深色变体），与既有六色低饱和家族一致。
- 应用规划阶段为空时显示诚实空状态（"当前没有该阶段的应用"），不渲染空列表。
