# 103: 应用中心产品货架视觉

## 要什么

根据用户提供的应用中心与 SaaS 产品参考，将 `/inno/apps/` 从 101 的“Dock + 详情工作台”进一步升级为产品应用货架。六个应用各自拥有独立识别色、应用图标、场景分组、搜索、产品卡片和明确行动入口；点击卡片后，详情区呈现为该应用的产品主页。

## 不做什么

- 不新增未验证应用、评分、进度、用户头像或模拟产品截图。
- 不改变六个应用的名称、路由、状态、真实案例和证据边界。
- 不部署生产，不改公共导航，不把规划应用写成已上线。
- 不引入外部图标库或新前端依赖。

## 验收清单

- [ ] 应用按“内容学习 / 创新研究 / 接入扩展”分组筛选，并支持真实搜索。
- [ ] 每个应用卡包含独立色调、文字图标、标题、人群任务、摘要、状态、交付物和入口。
- [ ] 详情面板随应用切换独立色调，包含产品头图、元信息、交付物、真实案例路径与行动入口。
- [ ] 保留 096 的 `app-workbench`、`app-detail-title`、`app-case-title`、`app-data`、`selectApp` 契约。
- [ ] 桌面 1440px、移动 390px、深色模式无横向溢出，点击后详情进入视野。
- [ ] 构建和专项/既有回归通过；未部署生产。

## 实现约束

继续读取 `apps.json` 与 `cases.json`。色彩在页面 CSS 中集中定义为应用色调变量，保持深浅色对比。搜索、分组和状态筛选必须组合生效。
