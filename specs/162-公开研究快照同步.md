# 162 公开研究快照同步

## 要什么

- 核对本地与生产项目索引、原生研究项目及研究版本数量，按文件哈希确认真实差异。
- 将本地560题录、103个原生研究项目和221个研究版本以公开安全快照同步到档案只读服务与MCP。
- 保留当前静态站、运行时业务代码、权限、企业数据和已有历史版本，提供独立回滚快照。
- 同步适合进入版本库的源码与项目文档到GitHub，不包含输出包、私有原件、密钥或本机运行数据。

## 不做什么

- 不把457个只有目录或外部素材的项目称为已完成原生深研，不公开私有素材库。
- 不重新发布静态站、方法库或nginx，不修改项目事实、评分、审核状态与MCP写权限。
- 不用 `git add -A`、`git add .` 或整目录搬运方式收编输出文件和不明私有资料。
