# 144 中文地名与全拼链接边界

## 要什么

- 所有用户可见地名使用中文：报告标题、报告编号、正文、浏览器标题、运行对象和分享页面。
- URL 与二维码继续使用全拼 slug，例如 `?report=jiashan`；slug 不得泄漏到报告文字。
- 已存在的拼音报告数据在读取时规范化，不要求重新研究；新研究即使收到拼音输入，也以中文地名执行和展示。
- 新旧链接、地图点亮、收录、保存 HTML 均保持兼容。

## 不做什么

- 不把地址改回中文或百分号编码。
- 不伪造地名翻译；只使用明确映射和双方约定的 slug。
- 不改变研究内容与项目事实。

## 验收清单

- [ ] `?report=jiashan` 的标题、编号和正文显示“嘉善”，不出现 jiashan 文本。
- [ ] 二维码仍为 ASCII 全拼链接。
- [ ] 拼音输入与中文输入进入同一报告；已有拼音数据读取时规范化。
- [ ] 打印、独立 HTML 与既有交互回归通过。
