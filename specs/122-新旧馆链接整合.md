# 122 新旧馆链接整合（20261114-122）

120 之后暴露的问题：旧馆首页（/inno/legacy/，浅色版）与新馆（/ 与 /museum/，深色版）并存；"legacy"字样直接出现在用户地址栏；新馆与 legacy 内容页的链接关系没有名分。

## 结构定版

- **新馆（/ 与 /museum/）= 唯一门面**。
- **展品内容页获得博物馆系干净地址**（文件仍在 build 根目录，nginx 直出）：
  - /museum/hall 特展厅（hall.html）
  - /museum/zones 三大展区（categories.html，锚点 #industry/#life/#society 保留）
  - /museum/x-ray 拆解实验室、/museum/playground 互动乐园、/museum/laureates 获奖数据库、/museum/assistant 导览员、/museum/connect 产业、/museum/award 奖项
- **旧馆首页退役**：/inno/legacy/ 与 /inno/legacy/index.html → 301 到 /。
- **旧内容页 301**：/inno/legacy/hall.html 等 8 个映射到对应 /museum/ 地址。
- **不动**：/inno/legacy/ 下的资产（cases/*.jpg、css/js）与 atom/561、project/560 旧项目页继续作为技术路径服务；新链接一律指向 /dossier/，atom/project 不新增入口。

## 关键实现决策

- **链接改写放构建期，不改 original-app 源文件**：original-app 同时服务旧渠道（gooddesign.qiuyiwu.com），/museum/ 链接只在 inno 平台存在。build_gooddesign_site.decorate() 内置 MUSEUM_LINK_MAP，对博物馆系页面改写展品互链；曾因直接改源文件导致 005 历史快照身份校验失败，已回退并改为构建期改写。
- canonical 同步：8 个内容页指向 /museum/ 对应地址；审计器 ROUTE_MAP 同构。
- nginx：inno-root.conf 两个 regex location（zones 特殊映射 categories，其余 /museum/<name> → <name>.html）；server 级 rewrite 8 条旧路径 301 + 旧馆首页 301。

## 验证

- 733 项全量回归通过（005 身份校验、118 canonical 断言同步更新）；审计 P0=0/P1=0。
- 线上：/museum/hall、/museum/zones 200；/inno/legacy/hall.html → 301 /museum/hall；旧馆首页与 index.html → 301 /；/inno/legacy/categories.html#industry 全链 200 落到 /museum/zones；资产 200 不受影响。
- 页面链接实测：新馆首页与特展厅内互链已是 /museum/ 干净路径；canonical 正确。
- 桌面浏览器工具在验证阶段对 haoshejiguan.com 全域名连接中断（含此前正常的页面），curl 全部正常，判定为工具侧连接状态问题；页面内容此前已在本地同构环境（8892/8896）浏览器验证。
