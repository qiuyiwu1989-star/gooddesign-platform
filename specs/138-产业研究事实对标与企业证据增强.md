# 138 产业研究事实、对标与企业证据增强

## 要什么

- 在现有假设—证据—修正流程上增加真实研究投入：关键事实、可量化指标、对标地区、代表企业证据。
- 标准与深研的产业链/企业深读均使用联网检索；企业必须说明“证明什么”，并尽可能附公开来源与链接。
- 侦察阶段追加关键事实与对标研究；无来源数字不写成事实，不确定保持 unknown/待核。
- 机会方向增加关联依据与证伪路径，让产业研究和项目机制之间形成可追踪链路。
- 新增工作全部进入真实事件计数、报告和附录工作量。

## 不做什么

- 不通过增加固定文本或动画冒充深度；不伪造数字、URL、企业或对标关系。
- 不把联网模型输出升级为人工核读或投资结论。
- 本轮不做多模型投票、真实访谈和工程验证。

## 验收清单

- [ ] 标准/深研新增关键事实与对标的结构化字段及真实 activity 事件。
- [ ] 企业深读联网，企业卡包含证明意义与来源边界；空企业列表如实呈现。
- [ ] 报告可回查“事实/对标→需求→真实项目→验证”的关系。
- [ ] 模型新增调用计入 metrics；失败留痕并保留其他研究内容。
- [ ] 线上真实运行完成，无伪造来源或脚本异常。

## 实现约束

沿用阿里云 compatible-mode 与现有校验器；新增字段均经白名单截断和默认值校验。
