# 139 政府领导版咨政报告语言规范

## 要什么

报告面向地方政府领导与产业部门决策者，语言从系统技术说明转为“判断—依据—启示—试点建议”的咨政表达。信息简洁、稳重、积极但不夸大，保留证据边界。

核心口径由“方向可以谈，结论不能下”改为“先开展验证，再研究推广”。

## 用语对照

| 技术/内部表达 | 领导阅读版 |
| --- | --- |
| 机制迁移评估 | 优秀案例的借鉴价值 |
| 企业画像与需求 | 企业需求与主要制约 |
| 研究假设 | 初步判断 / 创新方向 |
| 支撑 / 部分 / 未知 | 依据较充分 / 部分印证 / 待进一步核实 |
| proposed、hard=null | 待企业确认 |
| 模型生成·待核 | 智能分析初稿·待核实（仅方法说明） |
| 确定性层写入、逐字召回 | 不进入领导正文；用“平台检索、资料核查” |
| 模型调用 | 智能分析（仅附录工作说明） |
| 0 项推荐 | 先验证（形成正式建议前的工作） |
| 风险与边界 | 需要注意的问题 |

## 不做什么

- 不因语言更积极而删除证据缺口、差异和试点前提。
- 不写“必然、领先、最优、应当上马”等无依据判断。
- 不改变结构化数据、研究状态和推荐纪律，只调整呈现语言与模型写作风格。

## 验收清单

- [ ] 封面、章节名、管理层摘要、需求表、机会方向、附录均为咨政语言。
- [ ] 页面与独立 HTML 不再出现“方向可以谈，结论不能下”及 proposed/hard=null。
- [ ] 正文不出现“确定性层、逐字召回、模型调用”等内部术语；附录工作量使用“智能分析”。
- [ ] 模型提示词要求面向地方政府领导，输出简洁、可论证、可试点的内容。
- [ ] 独立 HTML 与 PDF 排版无回归，真实报告链接可打开。
