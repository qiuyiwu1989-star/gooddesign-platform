# 142 上方分工主视图与单 Agent 执行流

## 要什么

- 上方角色链是唯一的研究分工主视图，保留角色、状态和真实工作量。
- 左侧不再重复七张角色卡，改为一个“小好 · 研究统筹 Agent”面板。
- 左侧以 Coding Agent 式连续执行流呈现：当前目标、正在思考、检索/阅读/核查/对照等动作、阶段结果和下一步节奏。
- `log`、`activity`、`think` 和阶段成果都进入同一连续过程；思考更新原位条目，活动逐条追加，自动滚动到最新。
- 暂停冻结过程与计时，继续后按事件顺序恢复；返回不遗留旧回放。

## 不做什么

- 不删除上方角色，不在左侧复制角色分工。
- 不展示原始 JSON、字段名、密钥或系统提示词。
- 不用定时器虚构工作量；所有过程来自真实事件或明确标注的数据包回放。
