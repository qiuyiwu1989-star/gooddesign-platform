# 137 报告专属扫码交付与项目可视化

## 要什么

- 每份报告有专属链接 `https://haoshejiguan.com/expo/?report={地名}`；封面和屏幕工具栏只显示本报告二维码，不再显示首页/项目库/展厅三个通用码。
- 扫码直接打开对应报告，可继续保存独立 HTML；下载文件封面也嵌入本报告二维码。
- 报告采用专业咨询版式：清晰的表格列宽与层级、产业链结构图、关键事实卡、项目封面与项目关系卡。
- 每个引用项目包含真实项目名、奖项、迁移点、差异、档案链接和项目专属二维码；动态召回项目同样可用。
- 下载 HTML 嵌入二维码和可获取的项目封面，保持离线阅读能力。

## 不做什么

- 不展示与当前报告无关的二维码；不使用第三方二维码图片接口。
- 不编造项目封面或项目关系；无封面使用中性占位，不把项目命中写成已验证采用。
- 不改变报告证据状态和推荐为空的纪律。

## 验收清单

- [ ] 报告链接可通过查询参数直接打开；二维码内容与本报告地址一致。
- [ ] 通用首页/项目库/展厅二维码不再出现在报告工具栏。
- [ ] 每个动态或静态引用项目均有档案链接和二维码，未知项目不导致脚本错误。
- [ ] 表格、产业链、项目封面在屏幕和 A4 中无逐字换行、无横向溢出。
- [ ] 下载 HTML 的二维码/封面为 data URL，离线打开可阅读。

## 实现约束

复用 `original-app/public/vendor/qrcode.min.js` 并在构建时内联；不新增依赖。项目事实与封面来自 catalog 或静态真源。
