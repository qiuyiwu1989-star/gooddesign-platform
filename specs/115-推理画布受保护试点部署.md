# 115: 推理画布受保护试点部署

## 要什么

把 113/114 已验收的推理画布部署到 OpenDesign 受保护试点路径 `/inno/canvas/`，让指定登录用户可以在浏览器中打开画布、保存工作区、恢复状态并导出 GDRP 研究包与人读报告。部署必须独立成服务，可回滚，不影响 112 应用中心与现有创新工作区。

## 不做什么

- 不公开匿名访问。
- 不改变现有 `/inno/loop/`、MCP、档案只读服务或应用中心路由。
- 不接在线模型，不同步私有原件，不把本机角色选择写成真实账号系统。
- 不删除旧 release；根分区空间不足时不强行部署。

## 部署结构

- 新 systemd 服务：`innovation-canvas.service`，监听 `127.0.0.1:18791`。
- 新数据目录：`/var/lib/innovation-canvas/canvas-state.sqlite3`。
- 新 release：`/var/www/innovation-design/releases/20261112-115`。
- nginx snippet 增加：
  - `/inno/canvas/` → 推理画布页面与静态资源。
  - `/inno/canvas/api/rc/` → 画布 API。
  - 两者都经 `/inno/auth/check` 保护，401 跳转 `/inno/login/`。
- 资产路径 `/inno/method-workbench/vendor/` 与 `/inno/design-system/` 只读代理到当前 release，保持 GoodDesign UI 单源。
