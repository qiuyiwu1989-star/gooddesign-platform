# 101: 应用中心应用化视觉设计

## 要什么

把 `/inno/apps/` 从说明型三栏页面升级为更像应用中心的视觉工作台：首屏展示项目证据与六类应用的关系，主体采用应用 Dock 加产品详情面板，明确交付物、案例路径、状态和阶段规划。用户能快速识别任务、判断应用状态并进入对应入口。

## 不做什么

- 不新增未验证的应用能力、模型执行进度或模拟数据。
- 不改变应用路由、案例路由、状态口径和证据边界。
- 不部署生产，不改动其他页面族或公共导航。
- 不为六个应用手绘独立 SVG 图标；使用统一文字图标与状态系统。

## 验收清单

- [ ] 首屏包含共享底座应用地图，六个应用节点与左侧 Dock 可点击联动。
- [ ] 详情面板包含适用人群、任务、状态、交付物、真实案例路径和行动入口。
- [ ] 阶段规划只按现有 live/pilot/planned 状态聚合，不虚构新计划。
- [ ] 桌面 1440px 与移动 390px 无横向溢出，移动详情能随选择进入视野。
- [ ] 筛选、选择、案例联动、键盘焦点和打印状态保持可用。
- [ ] 构建与全量相关测试通过；未部署生产。

## 实现约束

沿用 GoodDesign 设计令牌和现有 `apps.json`/`cases.json` 真源。保留 `app-workbench`、`app-detail-title`、`app-case-title`、`app-data`、`selectApp` 等既有契约，避免破坏 096 回归。
