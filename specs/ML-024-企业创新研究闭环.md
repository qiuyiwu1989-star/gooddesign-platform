# ML-024 企业创新研究闭环

状态：in_progress（本机三任务技术闭环及内部24生成/48AI评审已验；客户/领域/生产验收仍待）。2026-10-31，Asia/Seoul。

## 目标
企业从一个有版本的需求出发，看到证据支持的设计经验、条件化路线比较、可执行的研究计划和反馈记录；通过接库/不接库对照判断增量。

## 复用
保留ML006—009工作台与候选审查、ML016需求、ML021正文、ML022认知适配、ML023历史评审。061本机与064远程入口分别核能力，不混同工具与数据版本。

## 范围
第一阶段三个样板任务、至少六条有界设计经验；一条完整真实MCP读取及工作台闭环；四组实验骨架与独立评审协议。数量是覆盖下限，不等质量证明。

## 不做什么
不训练小模型、不全面搬迁560档案、不改冻结正文及历史试验、不自动启动实体设备、不自动公开原件/客户数据、不发消息招募专家。生产部署单列验收，现有授权范围以最新STATE为准。

## 验收清单
- [ ] AC01：设计经验具有原问题、对象、约束、机制、取舍、验证范围、来源版本、局限；未知可空且有理由，AI推断单独标识。
- [ ] AC02：需求有版本/差异、确认主体和确认证据；缺预算/工况/阈值不自动生成数值或认定工程就绪。
- [ ] AC03：每条迁移建议双侧有锚点及差异、假设和证伪路径；原项目参数不得自动成为目标参数。
- [ ] AC04：比较页支持至少三条路线；证据充分程度与用户偏好分开；未知不填0，不无依据输出唯一最优。
- [ ] AC05：研究动作说明问题、资源/责任待定项、观测、判别与停止条件；安全/专业批准缺失明确可见。
- [ ] AC06：真实stdio SDK走通需求→经验→方法→路线→反馈读取；实际ID/版本/SHA一致，技术通过不等语义或工程有效。
- [ ] AC07：反馈绑定需求/路线/主张/版本、角色、依据和状态；未授权反馈不公开或进入训练，意见不自动改事实与分数。
- [ ] AC08：四组对照预注册先冻结，统一任务/预算/模型配置，记录全部输出及失败；评审与作者分离，无预设赢家。
- [ ] AC09：旧工具/旧记录仍可读；共享导航与设计令牌复用；真实浏览器桌面/移动端完成关键交互，刷新/错误恢复可验证。
- [ ] AC10：公开/私有资源按现有权限验证；未授权访问拒绝，私有原件及密钥不进入构建；回滚可恢复代码与兼容数据读取。
- [ ] AC11：三个任务分别标注真实输入、构造输入及缺口；领域评审未到位只能标内部试运行，不称企业效果验收。

## 完成口径
规划完成、实现完成、技术通过、语义复核、领域验证、生产发布分别记录。不得以80分自评或文件数量代替以上门禁。技术问题可修复后重测；效果无优势同样是有效实验结论。
