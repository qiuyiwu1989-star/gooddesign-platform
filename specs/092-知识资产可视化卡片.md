# 092: 知识资产可视化卡片

## 要什么

将091汇报页的数据资产升级为可视化知识资产卡片。展示项目档案、full/patents来源、原始文件、图片、原生研究版、方法库及079单案的规模、关系、状态和下一步，支持类型筛选和卡片详情。

使用090结构化JSON作为唯一数据源，不把数字或静态卡片样式当成可视化完成。

## 不做什么

- 不虚构每个项目的研究状态、质量分、证据关系或模型进度。
- 不把卡片样式当成数据洞察，不公开私有原件。
- 不引入图表库、前端框架或生产部署。

## 验收清单

- [x] 卡片展示资产类型、数量、关系、状态和下一步，079单案与全库统计准确。
- [x] 可按全部/项目档案/来源素材/方法应用筛选，筛选后数量和布局正确。
- [x] 点击卡片有真实详情、证据入口和边界，dialog支持关闭、Escape和焦点返回。
- [x] 原生覆盖与队列可视化不冒充质量分，深浅主题、移动端和打印正常。
- [x] 全量测试通过，保存截图，未部署生产。

## 实现约束

沿用GoodDesign UI与090 JSON，使用原生HTML/CSS/JS和dialog。新增卡片交互，不改变研究数据。
