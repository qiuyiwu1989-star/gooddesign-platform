# 152 领导决策摘要与专业核查内容构成

## 要什么

- 管理层摘要同时服务领导与专业读者：一页内呈现产业基础、关键制约、案例启示与建议工作路径。
- 核心判断除状态外显示具体依据说明；未知/部分印证不得只留标签。
- 机会章新增“试点组织建议（供会商）”：试点对象、牵头协同、评价依据、推广前提，全部使用报告已有方向与验证字段或明确标为通用工作建议。
- 保持现有八章与附录，新增内容必须来自 pack；无数据时使用明确缺口，不补造事实。

## 不做什么

- 不把通用组织建议写成政府已确定的职责分工或企业承诺。
- 不添加无依据预算、收益、时间和推荐排序。
- 不改变研究数据、证据状态、历史版本与链接。

## 验收清单

- [ ] 摘要含产业基础/关键制约/案例启示/工作路径四区，并有真实内容。
- [ ] 核心判断显示 note 或明确待核实说明。
- [ ] 机会章含试点组织建议及“供会商”标识。
- [ ] 独立 HTML 与 A4 PDF 无溢出、异常断页或旧技术文案。
- [ ] 既有历史、链接与交互回归通过。
