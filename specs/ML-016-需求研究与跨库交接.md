# ML-016 需求研究与跨库交接
用户同意按网站架构建议推进。目标：项目/方法→需求研究→可导出草稿与真实统一MCP交接。
实现：/inno/needs/统一外壳，四步自然引导，当前浏览器保存/恢复/导出；从项目或方法链接带稳定ID进入，不宣称项目采用该方法。参考选择基于公开目录，项目仅已发布研究版可进入组包，最多3项目/5方法，文本组包上限符合inno_prepare_research。缺选择时交给Agent先检索，不编造匹配结果。
边界：只保存用户输入与选择，不假装语义理解或生成方案；不将MCP密钥放前端，不公开私有原件，不上传需求或收费调用。后续工作台执行另接真实权限与接口。
验收：预选ID核对、去重/限额、浏览器草稿重启恢复、无存储可导出、XSS按文本处理、跨库链接及MCP参数可被实际只读prepare接受；移动/键盘与线上路由检查。
