# 086: 顶部与底部栏统一隔离

## 要什么

统一旧站页面的顶部和底部栏，消除双重导航、错误栏目高亮及旧页脚样式混入。以`categories.html`为实证：旧`<nav>`残留、通用`nav{}`污染`gd-links/gd-footer-links`、当前页错误高亮项目库。

保留统一GoodDesign品牌、导航栏目、真实页面内容和旧资源，不另造页面专用顶栏。

## 不做什么

- 不修改原始旧站文件、业务数据、URL或图片。
- 不删除正文内部功能导航、阅读目录或研究交互。
- 不用局部颜色覆盖掩盖结构重复，不部署生产。

## 验收清单

- [x] 旧馆`<nav>`按装配规则移除，正文header不被误删；每页只有一个统一主导航。
- [x] 旧footer在注入共享底部前清理，每页只有一个统一底部。
- [x] `gd-links`与`gd-footer-links`不受旧通用nav背景/定位/高度/边框影响，浅深色一致。
- [x] categories、award、laureates等馆页面高亮好设计馆，项目库不高亮。
- [x] 展馆图片、首页、档案、小好及全量测试通过，保存前后截图，未部署生产。

## 实现约束

修改共享`replace_chrome`、构建期栏目映射和GoodDesign UI重置，不逐页复制补丁。

## 状态

done：旧馆导航/页脚和copilot统一清理，样式污染修正，栏目归属正确；功能导航与gd-live组件footer保留。34项专项检查、575项全量测试及首页/小好/展馆/动态案例/档案回归通过，详`00-项目管理/086-顶部与底部栏统一隔离验收.md`。未提交Git或部署生产。
