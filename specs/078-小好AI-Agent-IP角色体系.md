# 078: 小好AI Agent IP角色体系

## 要什么

将通用机器人“小好”改为GoodDesign自己的AI Agent研究伙伴。参考用户提供的圆润手绘形象，形成有辨识度、能长期使用的角色与动作体系，并接入全站真实导览。

角色定义：小好是陪用户找项目、读方法、核证据的研究搭子，性格亲和、好奇、严谨，不把演示冒充自动研究。

视觉方向：薄荷绿圆润身体、深色描边、探索笔记本与少量珊瑚色点缀；保持小尺寸辨识度，不做复杂3D、机器人天线或Emoji。

动作体系：
- 默认：挥手并拿探索笔记本，用于导航与欢迎。
- 读方法：翻开书本，用于方法库导览。
- 核证据：手持放大镜，用于项目证据导览。

## 不做什么

- 不复制参考图的 exact 轮廓与动作，不引入外部图片依赖。
- 不改变“小好只提供真实导览”的能力边界，不虚构模型对话或自动研究。
- 不改变导航结构、工作区project绑定、Escape与焦点返回。
- 不部署生产，不替换品牌Logo或奖项图标。
