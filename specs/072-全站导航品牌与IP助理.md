# 072: 全站导航、品牌细节与 IP 助理

## 要什么

统一全站导航栏、底部栏和 GoodDesign 品牌，继续打磨布局与自然人机交互。超链接不使用箭头，动作以明确文字表达。设计品牌 Logo 与好设计 IP 助理“小好”，提供真实的项目、方法和证据导览。

## 不做什么

- 不在链接文字末尾使用 `↗`、`→`、`←` 等方向符号。
- 不把导览称为已接通的模型、自动研究或工程建议。
- 不改变研究事实、权限、业务数据、私有原件和生产状态。
- 不用多个不同结构的导航/页脚或同页重复导航冒充统一。
- 不使用 Emoji 充当新 Logo 或 IP 形象。

## 验收清单

- [ ] 所有目标页面只有一个标准导航栏和一个标准底部栏，品牌为 GoodDesign。
- [ ] 栏目、当前状态、主题切换、键盘焦点和移动导航一致。
- [ ] 新 Logo 与“小好”IP 资产为独立 SVG，导航和导览实际使用。
- [ ] 小好可打开、Escape 关闭、焦点返回，三个导览动作进入真实页面。
- [ ] 全站可见超链接不再以箭头收尾，正文和代码内容不被误改。
- [ ] 全站结构比对、17类代表页面、双宽度与原有回归通过。
