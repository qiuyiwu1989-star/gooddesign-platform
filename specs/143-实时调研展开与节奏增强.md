# 143 实时调研展开与节奏增强

## 要什么

- 右侧主视区不再停留于固定角色和三节点结构；真实事件到达时展开研究调用与资料卡片。
- `activity` 形成检索、阅读、核查、企业研究、案例召回等卡片；`think` 形成当前分析片段并持续更新/扩展。
- 卡片有紧凑的出现、连接和状态动画；旧卡片有序退场，保留最近六项，不无限堆积。
- 静态回放与真实 SSE 使用同一动态区域；静态回放缩短空等，真实模型思考推送由 0.5 秒节流提高为 0.25 秒。
- 暂停时卡片和动画同时冻结，继续后队列事件展开；报告交付不变。

## 不做什么

- 不按时间伪造资料数量，不用无意义粒子冒充研究。
- 不改变模型输出、证据状态、工作计数和报告内容。
- 不影响上方分工、左侧单 Agent 执行流和浅色报告。
