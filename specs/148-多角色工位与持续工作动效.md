# 148 多角色工位与持续工作动效

## 要什么

- 在模型等待和真实事件之间，右侧持续显示多个角色工位，而不是空白或固定三节点。
- 每个工位有独立角色头像、当前分工、鼠标指针与进行中的读取/分析动线；使用已有内嵌角色图片。
- 工位表示正在执行的计划分工，不显示虚假完成数；真实 activity 到达后才增加成果卡与工作量。
- 新阶段保留最近真实成果，替换为新阶段工位；暂停冻结所有动画，减少动态偏好仍生效。
- 保持上方角色链、左侧单 Agent 执行流、真实事件计数和报告交付不变。

## 不做什么

- 不把工位动画称为真实鼠标操控、独立模型实例或已完成的网页访问。
- 不按动画帧增加工作量，不伪造完成百分比。
- 不引入新的图片依赖或动画库。

## 验收清单

- [ ] 阶段开始后无需等待真实事件，即出现至少三个具体工作工位。
- [ ] 工位包含不同角色形象、分工文字、指针和进行中动线。
- [ ] 工位不增加成果计数；真实事件继续展开，最多六项。
- [ ] 阶段切换替换工位且保留真实成果；暂停/继续正常。
- [ ] 移动无横向溢出，完整回放与报告交付通过。
