# 117 主域切换与全站视觉统一

用户决策（2026-11-12）：

1. **haoshejiguan.com 为平台主域名，opendesign.cc/inno/ 不再使用。**
2. **整个网站视觉统一打磨一轮。**

## 阶段划分

### 阶段一：硬切换（已完成，2026-11-12）

- opendesign.cc 的 443 server 块移除 inno-readonly.conf 与 method-library.conf 两个 include（两者全部内容均为 /inno/ 与 /methods 域内路由，摘除无副作用），改为：
  - 页面 /inno/* → 301 https://haoshejiguan.com$request_uri（保留查询串）
  - /inno/api/、/inno/canvas/api/、=/inno/mcp/api → 308（保留 POST 方法）
  - /methods/* → 301 到新域 /inno/methods/*
- 配置入库 deploy/nginx-opendesign.cc.conf（首次把主站配置纳入版本管理），服务器原件备份 opendesign.cc.bak-20261112。
- opendesign.cc 主站其余路由（/packs/、/zjuid/、/studio/、/api/、/admin 等）未动；gooddesign.qiuyiwu.com 旧站未动。
- 验证：页面 301、API 308 经 -L 到达 MCP 后端 401（端点存活、仅鉴权）、opendesign.cc 根 200、新域 200。
- Cookie 无 Domain 属性（Path=/inno，host-only），登录态在新域自动可用。
- deploy/innovation-project.json 入口已改指新域并加 main_domain 字段。历史验收文档（093/097/115 等）保留旧 URL 不改写。

### 阶段二：路径去 /inno/ 化 + 全站视觉统一（合并执行，进行中）

### 阶段三：MCP 与外部接入口径收口

- MCP 客户端 URL 从 https://opendesign.cc/inno/mcp/api 迁到新域（308 过渡期内仍可用）。
- registry.json、llms.txt、sitemap、MCP 说明页统一新域口径，随阶段二重建发布。

## 边界

- 任何一步失败回滚：opendesign.cc 用 .bak-20261112 恢复；release 回滚沿用三段式回滚材料。
