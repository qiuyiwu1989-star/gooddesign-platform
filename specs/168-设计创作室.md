# 168 设计创作室

## 要什么

- 选择真实项目图片，填写设计名称、真实问题与说明，实时形成作品。
- 支持主题、文字大小和标题位置调整，桌面/移动预览、草稿恢复、PNG导出和分享链接。

## 不做什么

- 不冒充云端发布、AI设计或公开社区，不引入大型画布依赖。

## 验收清单

- [x] 图片与文字实时更新，标题可定位，主题与字号可编辑。
- [x] 草稿刷新恢复，PNG与预览一致，分享链接可恢复作品。
- [x] 移动、键盘和资源加载通过。

## 验收证据

线上实测主题切换、标题拖动、草稿恢复、分享链接恢复及真实PNG导出通过。
