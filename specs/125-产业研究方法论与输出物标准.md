# 125 产业研究方法论与输出物标准（小好深研）

## 一、为什么是重构而不是优化

v1-v9 的流水线（S1→S6 单次通过）是工作流仿真：有阶段、有动画，但没有假设、没有求证、没有修正。真 Deep Research 的形状是**假设→证据→修正的循环**。咨询专家的三个基本动作：

1. 先定义研究问题（不是"产业是什么"，而是"升级的真实约束在哪、世界上有没有人解过"）。
2. 带初始假设进场，找证据推翻或支撑。
3. 每条判断标注证据状态：支撑/部分支撑/未知。

## 二、我们的独特位置：机制迁移研究

普通行研答"这个产业是什么"；我们答"这个产业能从 560 个国家级获奖项目里借到什么"。自有框架：

- **技术/工艺/装备三层拆解**：产业链之外加工艺层，因为获奖项目的机制在工艺层。
- **约束识别**：升级约束归类（精度/成本/合规/交付/人才），约束类型决定检索方向。
- **双侧映射校核**：迁移点与差异同列（既有 transfer 纪律）。
- **So-what 检验**：每节必须回答"对本地决策者意味着什么"，答不出的段落删除。

## 三、研究循环（产品流程重构）

```
破题 → 起草研究问题与 2-3 条初始假设（证据状态=未知）
侦察 → 按假设逐条联网取证（web_search，来源 URL 随证据保存）
拆解 → 产业链三级 + 技术/工艺/装备三层
求证 → 每条假设：库内检索 + 联网证据 → 支撑/部分/未知
映射 → 按约束类型在获奖库做双侧映射（真实项目）
综合 → 修正假设为核心观点，逐条过 so-what 检验
成稿 → 按输出物标准装配，证据状态全程可见
```

原则不变：模型只起草，确定性层才有写入权；联网内容标来源与"公开资料·待核"；推荐永远为空。

## 四、输出物标准 v1（质量门禁）

| 章节 | 必填 | 门槛 |
| --- | --- | --- |
| 摘要 | 3-5 条编号核心观点 | 每条带证据状态（支撑/部分/未知），无状态不合格 |
| 产业界定 | 定义+边界 | 必须写明"不含什么" |
| 产业链与技术栈 | 三级链+三层技术栈 | 环节落到具体主体 |
| 龙头与格局 | 代表企业 | 每家必须说明"它证明了什么" |
| 约束与需求 | 需求表 | 全部 proposed/hard=null |
| 机制映射 | 项目+迁移点+差异 | 项目必须真实存在；差异为空拒收 |
| 机会与验证 | 方向+验证步+证伪路径 | 无验证步不入报告 |
| 证据与来源 | 关键判断的来源 | 库内ID/来源URL/模型推断三类分标 |
| 风险与边界 | 未验证项与缺口 | 空缺明说不补造 |
| 禁项 | 推荐排序、无来源数字、百科式概况 | 出现即不合格 |

## 五、实施顺序

1. 破题与假设生成 + 证据状态贯穿（pack 增加 theses[]）。
2. web_search 接入侦察与求证（火山方舟联网搜索工具，来源 URL 入证据账本）。
3. 报告渲染升级（核心观点带证据状态徽标，证据与来源节）。
4. 评价回路：同一输入两次运行结构稳定、禁项扫描为零。
