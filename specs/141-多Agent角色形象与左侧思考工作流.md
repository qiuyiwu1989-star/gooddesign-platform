# 141 多 Agent 角色形象与左侧思考工作流

## 要什么

- 顶部节点和中央当前角色使用小好 IP 角色形象与角色徽章，不再只是抽象字块。
- 左侧每个 Agent 卡片持续呈现自己的工作流：当前分析内容、逐项资料/数据处理过程和阶段结果，不只显示底部一条全局状态。
- `think` 流以简短可读摘要进入对应角色，去除 JSON 括号、字段名等技术噪声；`activity` 和 `log` 进入对应角色的最近过程。
- 已完成角色保留最后工作记录；工作中角色可展开显示多条过程，整体可滚动。
- 静态回放、真实 SSE、暂停/继续继续共用同一事件处理，不虚构工作量。

## 不做什么

- 不宣称每个角色一定是独立模型实例；它们是研究分工与真实事件的可视化。
- 不展示原始 JSON、密钥或内部系统提示词。
- 不改变研究流程、报告内容、全拼链接或浅色报告版式。

## 验收清单

- [ ] 顶部与中央角色均显示小好形象，角色徽章和色彩仍可区分。
- [ ] 左侧七角色均有独立最近过程区；活动事件进入对应角色而非只更新全局。
- [ ] think 内容去除 JSON 结构字符和字段名，暂停时不推进。
- [ ] 静态回放可完整到报告，桌面/移动无横向溢出。
- [ ] 已有报告直达、返回、暂停、收录和下载不回归。
