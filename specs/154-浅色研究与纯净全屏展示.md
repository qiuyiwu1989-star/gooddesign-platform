# 154 浅色研究与纯净全屏展示

## 要什么

- 产业看台首页、地图、研究过程与报告均可使用完整浅色主题，沿用全站主题按钮与本机偏好。
- 首页、研究过程和报告可进入纯净全屏；隐藏全站导航、页脚、应用操作栏和地图工具，仅保留研究内容与一个最小退出按钮。
- 浏览器全屏不可用时仍提供 CSS 纯净展示；Esc、浏览器 fullscreenchange 与退出按钮保持状态一致。
- 全屏展示期间不因空闲计时自动返回首页；移动端、报告独立链接、暂停、保存 HTML 与 A4 打印不回归。

## 不做什么

- 不改变研究流程、真实事件、报告内容、历史记录或服务端 API。
- 不在页面加载时强行请求浏览器全屏，不伪造全屏成功。
- 不为产业看台增加第二个主题按钮，不修改其他页面的导航与主题。

## 实现约束
