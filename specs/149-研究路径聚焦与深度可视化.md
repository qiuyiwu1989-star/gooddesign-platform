# 149 研究路径聚焦与深度可视化

## 要什么

- 借用路径追踪、点击聚焦和降噪策略，不引入外部库。
- 新研究事件出现时有短促的关联/追踪动线；点击或键盘选择卡片可查看完整内容、研究环节、动作类型和真实序号。
- 工位、思考与成果卡的聚焦状态明确区分；工位不冒充已完成成果。
- 左侧统筹面板增加研究覆盖深度：公开资料、企业深读、判断核查、案例对照，全部显示真实计数；核查可显示已核/总数。
- 深度指标不使用无依据综合评分，不替代现有工作量和报告。

## 不做什么

- 不改变研究流程、召回算法或证据状态。
- 不生成虚构的相关关系；聚焦只展示该事件已有字段。
- 不引入第三方字体、动画库或网络请求。

## 验收清单

- [ ] 新事件有追踪动线，点击/Enter 可聚焦，Escape 清除。
- [ ] 聚焦内容完整且与原事件一致，其他卡片降噪。
- [ ] 左侧深度四项随真实事件更新，未知显示“—”。
- [ ] 暂停/继续、阶段切换、静态回放与完整报告通过。
- [ ] 移动无横向溢出，减少动态偏好生效。
