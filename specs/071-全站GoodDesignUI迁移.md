# 071: 全站 GoodDesign UI 迁移

## 要什么

用户要求项目所有页面按 GoodDesign UI 打磨。以 069 的长期设计系统为唯一视觉底座，对旧站公开页面、`/inno/` 公共页面、方法库、项目档案、需求研究、数据总览、MCP、资料后台和研究工作台实施统一视觉迁移，并保留真实内容、交互、权限与旧链接。

基线盘点：

- `original-app/public/`：1165 个 HTML，含首页、560 项目页、561 atom 页面、课程、展项、教育工具、教师工作台和产业演示。
- `extensions/method-reader/`：67 个 HTML，含 64 方法详情及索引/接入/写入规范。
- 动态公共页：项目库首页、档案、需求研究、数据总览、MCP、使用说明。
- 工作区：8776 资料后台、8786 方法工作台、18784 企业研究闭环。

## 不做什么

- 不修改研究事实、评分、项目 ID、权限、私有原件、模型配置或业务数据。
- 不直接部署生产，不关闭旧站，不执行 070 的退役动作。
- 不把输出目录、历史快照、私有研究文档和 API 响应当作公开页面换肤。
- 不用统一 CSS 破坏 3D/大屏展项、课程画布、节点编辑器、PDF 预览和打印。
- 不以“所有文件已加 CSS”冒充所有页面已经视觉验收，不伪造全量完成状态。

## 实施方案

1. 建立 GoodDesign UI 统一资产与旧令牌兼容层，所有目标页面使用同一字体、色彩、控件、圆角、表面、状态和动效。
2. 旧公开页面通过可重复构建的迁移层处理，保留原文件和原始构建，不改历史快照。
3. `/inno/` 共享 shell、方法阅读器、档案与工作区按页面族接入并精修。
4. 公开只读、私有本机、互动展项和打印分别验收，生产仍保持原状。

- [ ] 项目库、方法库、档案、需求、汇报、MCP、资料后台和工作台真实走查。
- [ ] 旧站首页、项目页、atom、课程、展项、教师工具和产业演示真实走查。
- [ ] 1440、1024、768、390、360px 无意外全页溢出，特例显式登记。
- [ ] 键盘、焦点、主题、筛选、分页、抽屉、表单、保存与错误恢复无回归。
