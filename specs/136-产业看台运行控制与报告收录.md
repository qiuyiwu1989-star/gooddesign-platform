# 136 产业看台运行控制与报告收录

## 要什么

- 运行页提供清晰的“返回”和“暂停/继续”；报告页也可返回首页。
- 返回离开当前演示并回到地图首页，不允许旧静态回放在后台再次打开报告。
- 暂停冻结角色状态、计时和事件呈现；真实 SSE 到达的事件排队，继续后按顺序播放；静态回放同步暂停。
- 报告提供“收录后台”动作，收录已有服务端报告并显示成功/失败状态；地图点亮数据同步更新。
- 暂停是演示播放控制，不宣称暂停远端模型计算。

## 不做什么

- 不实现远端模型推理的取消或断点续算。
- 不接受客户端上传任意报告内容覆盖后台；收录接口只接收地名并操作服务器已有报告。
- 不改变现有报告完成后的自动冻结存档行为。

## 验收清单

- [ ] 运行中返回首页后无旧事件/回放继续改变页面。
- [ ] 暂停后计时和事件呈现停止，继续后顺序恢复，不丢 pack/done。
- [ ] 静态回放在暂停时不推进后续阶段。
- [ ] 收录接口拒绝无报告地名，合法收录返回时间；前端成功显示“已收录”。
- [ ] 报告页返回、重新研究、保存 HTML、打印互不影响。

## 实现约束

沿用单页状态与 SSE；新增 `POST /expo/api/archive` 只读客户端地名、写服务器已有报告。同源请求，限制请求体大小。
