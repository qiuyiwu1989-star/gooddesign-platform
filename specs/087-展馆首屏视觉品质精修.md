# 087: 展馆首屏视觉品质精修

## 要什么

替换好设计馆及三大展区页面中高饱和蓝色渐变，提升整体视觉品味。采用石墨色低饱和层次、系统无衬线、珊瑚色小提示和克制的间距，保持统一GoodDesign品牌与真实内容。

覆盖`inno/museum/`的`.foyer`和`categories.html`的`.page-hero`，同步调整标题、英文副标题、正文、移动端与深色可读性。

## 不做什么

- 不改变导航、页脚、文案、图片、URL或数据。
- 不使用另一套高饱和渐变、紫色光晕、装饰动画或在线字体。
- 不把局部首屏修改扩散成全站换肤，不部署生产。

## 验收清单

- [x] 旧蓝色渐变不再生效，石墨色层次与品牌紫/珊瑚点缀一致，页面不显得廉价或刺眼。
- [x] 标题使用系统无衬线，英文副标题和正文清晰，间距与行高统一。
- [x] 1440/1280/1024/768/390/360px无溢出，移动端标题与正文不重叠。
- [x] 深浅主题对比度满足WCAG AA，图片和统一顶底栏不回退。
- [x] 全量测试通过，保存前后截图，未部署生产。

## 实现约束

新增独立`museum-hero.css`，在页面既有内联样式之后加载，确保覆盖旧渐变；由`build_gooddesign_site.py`白名单同步。
