# 007 双环现场研究 Agent

用户目标：现场可输入问题并交互，充分利用预加载双环背景及好设计知识，展示研究过程。

实现：/industry-demo/live.html；企业画像、六条案例依据预加载；真实在线/api/chat SSE；现场问题和约束进入请求；输出问题缺口、证据选择、两种方向、验证及确认问题。再次研究按当前完整问题和新增约束重算，不自动承接上一轮未明确写入的回答。输入限公开演示资料；模型服务接收输入已有提示。

诚实状态：资料加载、请求模型、流式生成、完成/中断均跟随实际事件；不使用定时动画冒充研究，不显示内部思考记录，不声称已联网或调用TRIZ矩阵。网络失败后仅由用户点击显示固定预置案例，明确不会随现场输入重算。

交互：三个问题快捷入口、补充条件、停止、修改后重算、来源展开、导出模式标注的简报、进入课题工作台。

验收：test_live_demo.cjs 验证输入条件传递、接口字符限制、分片SSE解析、完成与预置标记。服务器HTTPS四文件字节一致通过。浏览器控制超时，视觉未验证。真实模型可用性另见STATE记录；未经成功实测不可承诺现场稳定性。
