# 077: MCP接入中心布局重构

## 要什么

将 `/inno/mcp/` 从连续说明长文重构为MCP接入与工具管理页，让开发者能依次完成接入配置、理解工具、复制任务和排查问题。

设计读法：面向开发者和研究人员的接入工作台，沿用GoodDesign UI，视觉变化4、动效2、信息密度6，配置与工具内容优先于品牌说明。

信息结构：
- 首屏：远程只读定位、服务地址、Streamable HTTP、8项工具和0模型调用。
- 接入配置：JSON/TOML切换、密钥输入、配置预览、复制与环境变量说明。
- 工具目录：发现、深读、组包三类8项真实工具，支持搜索、筛选和参数展开。
- 调用流程与任务：检索、读取、核证、组包，保留完整任务描述复制。
- 权限与排障：只读边界、120KB及3/5/5限制、无历史保存、常见错误。

## 不做什么

- 不伪造在线连接状态、服务健康检查、模型调用或研究历史。
- 不把原本机10工具与远程8工具混写，不开放源写入、原件下载或付费模型。
- 不将真实密钥写入HTML、预览、URL、浏览器存储或服务器请求。
- 不改变远程API、认证、工具参数、权限或生产部署，不引入前端依赖。

## 验收清单

- [x] 首屏配置优先，服务地址和远程只读边界清楚，无虚假在线状态。

- [x] 077静态测试、真实浏览器和全量回归通过。

## 实现约束

复用 `innovation_gateway_http` 的8工具定义和现有 `mcp-guide.js` 安全原则。`innovation_gateway_page.py` 输出结构化HTML，新增 `mcp-center.css` 并纳入全站构建。配置预览只使用 `<YOUR_PRIVATE_MCP_KEY>`；TOML继续读取 `GOODDESIGN_MCP_TOKEN` 环境变量。复制降级采用用户主动打开的全选对话框，不伪造复制成功。
