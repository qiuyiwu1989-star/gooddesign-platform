# 130 expo 首页县级中国地图

## 需求
用户要求：首页地图以全国县级为单元、完整显示轮廓、可放大缩小进行寻找。此前 121v8 为规避地图合规风险用的是"城市点阵示意（非精确边界）"，本次按用户明确要求升级为真实县级边界。

## 数据
- 来源：阿里云 DataV GeoJSON areas_v3（https://geo.datav.aliyun.com/areas_v3/bound/{adcode}_full.json）。省级文件只到地级，地级文件才含区县；363 个地级文件 + 34 个省级文件。
- 特殊处理：
  - 直辖市/港澳的区在省级文件（110000/120000/310000/500000/810000/820000）；
  - 省直辖县级单位（仙桃 429004、石河子 659005 等 34 个）无地级文件，几何回退取省级文件中的对应要素；
  - 台湾（710000）DataV 无下级数据，用省级轮廓补齐为一个单元；
  - 九段线（adcode 100000_JD）保留在省级文件，供南海诸岛插图。
- 构建：scripts/build_expo_geo.py，缓存 output/expo/geo-cache（gitignore，可用 --refresh 重下），产物 extensions/expo/geo/：
  - cn-counties.json 县级单元 2875 个（保留 centroid，坐标 3 位小数 ≈100m 网格，相邻县共享顶点不被破坏），约 16.9MB（gzip 约 3.7MB）；
  - cn-provinces.json 省级轮廓 + 九段线 35 要素，约 0.5MB。
- 部署：/var/www/expo/geo/，nginx 专用 location ^~ /expo/geo/ 长缓存 7 天（gzip_types 已含 application/json）。边界数据不经常变；变更时重新构建即覆盖（文件名不变，缓存到期自然更新）。

## 交互（extensions/expo/agent-template.html）
- 投影：等距圆柱 + cos(35°) 横轴修正，纯前端计算，无第三方库。
- 渲染顺序：省级轮廓与省名先画（小文件先到），县级层异步绘制完成后淡入（opacity 过渡）；南海诸岛插图右下角独立小组（不随缩放）。
- 缩放：滚轮以指针为中心 1–16 倍、双击放大、右上 +/−/复位按钮；平移：指针拖动（缩放>1 时）；点击与拖动以 5px 位移阈值区分。
- 描边用 vector-effect:non-scaling-stroke，缩放下保持恒定线宽。
- 悬停显示县名 tooltip，并提示"已点亮·点击查看报告 / 点击开始研究"。
- 点亮：LIT（/expo/api/places ∪ 默认玉环/嘉善）按短名匹配县级要素（去 市/县/区/自治县 等后缀），命中的县高亮 + centroid 脉冲标记与名称；未命中的点亮地名（如地级市"嘉兴"无同名县级单元）本轮不标，为已知边界。
- 点击：已点亮 → 打开现成报告；未点亮 → 取短名填入输入框并启动真实研究。
- 兜底：geo 数据拉取失败（离线）自动退回 121v8 城市点阵示意。

## 合规注意
- 121v8 曾刻意用点阵规避地图合规问题；本次按用户要求上真实边界。数据含台湾与九段线（南海诸岛插图），要素完整、未删改。正式对外长期公开前，建议评估是否需要在页面标注审图号或改用有审图号的标准地图服务；本地图不用于测绘用途、不标注敏感地理信息。
