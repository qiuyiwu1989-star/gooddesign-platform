# 064 可分享远程MCP
用户纠正本机硬盘配置无法分享，需要别人复制即可接入。部署HTTPS Streamable HTTP统一入口，地址+独立Bearer访问密钥；不要求客户端持有数据库或外置盘。

远程范围：8只读工具，发现/读取两库、字段/证据及组包。禁止源写入、模型付费、保存本机计划和回读私有研究历史。原本机10工具不变。密钥不写网页/代码，只保存SHA登记于服务器私有配置，原始协作测试密钥只交本地私有配置文件，支持撤销。无密钥/坏密钥401。

验收：外部真实MCP initialize/list/search/read/prepare；匿名/错key/撤销/超体积/错Origin/写和历史调用拒绝，后端只loopback，public文档不含真实密钥。页面以远程URL配置为默认，本机配置降为高级备用。旧版可回滚。
