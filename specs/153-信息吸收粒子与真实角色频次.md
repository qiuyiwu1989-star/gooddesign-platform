# 153 信息吸收粒子与真实角色频次

## 要什么

- 每个真实 activity/think 事件可生成一个信息粒子，从当前工作卡流向对应角色，表现“吸收与处理信息”。
- 角色核心有克制的吸收环；粒子有轨迹、淡出和数量上限，不能无限堆积或影响阅读。
- 角色记录实际事件总数与近 10 秒频次，并在指针/聚焦详情中展示；不将次数解释为专家能力评分。
- 多角色工位继续呈现分工与协同，粒子只绑定真实事件；静态回放明确沿用数据包事件。
- 暂停、减少动态、移动端与报告交付不回归。

## 不做什么

- 不按时间随机生成粒子，不把粒子数当作数据条数或计算能力。
- 不伪造独立模型实例、真实鼠标操作或能力等级。
- 不改变研究内容、事件计数、链接和报告。

## 验收清单

- [ ] 真实事件生成粒子并流向当前角色；同一事件不重复生成。
- [ ] 粒子有轨迹与淡出，活动粒子数有上限。
- [ ] 角色总数与近10秒频次可从事件时间戳复算，聚焦详情可见。
- [ ] 暂停不新增粒子，减少动态时可直接跳过粒子。
- [ ] 完整回放、独立 HTML/PDF 与既有回归通过。
