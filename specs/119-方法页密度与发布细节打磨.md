# 119 方法页密度、档案孤立符号与发版细节（20261112-119）

117 阶段二版式层打磨的第一轮，随全站审计（118）之后做深一层的修正。

## 修复内容

### 1. 方法页信息密度（extensions/method-reader/method-detail.css）

- 根因：hero 的 `gap:28px` 同时作用为 grid 行距，5 行内容被撑出 112px 额外空白；改 `column-gap:28px; row-gap:2px`，移动端同步。
- hero 外边距 24→16、内边距 34/36→28/32。
- "全部方法"返回链：上移（margin-top 24→8）、加 `‹` 符号、改为品牌色，不再像死链文字。
- 效果：首屏可见 hero + 增补说明 + 第一章节与目录，桌面 1440 与移动 390 截图对比存 output/design-119（before/prod）。

### 2. 档案页孤立 `>` 符号（scripts/workspace_ui.py:31）

`re.sub(r'<main\b(?![^>]*\bid=)', '<main id="main">', ...)` 只匹配 `<main` 不含闭合符，替换后原 `>` 残留成文本节点，所有档案页 main 后都多一个可见 `>`。改为匹配完整标签并保留原属性的 lambda 替换。回归测试锁定（test_no_stray_gt_after_main_id）。

### 3. 双 skip link 修复（scripts/gooddesign_chrome.py）

replace_chrome 现在先移除页面自带的 gd-skip / skip 跳转链接再插入新 chrome，旧页（如 inno_site_chrome 模板页）不再出现两个"跳到主要内容"。

### 4. CSS 内容指纹版本化（scripts/gooddesign_assets.py、build_method_reader.py）

portal 四个 CSS 与方法库 reader/method-detail CSS/JS 链接统一带 `?v=<内容sha前8位>`。解决发版后浏览器沿用旧缓存导致"样式改了但页面不变"的问题（本轮验证时实际踩到）。

### 5. canonical 标签（scripts/build_gooddesign_site.py）

全部 1248 页注入 `rel="canonical"`：inno 页指向对应 /inno/ 路径，legacy 页指向 /inno/legacy/，museum 指向主域根（好设计馆即首页）。主域切换后给搜索引擎的去重信号。

### 6. 深浅色域规则入规范（03-平台规划/好设计平台UI视觉规范-v2.md 第 13 节）

定义浅色工作区与深色展厅的场景分工与五条过渡规则（chrome 恒浅色、深色只从 hero 边界开始、展厅控件按深色令牌、主题切换不覆盖展厅、新展页必须归入 museum family）。
