# 042 资料整理入档引导

## 要什么
用户看不懂提炼与审核如何操作，要求简化交互并明确创新研究用途。
- 保留三入口和资料布局；创新研究改为应用案例，明确当前是固定模拟企业需求。
- 文件行与预览提供整理入档入口，带入当前资料；整理页采用选资料/核对内容/更新研究档案三步。
- 一个按钮完成机器侧文字识别与字段提取；显示处理中、结果与无结果的下一步。
- 核对时并排看准备写入的内容与原文，明确采纳/待补/不采用；不自动审核。
- 更新前预览全项目已确认项，显式确认后发布独立研究版本；解释展示档案另行整合。
- 专业表单、来源定位、原始记录收进研究人员工具。

## 不做什么
不加入通用LLM提炼、批量自动采纳或自动覆盖人工底稿；不改嫦娥现有事实评分；不新增真实企业案例。

## 验收
- [x] 文件→选定资料→提取→核对原文→确认→预览→发布在隔离库实测。
- [x] 无结果、处理中、失败、共享资料、跨项目、刷新/返回的状态明确。
- [x] 待更新项为全项目范围，明确发布不会覆盖展示底稿。
- [x] 应用案例说明与命名一致；历史研究数据不覆写。
- [x] 手机、键盘与现有管线/API回归通过；只交付本地改动。
