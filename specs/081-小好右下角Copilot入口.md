# 081: 小好右下角 Copilot 入口

## 要什么

将“小好”从顶部导航迁移为右下角常驻入口，形成接近Copilot的自然使用方式。桌面显示头像与名称，移动端使用圆形头像。点击后在入口上方打开研究导览面板，保留找项目、读方法、核证据三个真实动作和当前项目绑定。

沿用统一`gooddesign_chrome.py`、GoodDesign UI令牌、原生dialog和现有角色资产，不另造助手或模型能力。

## 不做什么

- 不改变导航栏目、三个导览URL、项目ID、主题或数据。
- 不模拟在线对话、模型生成、自动研究或云端状态。
- 不新增依赖、角色图片、自动动画或滚动监听。
- 不让浮层造成页面横向溢出，不丢失Escape关闭、焦点返回、移动和深色支持。
- 不部署生产，不因入口迁移改动其他业务页面内容。

## 验收清单

- [x] 入口在桌面和移动端均固定于右下角，顶部导航不再承担助手入口布局。
- [x] 面板锚定右下方，尺寸不溢出视口，支持Escape和关闭按钮，焦点返回入口。
- [x] `aria-haspopup`、`aria-controls`、`aria-expanded`与真实开合状态一致。
- [x] 首页、方法库、动态项目档案均可使用，核证据链接保留当前项目。
- [x] 390/360px无全页横向溢出，触控目标至少44px，深浅主题与资源加载正常。
- [x] 078既有回归、首页和079档案回归、全量测试通过，保存截图，未部署生产。

## 实现约束

只调整共享角色入口样式和现有`chrome.js`可访问状态。构建继续由`build_gooddesign_site.py`完成，动态页面复用同一资源。
