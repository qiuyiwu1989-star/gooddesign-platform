# 109: 应用中心桌面控制台视觉

## 要什么

针对 103 在宽屏上内容过窄、卡片模板化、图标与按钮廉价、详情区像后台表单的问题，将 `/inno/apps/` 重构为真正的桌面应用控制台。桌面采用左侧场景导航、中间应用货架、右侧固定应用详情三栏；页面最大内容宽度扩展至约 1680px，卡片和详情在 1440 与 2000px 宽度下都有明确尺度。

## 不做什么

- 不继续使用大号渐变地图、浅色圆点背景或全宽胶囊假按钮制造产品感。
- 不新增评分、进度、头像、假截图或未验证能力。
- 不改变应用、案例、路由、状态与证据边界。
- 不部署生产，不改公共导航信息架构。

## 验收清单

- [ ] 桌面为三栏：场景导航、产品卡网格、固定应用详情；2000px 下不出现超过半屏空白。
- [ ] 产品卡拥有克制的独立色调、明确标题层级、摘要、交付物标签和真实入口，不使用模板化大圆点。
- [ ] 右侧详情含产品头部、行动按钮、元信息、交付物、案例路径和证据边界。
- [ ] 移动端降为单列，分类/搜索/状态可用，点击卡片后定位详情。
- [ ] 保留 `app-workbench`、`app-detail-title`、`app-case-title`、`app-data`、`selectApp` 契约。
- [ ] 2000px、1440px、390px、深色模式与组合筛选验收通过；专项回归通过，未部署生产。

## 实现约束

沿用 GoodDesign 基础令牌；应用色调集中定义，降低饱和度，深浅色保持对比。继续使用 `apps.json` 与 `cases.json`，搜索/场景/状态组合生效。
