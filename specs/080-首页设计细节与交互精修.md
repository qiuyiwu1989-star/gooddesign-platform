# 080: 首页设计细节与交互精修

## 要什么

在069既有GoodDesign UI和造物云离线V2.3基础上，精修`/inno/`首页。保留GoodDesign品牌、真实560项目、搜索筛选、分页、URL恢复、研究状态和深链，不另起视觉风格。

根据用户提供的UI Kit、精致后台与落地页参考，重点改善：字体层级、4/8px间距节奏、发丝边界、连续圆角、内容表面、默认/悬停/按下/焦点/禁用状态、移动端自然操作。

首屏从营销式大标题+厚卡，调整为安静的探索入口+真实精选档案。项目统计独立为轻量信息带，筛选区减少包装，项目卡以真实图像和阅读信息为主。

## 不做什么

- 不改变导航栏目、URL、字段名、项目顺序、分页大小、数据、权限或研究状态。
- 不新增前端依赖、在线字体、图标库、自动轮播、滚动劫持、紫色光晕或装饰动画。
- 不用假截图、虚构项目、伪造数据或AI生成装饰图代替真实封面。
- 不把首页精修自动扩散为全站换肤，不修改生产站点。
- 不删除空、载入、错误、键盘、减少动态、深色和打印支持。

## 验收清单

- [x] 首屏标题、导语、搜索、精选项目与统计形成清晰层级，链接文字无箭头。
- [x] 筛选区轻量化，输入/选择/清除/分页的默认、hover、active、focus、disabled状态完整。
- [x] 无筛选时清除按钮禁用；输入、筛选、清除、空结果、分页、前进后退和URL恢复均真实可用。
- [x] 项目卡图像、奖项、研究状态、标题、摘要和单位层级一致，未知内容不补写。
- [x] 1440、1280、1024、768、390、360px无全页横向溢出，桌面导航单行，触控目标至少44px。
- [x] 浅色/深色对比度满足WCAG AA，键盘焦点清晰，减少动态与减少透明度可用。
- [x] 无浏览器脚本或资源错误，079既有档案回归与全量测试通过。
- [x] 保存修改前后截图、浏览器报告和设计系统变更记录，未部署生产。

只组合现有`portal.html`、`portal.css`、`portal.js`和GoodDesign UI核心。公开类名、表单ID和JS数据绑定保持兼容。`build_gooddesign_site.py`继续作为本地全站构建入口，vendor只读。
