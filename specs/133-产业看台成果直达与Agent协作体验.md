# 133 产业看台成果直达与 Agent 协作体验

## 要什么

- 已有研究成果的地区，从地图、快捷入口或输入框进入时直接打开已有报告，不重复消耗研究任务；只有主动选择“重新研究”才再次运行。
- 运行页从“模型文本流 + 日志”升级为“研究小组 + 思维构成 + 阶段成果”：七个环节各有明确角色、专属视觉和实时状态。
- 左侧角色卡随真实事件更新工作量，资料、假设、企业、需求、候选、方向等逐项出现时数字同步变化并给出轻量动效。
- 中央在等待模型时展示该角色的认知构件如何逐步形成，不展示模型原始 JSON，不用大段文字冒充思考。
- 静态回放与真实 SSE 使用同一事件处理和角色状态；未知工作量不编数。

## 不做什么

- 不把角色化界面宣称为多个独立模型实例；它是同一研究流水线的角色分工视图。
- 不根据等待时间虚构文章数、检索数或完成百分比。
- 不改变证据状态、项目召回、报告结构和推荐恒为空的研究纪律。
- 本轮不做追问、地区比较和独立 PDF 生成。

## 验收清单

- [ ] 玉环/嘉善快捷入口及输入已有地名直接打开报告，不创建 EventSource。
- [ ] 已缓存地区读取失败时不循环打开报告，可显式重新研究。
- [ ] 七个角色具有不同名称、字形/色彩和工作中/完成状态。
- [ ] `activity` 事件使对应角色计数递增；无真实事件时不自动增加工作量。
- [ ] `think` 事件只驱动认知构件动画，不显示模型原始文本。
- [ ] 静态回放完整到报告；移动窄屏无横向溢出；减少动态偏好生效。
- [ ] 构建与 JS 语法检查通过，线上健康检查和已有报告直达通过。
