# 043 资料管家：从人工工作流转向自动整理

## 用户目标
放入资料后由管家持续整理，定期吸收新增内容；人工处理异常和关键判断，而非逐份启动、逐字段批准。

## 本轮交付
- [x] 核实并展示当前自动接收/识别/规则提取服务的运行状态、当前项目队列与异常。
- [x] 明确现有自动处理与尚未接入的语义整理 Agent，避免误称已经全自动入档。
- [x] 固化管家职责、发布规则与后续验收，现有人工工具保留作干预入口。

## 管家完整能力（后续实施，不算本轮完成）
- [ ] 新文件触发任务；按内容指纹和处理器版本去重，合并短时间内的更新。
- [ ] 周期巡检增量/失败任务，重启续跑、有限重试；支持暂停、状态与操作记录。
- [ ] 阅读清洗文本，识别资料归属、实体、事实、证据、AI解读、关系与缺口。
- [ ] 比较已有档案：新增、重复、补强、冲突、撤回分别处理，保留出处与原件。
- [ ] 对符合准入规则的更新自动生成研究版本和可读文档；变更内容可追溯、可撤回。
- [ ] 归属不清、证据冲突、关键参数变更、权属和成果归属争议进入例外队列。
- [ ] 输出每次整理简报；未有实质变化不生成空版本，不每日打扰。
- [ ] 新版本可被MCP读取，旧调用可固定版本；展示文档绑定通过检查的版本。

## 不做什么
本轮不接未配置的大模型，不自动审核现存候选，不改嫦娥事实/55分，不部署公网，不创建Codex定时提醒来代替后台服务。

## 验收
- [x] 状态来自当前服务进程，不把历史心跳当作在线；项目队列不串项目。
- [x] 服务未监听/巡检失败/无任务时文案准确；API无写操作。
- [x] 文件上传、人工核对、发布和原件访问边界不变。
