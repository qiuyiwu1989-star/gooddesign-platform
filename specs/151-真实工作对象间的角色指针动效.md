# 151 真实工作对象间的角色指针动效

## 要什么

- 增加一个明显的角色工作指针，在右侧当前真实工作卡片之间移动。
- 新思考、真实 activity 和阶段工位出现时，指针平滑移动到对应卡片，并显示当前角色。
- 指针是角色分工的可视化，不是用户鼠标，也不代表真实电脑操作。
- 保留卡片内指针、工位动线和路径聚焦；暂停、减少动态和移动端保持自然。

## 不做什么

- 不随机乱跳，不按时间增加工作量，不遮挡阅读。
- 不改变事件、报告或研究数据。

## 验收清单

- [ ] 新事件后指针位置随目标卡片变化，角色标签正确。
- [ ] 工位/思考/成果均能接收指针；移动平滑且不明显遮挡。
- [ ] 暂停时无新目标移动，移动端无横向溢出。
- [ ] 完整回放与既有回归通过。
