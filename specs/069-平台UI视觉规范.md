# 069: GoodDesign UI 长期设计系统

## 要什么

用户明确不喜欢现有设计系统，要求参考造物云并精致化打磨，进一步提出 Apple 级细节与品质，并将造物云持续演进为长期使用的设计标准。

以项目已有的造物云离线 V2.3 为稳定底座，建立 **GoodDesign UI**：统一项目库、方法库、项目档案、需求研究、企业工作台和资料后台的视觉、组件、验收与版本治理。Apple 级精致度是质量要求，不是另起一套短期皮肤。

交付物：

- `03-平台规划/好设计平台设计系统-v3.md`：设计原则、令牌、组件、页面模板、状态和迁移规则。
- `extensions/design-system/`：可复用 CSS、真实组件样板与长期贡献指南。
- `tests/test_design_system_069.py`：静态资源、组件契约和交互钩子回归。

## 不做什么

- 不沿用上一版“创新档案馆”或印章红作为主视觉，不在不同风格之间反复切换。
- 不把 Apple 简化为毛玻璃效果，不照抄 Apple 官方组件或宣称使用其官方 Web 设计系统。
- 不直接修改生产页面、研究内容、URL、权限、模型调用或数据版本。
- 不引入新的前端框架、在线字体、图标包或其他依赖。
- 不在单个页面私改核心令牌，不用假数据证明研究能力。
- 不宣称样板页通过就等于全站迁移或长期 1.0 稳定版已经完成。

## 验收清单

- [x] 以 `extensions/method-workbench/vendor/tokens.css` 和 `design-system.css` 为稳定基准。
- [x] 样板覆盖色彩、字体、按钮、表单、项目卡、方法卡、内容状态、证据抽屉和研究路线。
- [x] 使用真实项目封面、方法图标和真实研究边界文案。
- [x] 1440、1280、1024、768、390、360px 无横向溢出，主要操作至少 44px。
- [x] 主题切换、证据打开/Escape 关闭、路线选择、反馈保存、待确认补充和错误保留输入可实际使用。
- [x] 关键浅色组合对比度满足 WCAG AA，完整状态、减少动态、键盘焦点和打印规则明确。
- [x] 具有连续圆角、精细字体、轻薄材质、自然反馈和柔和层级，而非简单叠加玻璃效果。
- [x] 具有稳定底座/产品扩展/页面组合分层、语义化版本、组件变更门禁和页面采纳流程。
- [x] 规范与项目管理记录不再把上一版方向描述为当前推荐。

## 实现约束

沿用原生 HTML/CSS/JavaScript，直接复用现有造物云 V2.3 离线资产。新样式集中在 `extensions/design-system/`，vendor 只读，不得全局覆盖原站。样板页使用本地真实资产，无网络请求、模型调用或私有原件。

当前为 0.1 候选版本。首个真实页面完成设计、代码、无障碍与浏览器验收后，才能评估是否进入 1.0 稳定线。
