# 065 多Agent资料投递与接收

目标：外部Agent按项目独立收集，root批次核验加工后接入现行研究工作流，不要求重写档案。沿用560项目索引及既有04-深研素材，保豆包原包。

目录：项目/04-深研素材/外部投递/<批次ID>/，批次唯一、禁止覆盖；中央规范/模板/33及98等任务范围从索引选取，不新编ID。

协议v1：batch.json、sources.jsonl、claims.jsonl、queries.jsonl、交接说明.md，以及原件/可读件/图片。JSONL一行一条，UTF-8；摘要与全文、来源陈述与AI、相关技术与实际采用分开。失败和缺口留下记录。

工具：scripts/agent_intake.py init创建一次性目录；validate只读本地文件并输出结构/指纹/引用检查，不能认定内容真实、项目归属或质量80，不抓网页、不改正式数据、不自动审批。空批次不得通过。资源路径必须在批内，无符号链接，不执行附件代码。

验收：全量项目目录就位；可转发任务书/字段例子/模板齐；真实豆包包保留未迁移；合法最小包通过，坏指纹/目录穿越/无引用/摘要冒全文拒；验证前后原件SHA不变。后续root人工/Agent独立核读→native pending→审批→新版发布→导读/评估/MCP测试，原件不自动公开。

Non-goals：不是上传服务、联网采集调度器、全文语义审核器或质量打分器；不回改冻结档案/网站/MCP接口。
