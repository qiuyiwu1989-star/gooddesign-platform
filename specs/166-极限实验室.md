# 166 极限实验室

## 要什么

- 用嫦娥钻取模拟器形成准备、运行、暂停、继续、复位、完成的完整实验流程。
- 提供真实参数控制、月壤剖面动画、过程状态、样芯/风险/能耗反馈和A/B两次实验复盘。
- 保存最近两次实验并可导出设计观察卡，明确教学模拟边界。

## 不做什么

- 不宣称工程精确、专家验证或AI评分，不引入新模型/后端。

## 验收清单

- [x] 转速、进给、冲击影响过程与结果，暂停/继续/复位准确。
- [x] 最近两次结果可比较，刷新恢复，导出参数和边界完整。
- [x] 桌面/移动、键盘、减少动态与资源加载通过。

## 验收证据

线上实测暂停/继续、两次A/B实验、刷新恢复和观察卡导出通过；无脚本异常和资源失败，移动端无横向溢出。
