# 073: 奖项系列图标

## 要什么

为金奖、银奖、铜奖设计不同轮廓的统一图标，并补齐真实项目中的创意奖、提名奖、菁英奖。图标用于项目卡片和奖项展示，保持 GoodDesign 的精致、简洁和可识别性，同时保留文字标签，不只靠颜色区分。

## 不做什么

- 不使用 Emoji、截图或带文字缩写的奖章代替图标。
- 不把创意奖、提名奖、菁英奖统一改叫铜奖。
- 不改变项目事实、奖项字段、生产页面或权限。
- 不用图标大小制造无依据的项目排名。

## 验收清单

- [ ] 六类 SVG 图标轮廓可区分，风格、线宽和视觉尺寸统一。
- [ ] 金奖、银奖、铜奖具有不同星芒/环形/几何章形，其他三类有独立语义。
- [ ] 项目卡片实际显示图标与文字标签，图片资源和移动布局正常。
- [ ] 全站构建包含图标，静态与浏览器回归通过。
