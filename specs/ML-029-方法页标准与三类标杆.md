# ML-029 方法页标准与三类标杆

状态：approved（2026-11-05，用户要求全部完成；本机候选，未发布）

## 要什么

形成可复制的《方法页标准 v1》，完成R17契约工具、R02框架编排、R52定性/定量分级三类标杆资产包，并把方法质量与引擎研究质量评价连接。每个标杆包含内容、Skill、调用、评测、参考回放、版本和质量报告。

## 不做什么

- 不覆盖冻结档案、六契约、原MCP、历史运行和原24报告/48评审。
- 不把教学回放当真实客户应用，不把AI评审当领域专家。
- 不把方法包整体对照归因给R17，不在缺少真实新生成时伪造R17专属性提升。
- 不给R02/R52伪造S2 Schema，不让R52在缺概率时输出数值结论。
- 不批量复制到其余61方法、不部署、不公开私有证据。

## 方法包交付

每方法目录必须包含：

- `asset.json`：身份、类型、能力、版本、质量贡献与资产引用。
- `深化内容.md`：ML-021独立Agent内容候选的原字节副本及SHA。
- `SKILL.md`：按S0/S1/S2生成的使用策略。
- `invocation.json`：统一MCP调用层级、输入、逻辑产物和限制。
- `evaluations.json`：正例、负例、迁移和路由测试。
- `reference-artifact.json`：R17历史Artifact；R02/R52为明确教学产物。
- `reference-run.json`：可复核的回放输入、步骤、结果和边界。
- `quality-report.json`：内容、执行、研究贡献、审核和外部依赖。

R17另保存原冻结`contract.json`；R02/R52的`contract_ref=null`，只能S1引导。顶层目录记录全部文件SHA和生成器版本。

## 标杆要求

### R17契约工具

复用RUBBER-20261026/r1历史Host+MCP产物，合并研究笔记与案例证据回放。核对7功能、28选项、4组合、未知相容性、上游ID、证据解析和R36/R42交接。负例至少包括缺FunctionModel、未知变通过、矛盾组合候选和引用失效。

### R02框架编排

回放40/60教学总量如何改变问题定义，以及同介质交接协议如何保留/排除路线。没有现场材料时只能输出研究计划；新证据推翻问题时必须返回Define，不把四活动当一次性瀑布。

### R52定性/定量分级

用ML-021公开教学数值独立复算R0、RPI、RSI、EVPI、EVSI和净价值；增加跨不过行动阈值的零价值例。缺先验、损失或似然时降级定性，安全必需验证不被经济VOI豁免。

## 引擎研究质量评价

分为四层：

1. 方法单元：内容、契约、计算和负例。
2. 路由：能力、输入、产物与替代方法是否正确。
3. 端到端：同任务、模型、预算下比较研究产物。
4. 真实情境：客户、专家、试验与采用反馈。

R17专属性效果必须比较“相同ProblemBrief/FunctionModel/证据/Schema，是否加入R17资产”两臂。现有ML-024只能作为方法包整体背景，不能替代该实验。
