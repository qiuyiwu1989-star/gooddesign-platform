# 076: 企业创新工作台产品重构

## 要什么

将旧 `gooddesign.qiuyiwu.com/industry-demo/` 所代表的产业演示，重新定义为 `/inno/loop/` 企业创新工作台。服务对象是企业研发负责人、工程师和设计研究人员，核心对象不是演示流程，而是一个持续推进的企业研究任务。

产品定义：围绕真实任务，把需求确认、路线比较、证据核对、验证计划和反馈回流放在同一个工作区，让团队知道当前判断、未知和下一步。

设计读法：高频使用的B2B研究工作台，沿用GoodDesign UI，视觉变化4、动效2、信息密度7。桌面为任务导航、当前工作、研究判断三层，手机自然转为单列。

核心视图：
- 研究概览：任务切换、当前目标、三条候选路线、关键未知和建议下一步。
- 需求与条件：需求来源、确认状态、硬约束、待确认补充及保存记录。
- 路线比较：机制、成立条件、成本未知、约束状态和对应证据；不输出无依据最优。
- 验证计划：竞争解释、观测、判别、停止条件、资源与批准状态；可导出研究交接。
- 反馈与回流：精确绑定需求/路线/主张版本，保存反馈并显示待审核状态。

## 不做什么

- 不做自动演示、模拟进度、节点画布秀或假装实时AI研究。
- 不重新定义另一套后端，不替换ML024需求/路线/行动/反馈真源。
- 不把三条预置路线称企业方案，不把候选资料称为已匹配证据，不自动执行实体试验。
- 不伪造客户需求、预算、阈值、专家批准、云端协作或模型调用。
- 本轮不替换旧生产URL、不改DNS、不执行旧站退役，不公开私有原件或SQLite。

- [x] 反馈精确绑定主张，授权、保存、刷新隔离和失败重试保持原契约。
- [x] 桌面三层/移动单列，键盘、Escape、深浅主题、错误恢复和360px可用。
