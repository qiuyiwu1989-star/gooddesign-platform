# 146 报告历史与独立版本链接

## 要什么

- 每次生成报告都保存为不可覆盖的新版本，同一地方的历史报告全部保留。
- 首页提供“研究历史”区域，显示中文地名、研究深度、时间和数量；可打开任意历史版本。
- 每个版本有独立 ASCII 链接 `?report={slug}&id={report_id}`，二维码和下载 HTML 均指向该版本。
- 地图和已有地名入口默认打开最新版本；旧链接与无 id 链接保持最新兼容。
- 收录只更新对应版本的 curated 状态，不复制或覆盖其他版本。

## 不做什么

- 不删除或改写历史报告；不把历史版本伪装成最新。
- 不使用中文 URL；不改变中文地名展示。
- 不公开原始私有资料，历史仅包含现有公开报告 pack。

## 验收清单

- [ ] 同一地方连续保存两份报告，文件和 report_id 均不同，两份均可读取。
- [ ] 无 id 打开最新，有 id 打开指定版本；错误 id 返回 404。
- [ ] 首页历史区域可打开指定版本，地图仍打开最新。
- [ ] 报告二维码含 slug+id，独立 HTML 保留该链接。
- [ ] 收录指定版本不新增副本；既有交互和 PDF 回归通过。
