无接触扶手消毒环

完成单位
辽宁石油化工大学
主要完成人
郜红合,曾旭,迟钧文,张巍
项目编号
202104317
项目简介 / OVERVIEW

2020年至今COVID-19病毒在全球肆虐，造成了大量的人员死亡，也带来了诸多严重的经济和社会问题。其中公共设施由于使用量巨大且使用频率高，其卫生防疫问题日益受到重视。而各种公共场所的扶手由于巨大的使用量而成为了新冠病毒间接传播的重要载体。但是目前公共扶手的消毒主要采用人工擦拭或者喷洒的方式进行，不能做到全方位消毒且消毒频率和效率非常低下。如何减少公共交通扶手所带来的接触传播便是该设计所解决的主要痛点。

无接触扶手消毒环是一款通过无接触自动消毒的方式来解决公共扶手消毒的清洁消杀设备。无接触扶手消毒环在消毒工作时从启动到结束不需要任何人工肢体的干预接触，均可以通过无线网络进行控制。该设计可自主通过扶手连接处及扶手的弯曲部分，无需使用多个设备或手动操作。该作品可自定义使用频率，实现在如地铁、公交内针对早晚高峰期进行不同的消毒频率调节。

本产品采用非接触式自动消毒设计，主要应用在地铁等公共交通工具的车厢扶手的消毒，考虑到公共场合的扶手的不同情况，本设计尽可能的考虑到使用场景的问题，设计成可以完全自主通过扶手上的诸多障碍实现全自动消毒，可以自由控制消毒频率并大大地减少清洁人员的工作量，为人们的健康出行保驾护航。目前市面上并没有此类产品的使用。

设计阐述 / DESIGN FEATURES

本产品整体类似圆环状，为半包裹式设计，上方留空可穿过扶手连接处并设有挡杆结构防止掉落。 产品内置紫外线消毒设备，透过包裹扶手的内壁的透明窗口进行照射消毒，可通过电控消毒次数频率来保证需求所需。 产品采用分节设计经过扶手弯曲部分时，节与节之间打开间隙通过弯管。

本产品采用了无接触自动清洁的设计，在消毒工作时从启动到结束不需要任何肢体接触。 该作品可自定义使用频率，实现在如地铁、公交内针对早晚高峰期进行不同的消毒频率调节。 该作品可自主通过扶手连接处及扶手的弯曲部分，无需使用多个设备或手动操作。
