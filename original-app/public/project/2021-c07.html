万景号未来邮轮设计

完成单位
武汉理工大学
主要完成人
邹志伟,张文斌,孙京京
项目编号
202104870
项目简介 / OVERVIEW

大型邮轮本身就是高附加值的产物，邮轮外观造型设计是为了在满足大型邮轮的功能需求的基础上进行的创造性活动。随着科学技术的发展以及生活水平的提高，人们对美的追求越发强烈，使得邮轮设计日益成为技术、工艺与艺术、美学相结合的产物。本概念设计目的在于增强外观造型设计在邮轮设计中的话语权。大型邮轮外观造型设计研究的方向不同于传统设计中“技术决定美学”的固有思路，通过对于约束因素的梳理，更好地发挥邮轮美学在其中的作用，促进造型设计师与工程师更好的沟通与合作，提高邮轮设计的效率与质量。万景号是一艘舱室可旋转的邮轮。甲板上共有六栋可以旋转的客舱楼，每一间客舱都是海景房，客人不必烦恼与只能欣赏一个角度的风景，旋转的舱室使得每个客人每天都有新鲜的体验。邮轮的水循环系统使得楼与楼之间产生一道水帘，使得邮轮的美观性和可玩性提升。另外主船体的舷窗排列为莫斯编码的设计。邮轮的海景房能够吸引大量游客登船，但由于邮轮的海景房数量有限，只有少部分游客能够享受随时观看海景的体验，并且传统舱室与陆地的房间区别不大，并不能给邮轮游客带来新奇的体验。该旋转的舱室不仅可以解决海景房的问题，同时可以使整船更具趣味性。虽然舱室结构改变了，但舱室数量并没有减少，而楼与楼之间的空隙也加以利用，弥补公共空间的减少。舱室旋转结构申请专利已受理，结构有实现基础，作为概念设计对未来邮轮发展有一定参考意义。探索更多新颖的海上平台设计。

设计阐述 / DESIGN FEATURES

万景号是一艘舱室可旋转的邮轮。甲板上共有六栋可以旋转的客舱楼，每一间客舱都是海景房，客人不必烦恼与只能欣赏一个角度的风景，旋转的舱室使得每个客人每天都有新鲜的体验。邮轮的水循环系统使得楼与楼之间产生一道水帘，使得邮轮的美观性和可玩性提升。另外主船体的舷窗排列为莫斯编码的设计。船身外观根据特征线确定邮轮的整体态势，态势应相对稳定，因此船首及船尾的交点偏后且较高，可保持稳定的态势；且造型相对来说较为整体，轮廓线高低错落，但整体趋势较为统一，保持了和谐的主题。舰桥及顶层甲板上的建筑部分保留邮轮“反趋势”的造型特征，且后部烟囱采用层叠式与旋转舱房呼应。以及靠近主甲板部分的腰部分割线也带有台阶状转折，并在逐渐消失，具有一定变化的造型，对风格进行强调。
