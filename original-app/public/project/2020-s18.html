新型商用无人驾驶磁浮列车

完成单位
中车株洲电力机车有限公司
主要完成人
郭庆龙,刘国玲,高楠,尹爱平
项目编号
202001221
项目简介 / OVERVIEW

随着我国城镇化加速发展，城市呈现多中心或者放射状发展趋势，卫星城大量崛起，促使城市地域内部、中心城区外围、特定方向上（郊区新城或机场与中心城区之间）大量通勤交通的产生，与此同时，城市圈经济、文化快捷交流需求变得越来越迫切，市域城市之间的联系也更加紧密，在此情况下，新型商用无人驾驶磁浮列车主要承担着中短途旅客高效运输的职能，是为满足城市化快速发展和城市群崛起对城际轨道交通的需求而研制的一种新型运载形式，为区域城市交通提供“绿色、智能”的多元化选择。

新型商用无人驾驶磁浮列车是将现代信息技术、控制技术和传统机电技术融合为一体的先进智能轨道交通系统，保证了列车的整体安全性与可靠性。列车采用4节编组，智能驾驶模式，运营速度200km/h，填补了世界磁浮列车该速度等级领域的空白。整列车载客量可达500多人，较现有中低速磁浮列车载客能力提升超20%，运行中采用车辆、轨道无接触式支撑和主动导向技术，振动小、噪音低、舒适平稳、列车加减速性能好，可实现高密度、公交化运行。

新型商用无人驾驶磁浮列车对于城市环境具有占地少、选线灵活的优势，对线路周边居民及环境影响小，可普遍适用于旧城与新城的衔接，对城市环境适应能力强。同时，磁浮列车的应用不仅创造单列车将近亿元的销售收入，还可带动国内轨道交通产业集群的智能制造、电力电子、网络与自动化控制、材料等多个产业的协同发展。

截止目前，新型商用无人驾驶磁浮列车累计共获专利20余项，其中发明专利12项，实用新型专利7项，外观专利1项，其中长沙中低速商用磁浮列车荣获2018年中国中车集团科技创新进步一等奖。

新型商用无人驾驶磁浮列车的诞生，将为城市轨道交通实现全制式覆盖，打造一小时都市圈，为我国市域交通的发展和为国家新型城镇化的发展做出贡献。

设计阐述 / DESIGN FEATURES

开创高效能的列车智能运维设计

列车牵引与运控系统突破传统车辆安装在列车上的思路，采用由地面牵引供电系统提供驱动力，由地面运控系统对列车控制，突破传统车辆牵引供电系统和运控系统安装在列车上的限制，从而减轻了车辆重量，降低了能量消耗，同时提升了车辆的承载能力和车辆运行的可靠性。列车通过牵引和运控系统可保证高速度通过弯道，可大大提高平均旅行速度，同时加减速性能好，可实现高密度、公交化运行。

列车低速运行时采用第三轨受流供电，高速运行时采用直线发电机感应供电，采用双供电模式，极大提高了能量利用率。双供电模式的切换，不仅扩展了列车运行的速度和范围，为列车速度提升提供冗余空间，同时使列车在高速运行过程中消除了高速受流的阻力和噪声，使列车运行平稳、乘坐舒适。

地面运控系统采用健康管理、在线实时监测技术，实现对车、轨、供电及运控实现全智能故障诊断和预警，使列车的可靠性和可维护性大大提升。同时地面运控系统还可以有效升级，提升列车应用的适用范围。

工业感极强的“钻石”外观设计与轻奢、居享的内饰设计

车辆外观造型硬朗大气，头型“钻石切割”棱角型面造型赋予列车更多的视觉冲击力，车身比例与姿态体现了功能与审美的统一，同时符合空气动力学特性的流线型外观设计，使车辆在高速运行过程中减轻风阻和噪声，运行平稳、乘坐舒适。如火一般热情的中国红涂装搭配金黄色带贯穿车辆，格外醒目。

内饰轻奢风格设计，内饰乳白色加以天蓝色点缀，墙板采用布艺纹理材质装饰，营造乐享、温馨的家居环境乘坐体验。乘客座椅通过人机舒适性分析与验证，应用绒面布艺包覆，采用红色和黑色的撞色设计，带来视觉冲击力的同时，提升内饰的美观性和科技感。

绿色、经济、节能的新技术组合应用

通过采用以碳纤维、复合材料和镁铝合金为代表的轻量化新材料和车体部件应用轻质高强度 “三明治夹层”符合材料激光焊接和铆接结构等轻量化新技术。通过模块化设计，不仅大幅提升工艺装配效率，降低装配差错率，方便检修维护，同时从而保证更大的载客量，整列车载客量可达500多人，较现有磁浮列车载客能力提升20%。
