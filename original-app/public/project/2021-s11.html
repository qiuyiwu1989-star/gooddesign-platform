首台国产712m水头敦化抽水蓄能机组研制

完成单位
东方电气集团东方电机有限公司
主要完成人
刘冬,骆林,郑津生,荀洪运
项目编号
202101078
项目简介 / OVERVIEW

抽水蓄能具有调峰、调频、调相、储能、系统备用和黑启动等“六大功能”，在保障大电网安全、促进新能源消纳、提升全系统性能、助力乡村振兴和经济社会发展中发挥着重要作用，是以新能源为主体的新型电力系统的重要组成部分。

敦化抽水蓄能电站，是我国首个独立研发、设计、制造、调试、运行的700m以上水头段大容量抽水蓄能电站，东方电气集团在20余年抽蓄机组科研、设计、制造、建设和运行经验的基础上，总结了过往的经验，投入大量精力，创新技术方法，提出先进设计理念，创造了电站长期安全稳定运行的先决条件。

敦化电站为国内首个额定水头达到700m级别，转速500r/min的大型抽蓄项目，水泵水轮机结构受力达到12MPa级，奠定了高水头水泵水轮机的结构设计基础。机组容量完成从传统常规单机300MW向350MW的突破。转子每极容量也在国内率先完成了单极30MVA的突破，为后续更大每极容量的抽蓄项目开发，奠定了通风冷却、转子可靠性等方面技术基础；另一方面，定子电负荷水平达到了893A.4/m，率先达到了900A/m级，为研制更高电负荷的机组拓宽了电、磁负荷选取及其相互匹配的思路。后续的长龙山、洛宁、平江等电站与敦化项目非常相似，敦化抽蓄机组的设计研发对这些电站具有重大的指导意义。阳江和天台这两个400MW级别的电站，其设计研究也需要借鉴敦化项目的设计成果。

通过多年的设计研发，东方电机独立研制成功具有自主知识产权的“712m水头敦化抽水蓄能机组”研制，形成了水力研究、过渡过程计算、结构静力学、结构动力学、振动分析、疲劳计算、电磁计算、通风研究、绝缘设计等多项达到或超过世界先进水平的核心技术创新成果。产品性能达到国内领先、世界一流水平，机组首台机已于2021年6月4日投入商业运行。

设计阐述 / DESIGN FEATURES

敦化抽水蓄能电站位于吉林省敦化市北部小白林场，距敦化市直线距离约70km，距吉林市120km，距长春市220km。电站总装机容量1400MW，装机4台，单机容量350MW。

敦化抽水蓄能电站是我国重型装备制造行业坚持自主创新的一个成功典范，该机组的成功研制离不开创新设计，以下将从新能源发展、智能制造、同创文化三个方面详细介绍该机的创新设计特点。

一、助力新能源发展，支撑“碳达峰、碳中和”

近年来气候问题日益突出，世界各国将大力发展新能源作为应对气候变化、保障能源安全、推进能源转型的重要抓手。在碳达峰、碳中和目标下，我国新能源将迎来跨越式发展。经测算，零碳情境下，预计2020~2030年我国新能源发电装机年均增长1.1亿千瓦，2030年总量将达到16.5亿千瓦。为保障新能源电量消纳和电力系统安全稳定运行，抽水蓄能亟待优先发展。在此背景下，首台国产712m水头敦化抽水蓄能机组研制成功，将从根本上保障和促进抽水蓄能的可持续发展，助力我国碳达峰和碳中和目标的实现。

敦化抽水蓄能机组是在东方电机20余年抽水蓄能电站科研、设计、制造、调试和运行经验的基础上，总结前期抽水蓄能电站经验，研制而成的首台国产700m以上水头抽水蓄能电站，代表着国产高水头、大容量、高转速抽水蓄能机组的最高水平。

敦化抽水蓄能机组摆度，瓦温、振动等关键指标全面达到精品标准要求，实测的关键数据都达到了国际先进水平。由于振动和摆度得到了有效控制，尤其是上导、下导、水导摆度均在0.1mm以下，让超高水头抽水蓄能电站稳定性设计标准迈上新台阶，进入新时代。

在敦化项目之前，国人从未从事过700m以上水头的抽水蓄能机组设计。该机组的研发技术一直属于中国的“卡脖子”技术。

水力研发方面的难点：敦化机组是国内首个700m以上水头的抽水蓄能机组，在此之前从未进行过该超高水头段的技术研发。该项目自主研发工作的难度和复杂性都是空前的。特别是在抽水蓄能机组核心技术攻关的水力研发阶段，遇到了一系列从未遇到过，甚至没有听说过的技术难题，研发方案进行了多次调整和反复。研发团队开发了数十个水力设计方案，通过多轮次优化和多方案比选，在多个关键技术领域进行了大胆创新，如小“S”曲线、大“S”曲线、压力脉动、驼峰曲线……一道道从未遇到的难题被攻克，一个个关键技术屏障被突破，团队研制的最终方案于2016年9月在第三方试验台上顺利完成验收。国网新源敦化抽蓄公司组织的验收专家组评价敦化机组综合性能达到世界先进水平。

结构设计方面的难点:与常规水电机组相比，抽水蓄能机组最主要的特点是：每极容量大、水头高、转速高、启停频繁、正反转、运行工况复杂，操作设备复杂，机组不仅要承受高转速下的高负荷，而且要承受启停、正反转过程中的交变负荷，工况转换中的冲击负荷，其在电气、机械、热学性能方面要求更高，对于敦化抽水蓄能700m以上超高水头，350MW大容量的抽水蓄能机组，难度系数甚至超过巨型水轮发电机，是水电行业中要求最高的产品之一。

机组在整个设计过程中采用了三维模型设计，通过将三维设计进行网络共享，可以模拟加工，装配过程，指导现场安装调试，提升制造和装配效率。例如敦化抽水蓄能电站在顶盖安装过程中，由于螺栓预紧力较大，预紧后会造成顶盖下沉，公司提前用三维计算模拟真实状态下顶盖预紧下沉量，将模拟下沉量提前反馈给现场，现场根据三维计算模拟量来指导现场安装过程，实际安装顶盖过程一次性成功，极大缩短了安装成本，节约了时间成本。

同时，通过公司的产品生命周期管理系统，实现了设计与制造过程之间的信息交互，包括制造成本信息，为设计人员提供了更多的设计依据，在保证产品设计可靠性的同时进一步提升了产品设计的经济性。

三、树立“同创文化”，提升设计创新水平

东方电机秉承的“同创”文化，凝聚了一代代东方电机人的优良传统和集体智慧，通过互联网的资源共享，将水力机械工程、电气工程、机械工程、高压技术、热能与动力工程、人机工程等专业领域进行了整合，实现了各领域、多学科交叉融合的协同创新设计，获得了大批发明专利。

敦化抽水蓄能电站机组研发首次对水泵水轮机转轮3D打印技术进行了研究，并成功应用于模型试验中。该技术将3D打印制备地转轮与连接组件组合成的复合装配结构安装到水轮机上，测量其水力性能，并与采用金属加工的转轮的水力性能参数进行对比，得出3D打印转轮模型工况试验的试验条件，该方法可以保证转轮试验的安全性，同时兼顾试验精度，满足IEC规程要求，不仅大大缩短了研发周期，而且很大程度上节省了研发成本。获批一项发明专利“一种3D打印水泵水轮机转轮模型试验方法”。

敦化抽水蓄能电站首次发明了一种适用于超高水头水泵水轮机的高压管路连接结构，此结构不仅保证了新结构的易拆性，而且通过环形卡环设计，让管路的径向水流和周向振动均由法兰和顶盖本体限位，可靠程度高，且卡环和卡槽之间留有一定的缓冲间隙，这样既能保证管路的柔性连接，又可以限制管路的位移。这种高压管路连接结构完全解决了以往电站高压管路频繁开裂，振动较大的设计难题。获批一项发明专利“一种水泵水轮机顶盖高压管路连接结构”。

敦化抽水蓄能电站的发电电动机推力轴承设计采用非浸泡低损耗推力轴承技术，突破了传统的全浸泡运行机理，将润滑油液位降低至滑动旋转面以下，从根源上消除了润滑油的搅拌问题；采用喷淋方式直接润滑推力轴承瓦，提出了少润滑介质条件下提高轴承油膜安全裕量的方法，促进了高效清洁轴承的技术新发展。获批一项发明专利“一种降低组合推力轴承搅油损耗的方法”。

除上述简述的研究以外，还有许多方面的研究已发表论文或获得专利。创新成果人人共享，这个成果包含了技术专利等技术创新成果，还包含人才培养成果，在敦化抽水蓄能机组研制过程中，培养了和造就了一大批水电行业的技术专家，为今后我国抽水蓄能事业的发展储备了强大的后备力量。

综上所述，以助力新能源发展为出发点，借助智能制造这一工具，秉承了东方电机的同创文化的精神，才有了今天的国产首台712m敦化抽水蓄能机组的成功研制。
