一次成型纺织双面数码印花机

沈阳飞行船数码喷印设备有限公司

王辉,梁健,陈军,王军,于涛,陈艳艳,陈艳君,李捷新,喻晓兵

项目简介 / OVERVIEW

数码印花技术的不断发展和完善，为印花行业的产业转型和技术升级带来了机遇和挑战。纺织品单面数码印花存在正反色差大、露白、翻丝等问题，因而双面数码印花技术逐步得到开发和应用。双面数码印花存在几个关键性难题：（1）前后面料形变量大，花型无法准确对位；（2）现有数码印花及其配套工艺，难以满足双面数码印花需要严格控制纵横向渗透、控制搭色和沾色等要求；（3）图像识别系统识别精度偏低，对位过程需要人工干预等问题导致正反对位精度稳定性差。

项目采用一次成型双面数码印花技术方案，突破了织物变形大、图像识别精度低及稳定性差、无识别数据的图像难以自动跟踪对位等难题，主要技术创新成果如下：（1）开发了一次成型双面数码印花设备及其在真丝绸上的应用技术，研制了同步双面打印结构与系统，实现在织物不同位置的正反面同步打印。（2）研制了织物恒张力控制系统和图像调整自动对位技术，实现一次成型双面数码印花的稳定、自动、精准对位；（3）创建了图像智能识别软件及AI图像模糊识别技术，通过对图像识别大数据进行学习，优化AI模拟曲线，计算无法识别图像的偏移值，解决无识别数据图像难以自动跟踪对位问题，实现正反两面图案的智能、精准、稳定对位。

项目已获PCT专利1件，国内发明专利6件、实用新型专利1件，国际发明专利3件，软件著作权10件。项目主要技术指标达到任务书要求。经鉴定委员会专家评定，研发的一次成型双面数码印花设备达到国际领先水平。

项目已建成年产50台套、年产值10000万元规模的设备装配生产能力；建成双面数码印花加工年产能36万米、面料及服饰产品年产值14000万元规模的双面数码印花生产线；设备已出口意大利、日本、韩国等国家，经济与社会效益显著。

项目技术填补了数码印花领域的空白，形成了一次成型双面数码印花设备及精准对位双面数码印花产品的生产能力，促进了数码印花技术的转型升级，提升了我国在数码印花装备及印花技术的自主创新能力和国际竞争力。

设计阐述 / DESIGN FEATURES

主要科技创新

1
立项背景：

数码喷墨印花作为一种新型的印花工艺技术，省去了制花版（网）、调色浆、废浆处理等过程，具有小批量、个性化、多品种、高品质、反应快等优点，正逐步成为纺织品印花未来发展方向。当前印染行业处于产业转型和技术升级的关键时期，随着传统印花行业向数码印花行业递进的同时，双面数码印花以特有的技术手段，可更好地展现产品设计意图，实现不同于其他印花方式的独特设计风格，而且可有效解决单面数码印花正反色差大、露白、翻丝等缺陷。

然而，常规双面数码印花技术存在织物变形大、图像识别精度低及稳定性差、无识别数据的图像难以自动跟踪对位印花等问题，极大地限制了双面数码印花技术在纺织行业的发展。双面数码印花无论是设备制造还是工艺应用，都存在不少亟待解决的问题。

本项目采用一次成型双面数码印花技术方案，突破了双面数码印花技术中织物变形大、图像识别精度低及稳定性差、无识别数据的图像难以自动跟踪对位印花等难题，达到了一次性在织物正反面对应位置进行数码印花的智能双面花型精准对位，是对单面数码印花工艺的技术革命。

2
问题的提出

第一，二次双面印花方案，织物第一面打印完成后烘干收卷，再安装到设备上对另一面进行打印，第一面印花后织物变形量特别大（5-8mm）。

第二，二次双面印花方案，织物第二次安装时，无法控制走偏量和织物张力，导致双面对位过程需要人工干预，对位精准度低，对位误差大于0.3mm。

第三，二次双面印花方案，针对小色差、大弧线等无法识别图像依靠人工判断，手工输入对位参数，对位精度特别低。

实用新型专利1项：一种导带式同步双面喷墨印花系统，ZL 201721034920.0

纺织品经过上浆、喷印、烘干、收卷等数码印花工序后，都会产生明显的变形量（一般在5mm-10mm左右），本项目开发了同步双面打印结构与同步双面打印系统，将第一打印小车打印后的织物变形量控制在3mm范围内，大大提升了第二打印小车对织物另一面进行对位印花时的精准度和稳定性。

如图1.1所示，同步双面打印结构采用两套打印小车，两套打印小车同步进行，织物在第一打印小车与第二打印小车之间实现正反面翻转，第一打印小车对织物的一面进行喷印，形成第一打印图像；第二打印小车同步对织物的另一面进行喷印，形成第二打印图像。进一步在第一打印小车与第二打印小车之间设置第一、二烘干装置对织物的第一打印图像面进行烘干，进而使得翻转后第一打印图像不返沾到导带上；同时，在第二打印小车与收布辊之间设置第三、四烘干装置对织物进行烘干，防止打卷后沾色，进而实现一次成型同步双面数码印花。

图1.1 同步双面打印结构

在同步双面打印结构下，两个打印小车的打印位置存在物理距离，因此，第一打印小车与第二打印小车的打印内容是不相同的，为此进一步开发了同步双面打印系统。第一打印小车和第二打印小车在Y方向的距离参数称之为辊间距，在X方向的距离参数称之为原点调整值。辊间距参数的设计标准为2600mm ± 50mm，原点调整值的设计标准为8mm ± 2mm。设备出厂前通过实际打印，对辊间距参数与原点调整值参数进行实际测量。

一次成型双面数码印花设备实现了对位精准、图案清晰的真丝绸双面数码印花产品的开发。

2.1 织物恒张力控制系统

在同步双面打印模式下，织物送布的恒张力控制非常重要，如果第一传动装置与第二传动装置不能执行同步送布效果，或者没有考虑织物本身存在的张力变化，织物在打印过程中都会出现过紧或过松状态。织物恒张力控制系统由第一送布辊和第二送布辊组成第一送布装置，由送布导带组成第二送布装置（如图2.1所示），通过两个步骤实现织物的恒张力送布效果，有效控制了送布过程中的张力，减少织物形变量，提升对位精准度和稳定性。

第一步：测量基础张力参数。在传动装置空载的条件下，张力系统根据设置的传感器自动测试出两套传动装置的送布步长是否存在误差，修正误差后获得每台设备的基础张力参数，使两套传动装置物理上实现同步长的送布结果。

第二步：针对不同织物设置张力参数。安装好织物，连续打印步进测试图，通过电子放大镜测量第一打印小车与第二打印小车步进误差的变化规律，如果误差为正数（分离状态）则缩小张力参数值，如果误差为负数（重叠状态）则加大张力参数值，直到步进误差小于0.1mm。

图2.1 织物恒张力控制示意图

织物安装在放布辊上，经过第一送布主动辊、第二送布主动辊、送布导带后实现送布效果。恒张力控制系统的作用就是保证第一送布辊、第二送布辊和送布导带驱动辊始终保持一个恒定、同步的送布状态。

2.2 图像调整自动对位技术

织物经过第一打印小车后仍然存在一定量的形变，导致第一打印图案发生不规则变形，如果不对即将打印的第二打印图案进行调整，无法实现精准对位。如图2.2所示：红色图像是没有经过调整的第二打印图案，文字和线条都没有变形。灰色图像是第一打印图案的采集图像，是织物变形后的图像。可以明显看出没有调整的第二打印图案与第一打印图案无法精准对位。

图2.2未调整时的对位情况

项目开发了图像调整自动对位技术，通过图像智能识别技术获得第一打印图案的偏移值后，图像调整系统对第二打印图案的打印数据进行调整，改变第二打印图案的形状，使第二打印图案与第一打印图案可以重合。

图2.3利用图像调整自动对位技术后的对位情况

如图2.3所示：红色图像是第二打印图案，虽然文字和线条都已经变形，但第一打印图案的灰色采集图像，已经被第二打印图案的红色打印图像完全覆盖。可以明显看出在图像数据调整后，第二打印图案与第一打印图案完全重合。

织物变形量与喷墨量有关，喷墨量越大的区域变形量越大，因此，第一打印小车完成喷印后，织物易发生不稳定形变，进而导致连续打印时第二打印小车喷印时易使得双面印花对位偏移量发生实时变化。图像智能识别技术及AI图像模糊识别算法，能够智能识别打印图像的偏移量，实现无人值守的全自动双面印花过程，减少了人工干预，提高了印花效率。

3.1 图像智能识别技术

在第一打印小车喷印完成后，在织物背面、第二小车上设置图像采集装置，采集第一打印小车喷印后渗透到织物背面的图像数据。系统通过比对采集图像（图3.1）与第一打印小车喷印的原图（图3.2），计算获得图像偏移值。图像识别过程：对采集图像和原图进行区域划分，通过特征点匹配、模糊匹配、边缘识别、色差判断等图像识别技术，获得每个区域X、Y方向偏移值，然后再通过数字滤波技术对可能产生的误差点进行修正。

3.2 AI图像模糊识别算法

印花图案千差万别，很多情况系统无法通过图像比对得到图像偏移数据，比如：小色差图案、大弧线图案。项目开发了AI图像模糊识别技术，有效解决了无法识别图像难以获得变形偏移值的问题。主要通过两个步骤来解决：第一步，通过AI学习程序获得模拟曲线。每个图像对应60000个数据，通过大数据分析获得织物变形规律。进一步对1000万个类似的大数据进行分析，通过学习找到最优的AI模拟曲线，模拟出织物的变形规律。第二步，计算无法识别区的模拟数据。系统根据AI模拟曲线和已知的可识别数据，计算出无法识别区的变形偏移值。

通过上述方法实现了图像的AI模糊识别，进而提升了无法通过图像比对得到图像偏移数据的印花产品的对位精准度，实现了一次性在织物正反面对应位置进行数码印花的智能、精准对位。

设备技术指标

（1）机器应有介质烘燥功能；

（2）机器应有导带纠偏功能，导带跑偏量≤2mm；

（3）系统连续工作7h，累积工作20h，不应有漏墨现象；

（4）喷头工作面和导带工作面距离偏差≤0.5mm；

（5）各喷印线间的成行度≤0.07mm；

（6）各喷印线间的成列度≤0.07mm；

（7）相邻喷印行图案拼接精度≤0.03mm；

（8）喷印图案双面印花对位精度≤0.2mm；

（9）印花速度大于30米/小时；
