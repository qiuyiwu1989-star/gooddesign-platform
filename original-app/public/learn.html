LEARNING PATH

三步完成一次好设计学习

不把拆解实验室、互动乐园和课件当作三个分散入口，而是组织成一条从观察到迁移的学习流程。

01 / 看懂结构

拆开一件好设计

从部件、结构、图纸和热点说明进入展品内部，理解它如何把极端任务变成可运行系统。

学习目标：看见系统构成，而不是只记住装备名称。
进入拆解实验室 → 02 / 玩懂权衡

调参数，观察结果

通过模拟、拼装、问答和挑战，理解速度、能耗、风险、可靠性之间的设计取舍。

学习目标：把“厉害”转化成可解释的设计判断。
进入互动乐园 → 03 / 教懂原理

生成一节课堂任务

把展品连接到力学、热学、电磁、材料、控制等知识点，形成可讲、可做、可评价的课程包。

学习目标：把展馆参观变成可带走的学习成果。

CLASS FLOW

一节课如何展开

以当前展品为主线，课程不是从知识点硬讲起，而是从真实任务和设计矛盾切入。

01 / 导入问题

为什么不能失败？

从深海、高速、能源或深空任务切入，让学生先理解真实约束。

02 / 观察结构

系统由什么组成？

进入拆解实验室，看部件、结构、材料和控制如何协同工作。

03 / 互动实验

参数改变会怎样？

在互动乐园调整策略，观察效率、风险和稳定性的变化。

04 / 表达迁移

还能用到哪里？

生成设计观察卡，把原理迁移到生活产品、产业场景或创新方案。
