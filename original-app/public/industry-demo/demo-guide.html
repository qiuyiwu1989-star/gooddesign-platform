User Journey

USER JOURNEY

让企业带着问题进来，带着课题出去。

以双环为例，把企业关心的“准不准、有无依据、能否改条件、下一步怎么做”组织成一条可体验的研究流程。

体验主线：建立信任、发现相关性、参与判断、沉淀行动。

01产业演示

确认双环画像，展示 01 到 05 的流水线。

 02证据看台

说明案例为什么被选中，边界在哪里。

 03现场 Agent

输入约束，生成一轮可回看的研究分析。

 04创新工作台

把研究分析沉淀成节点化创新课题。

交互设计原因

企业用户不是来浏览案例库，而是带着业务压力来判断平台是否真的懂产业、能否给出可追溯建议。

所以流程要回应四个疑问：你了解我吗？为什么推荐这些案例？我能不能加入自己的约束？最后能不能变成下一步工作？

用户视角的四个关键问题

01 / 信任

你真的了解双环吗？

先展示双环公开画像、机器人传动关联和资料边界，明确哪些是公开资料，哪些还没有企业确认。

确认企业画像

02 / 相关

这些案例和我有什么关系？

围绕企业问题筛出证据，并把档案事实、平台解读、迁移假设分层展示。

查看证据看台

03 / 可控

如果补充约束，结论会变吗？

现场加入约束，平台需要说明哪些建议保留、哪些调整、哪些暂缓。

进入现场 Agent

04 / 落地

这能变成下一步工作吗？

保存为创新课题，保留问题、证据、假设、未知项和最小验证计划。

进入创新工作台

明天推荐路径

  1. 从产业演示进入，确认双环公开画像和资料边界。
  2. 打开证据看台，筛选“工艺升级”，重点讲 2025 金奖项目与精密齿轮抛光的关系。
  3. 进入现场 Agent，使用默认问题，并补充约束：不能改变现有热处理工艺；先评估小批量试验投入。
  4. 保存为课题，进入创新工作台，展示节点画布、证据快照、原始分析、验证计划和待企业确认项。

一句话讲法

好设计平台不是让企业看获奖案例，而是把真实项目里的创新机制，转化为企业可以讨论、筛选和验证的创新课题。
