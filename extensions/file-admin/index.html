选一份你想整理的资料

也可以先回到文件列表，点击文件旁的“整理入档”。

这个按钮会做什么？

有文字的资料直接提取；需要识别文字的扫描件先识别，再提取。当前自动识别文献编号、专利公开号和完整摘要中的问题、方法与结果。图片含义、复杂表格等内容仍需研究人员补充。

提取结果都需要人确认，不会自动改动档案。
