## 可用能力

按已有项目切换，查看文件表、搜索及分类/格式/状态筛选；批量选择或拖放本地文件；输入公开URL保存网络响应；自动接现有清洗管线；查看来源信息、文本定位和PDF按页图像；下载原件/清洗文本/元信息；查看后台任务与失败重试。

原件保存于私有项目库与投递箱；来源版本/哈希沿用管线。任务记录在 `04-知识库/项目库/.file-admin/jobs.json`。进程停止后未完成的任务标中断，人工重试；不宣称开机运行或云端常驻。

本地上传最多30MB；未知格式保留原件并标待处理。网络PDF即使返回通用文件类型，也通过PDF头识别；其他不支持的网络格式以原始字节文件保存，不宣称完成语义清洗。

来源说明只保存线索与阅读索引，不代表已取得全文；下载、文字提取、研究核读和事实审核分别记录。重复字节复用已有来源；显式重试转换留新版本。没有删除/覆盖已存原件的入口。

## 运行边界

单用户、本机127.0.0.1，Host/Origin/CSRF校验，无CORS。原始HTML只作为附件下载；预览用安全文本或PDF渲染图像。接口只定位已登记的来源，不允许任意磁盘文件。不要直接暴露到公网；尚无多用户登录、云端授权或审计发布系统。

无需将私有库复制到公开网站；8775为读者预览，8776为私有文件管理。未接外部LLM自动深研/事实审核；038已有本机OCR、候选审核与只读MCP，详见上方说明。

## 044 资料管家（2026-10-22）
统一服务启动时同时运行SQLite持久资料队列。新增上传/网络保存/投递箱文件进入队列；已存在资料启动时不全量重跑。任务按指纹去重，租约过期可恢复，错误最多尝试3次；暂停、恢复可用下方CLI。当前自动发布限已登记文献编号与外部Agent提交的证据候选；归属/权利状态、关键数值、事实冲突与清空操作保留例外，不等同专家审核。

```sh
.runtime/pipeline/bin/python scripts/archive_steward.py status 2015-02
.runtime/pipeline/bin/python scripts/archive_steward.py pause
.runtime/pipeline/bin/python scripts/archive_steward.py resume
.runtime/pipeline/bin/python scripts/archive_steward.py submit 2015-02 --file output/research-batches/044/2015-02-first.json --actor 'Codex研究Agent'
```

Agent提交JSON含project_id与candidates列表，每项沿用research_workflow.propose字段，必须引用本项目已入库source_id/chunk_id/quote；AI内容另标content_nature及conditions/limitations。不要把任意上传文件当Agent指令执行。深度研究当前由外部Codex会话阅读和提交，后台没有内置通用推理模型。浏览器可看管家任务摘要和已发布研究档案；新项目/dossier/自动读取研究版本，嫦娥保留人工整合标杆。

自动发布只选本任务通过检查的候选，不夹带其他人工已批准项。来源原件与旧版保留；新记录多字段发布按同一发布前快照校验，自动审核身份单独记录。资料下载现已迁移到同一SQLite持久队列（044d），保留旧jobs.json历史记录。

044b：Deep Research下载也可进入持久队列：
```sh
.runtime/pipeline/bin/python scripts/archive_steward.py fetch 2017-01 --url 'https://example.org/article.pdf' --title '已确认的资料标题'
```
成功下载后自动排入文字处理；URL仍按公网检查并校验重定向，下载失败最多3次，原UI下载入口现与CLI共用持久队列（044d）。`source_reclean.py 项目ID 来源ID`可为HTML增加保留单元格边界的清洗修订；原件、旧块与已发布版本均保留，指针提交中断可恢复。图片表格不能通过HTML单元格修订自动还原，需另取图片、OCR与视觉对照。此轮取芯器表1即属图片表格，已另存图像和逐行数据，未把粘连文本猜成列值。

### 044d 页面下载持久化
“保存网络文件”和CLI现在共用SQLite下载队列。`/api/jobs`合并历史任务和持久下载记录（ID为`steward-数字`）；新下载不再依赖线程池jobs.json。服务重启后继续排队或恢复过期租约；同项目同URL字符串即使标题或处理器版本变化也复用原任务。下载失败最多自动尝试3次，之后用户可在任务进度显式重试，旧失败状态保留于controls日志；不会通过重复提交URL无限重跑。历史任务不批量回放。

下载完成只表示原件已保存，文字识别、深度阅读和研究入档是后续独立步骤。队列暂停为全库设置，上传原件仍可接收；正在执行的工作先结束。页面折叠区可暂停/恢复与查看操作记录。深度研究仍依赖外部Agent证据提交，后台未内置推理模型。

同一论文的HTML和关联PDF均归论文类别。图片提取脚本支持主文献与关联PDF，并可用`run(pid, source_ids={...})`限制本次处理来源；提取图保留PDF页码、哈希和父来源。出版商标识/期刊封面等应留存为公共资料，不计项目工程配图。保存原件与自动转换不会提升专家审核或质量分。

### 044e 版本绑定的阅读导读
新研究档案提供八模块短导读、记录索引与具体待补项，默认模块仍收起。导读是明确标记的AI阅读辅助，不写入事实字段，也不增加质量分。私有保存位置为`项目/研究工作区/阅读导读/research-N/导读版本/`，含JSON、Markdown与manifest；先校验档案哈希、八模块、记录引用，再以原子目录发布，禁止覆盖既有版本。不同研究版本不自动继承导读，旧版可固定读取。

`gd_project_overview(project_id, revision=None)`现附`reading_guide`；`revision`可固定旧研究版本，导读仍标AI性质。资料数量额外声明是当前归属规模，不伪装成旧版来源快照。工具总数仍为11。网页可下载绑定的Markdown导读；下载接口只允许已校验项目、研究版及导读版，不开放任意文件路径。格式错误或指纹不符时不展示导读，原档案仍可阅读。

### 044f 任务归属与同篇文献
管家每15秒核对有任务项目的现行归属。尚未完成的来源/下载任务若不再属于本项目，进入`scope_hold`，SQLite保留原状态/结果/失败原因及操作审计；归属回到本项目后恢复原状态，不直接标完成，也不重放完成记录。处理前另做一次归属核对；巡检不抢走正在运行的任务。状态GET不改变任务。

同篇文献的HTML/PDF显示相同论文/专利编号及实际格式，保持各自处理和核读状态。HTML已读不等于PDF公式和附图已核完，关联本身不会提升核读等级。资料改变归属不删除原件、候选或历史发布版。

### 044g 编号规则v2
提取器标识为`conservative_rules_v2_identity`。主文件及关联HTML/PDF解析至同一文献ID；已索引专利只提取清单指定的本件编号，不将封面上的对比专利号填到本件。自动登记DOI还须与清单或已发布字段一致；未知身份留给Agent。

后台可关闭旧DOC占位中已被标准记录收录的同值编号。前提包括本项目有效证据、明确文献身份、同字段同值与已发布版本。关闭记录标`reviewer_kind=rule`、保留原候选/证据和对应研究版本，不改变发布数据或评分；不同编号、同族线索、过时证据及人工决定不自动处理。任务只有全部例外被此规则解决才移出需判断；核读范围独立。

单个项目巡检异常会持久留在settings中并显示维护提示，不阻塞其他项目的队列。修正登记后会自动重试。调试错误只保存在本地记录，不直接把内部路径展示给页面。
