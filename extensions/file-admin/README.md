入口：http://127.0.0.1:8776/?project=2025-00 。依赖见 requirements-file-admin.txt。

## 038 可运行研究管线

## 可用能力

按已有项目切换，查看文件表、搜索及分类/格式/状态筛选；批量选择或拖放本地文件；输入公开URL保存网络响应；自动接现有清洗管线；查看来源信息、文本定位和PDF按页图像；下载原件/清洗文本/元信息；查看后台任务与失败重试。

原件保存于私有项目库与投递箱；来源版本/哈希沿用管线。任务记录在 `04-知识库/项目库/.file-admin/jobs.json`。进程停止后未完成的任务标中断，人工重试；不宣称开机运行或云端常驻。

本地上传最多30MB；未知格式保留原件并标待处理。网络PDF即使返回通用文件类型，也通过PDF头识别；其他不支持的网络格式以原始字节文件保存，不宣称完成语义清洗。

来源说明只保存线索与阅读索引，不代表已取得全文；下载、文字提取、研究核读和事实审核分别记录。重复字节复用已有来源；显式重试转换留新版本。没有删除/覆盖已存原件的入口。

## 运行边界

单用户、本机127.0.0.1，Host/Origin/CSRF校验，无CORS。原始HTML只作为附件下载；预览用安全文本或PDF渲染图像。接口只定位已登记的来源，不允许任意磁盘文件。不要直接暴露到公网；尚无多用户登录、云端授权或审计发布系统。

无需将私有库复制到公开网站；8775为读者预览，8776为私有文件管理。未接外部LLM自动深研/事实审核；038已有本机OCR、候选审核与只读MCP，详见上方说明。

## 项目归属与项目检索（036）

项目选择支持名称/编号/完成单位关键词，以及年份、奖项组合筛选。年份与奖项来自原库题录，不代表重新核验；筛选不会自动改变当前项目，选中结果才切换。

资料区分“本项目资料 / 公共参考 / 待确认归属 / 归属调整记录”。当前项目可以包含标明用途的技术参照或团队背景，不能把其他项目成果当作自身资料。归属依据在私有项目`资料归属.json`，归属历史在`归属版本/`；图片继承父资料，人物综合报道的新配图进入待确认。
