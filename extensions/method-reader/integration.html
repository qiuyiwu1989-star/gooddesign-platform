复制配置，接到你的Agent

下面是本机stdio配置，需MCP客户端支持该配置格式。其他电脑请替换绝对路径，并安装项目固定运行环境；这不是公开远程服务，也不会替你写入全局设置。

{
  "mcpServers": {
    "gooddesign-methods": {
      "command": "/Volumes/邱懿武/邱懿武认知大脑/好设计平台/.runtime/pipeline/bin/python",
      "args": [
        "/Volumes/邱懿武/邱懿武认知大脑/好设计平台/scripts/method_engine_incremental_mcp.py"
      ],
      "env": {
        "METHOD_ENGINE_DB": "/Volumes/邱懿武/邱懿武认知大脑/好设计平台/output/method-workbench-private/engine.sqlite"
      }
    }
  }
}

上述可选增量入口共20个工具；原method_engine_mcp.py入口仍是18个。现有模型调用依赖本机已配置的Codex服务与额度，不包含在纯规则检查内。

调用边界

semantic_match、propose_artifact、review_artifact及两个增量生成工具会调用真实模型、消耗额度；propose默认允许一次修复，需单次调用可传max_repairs: 0。生成结果仍是草稿；提交要提供运行版本和幂等键，通过校验也不等于专家审核或工程验证。案例证据归一化不认证原文真实性。

逐步保存输入版本、证据位置、未知事项和审查记录。输入不足或硬约束冲突应停止或返回；未知不得自动判定为通过。工作台页面的完整调用记录仍在“探索与验证”。
