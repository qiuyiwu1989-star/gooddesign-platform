# 按资料条件执行

## A 原图重绘（默认优先）

先核看原图→记录5至8项识别特征→引用原图编辑/生成→与原图并排看。明确主体参考与风格参考的不同职责。改变环境或光照不能改变主体型号。

如果图很小、遮挡严重或是缩略技术展板，先寻找项目已存高清素材，不把模糊像素解释为具体部件。没有更好资料时说明只能保留可见部分。

## B 场景扩展

从原图主体扩展到档案支持的用途。可以改变海水、地貌、建筑背景、光影，但不能凭空增加设备功能。机械剖面和地下作业图只画公开依据明确支持的关系；未经支持的部分采用外观场景代替。

## C 无图概念

确认原件库没有可用外观图，才按真实用途画概念场景。交付字段mode=concept_scene，reference_status=unavailable，标记“概念场景插画”；用通用环境和动作表达，不假装准确复原获奖整机。此模式不能被标为原型一致已通过。

## D 批量

先列实际项目清单和已有插画映射，去重后逐件判断A/B/C；别把“缺图”当“全部要替换”，也别把“有照片”误当“已统一插画”。队列至少有项目ID、参考、当前版本、待做事项、审核状态。

每件单独生成、对照与记录。批量渲染或下载不等于逐件验收。先修正偏差较大的对象，再检查系列统一性。不得把同一台机器换背景当成多个项目。

## 向其他Agent交接

任务应指明允许写入的位置、项目ID、任务模式、可用原图、用途摘录和交付物。没有来源或工具就如实登记缺口。采集/绘画Agent可补充候选；正式封面选用和部署按项目已有授权执行，不由本技能扩大权限。
