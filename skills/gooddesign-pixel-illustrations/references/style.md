# 画面语言

## 形式
“像素工业志”是精细的科技复古内容插画，不是低分辨率游戏截图。像素簇组成结构、材质和空间，不依赖全图颗粒。轮廓清楚、细节有取舍，缩至320px宽仍能识别对象。

推荐工作原件为16:9、长边至少1600px；工具只提供近似比例时保留原件，导出时不得拉伸主体。显示版通常960×540 WebP。不是要求重采样把所有画面变成固定像素网格；尺度以系列观感与清晰度为准。

## 色彩参考

| 用途 | 参考色 | 原则 |
|---|---|---|
| 钴蓝环境 | #1866D8 | 提供乐观科技感 |
| 青色光线 | #37C9E8 | 用作空气、水、轻量机制提示 |
| 深蓝阴影 | #102B59 | 主体与背景层次 |
| 暖白高光 | #F5EBD8 | 克制金属、建筑亮部 |
| 琥珀点缀 | #ECAF4D | 安全设备或金色原型 |

这些是背景与笔触的参考，不是把真实设备染成蓝色的调色命令。原型红白、绿白、金色识别配色优先。

## 构图

装备主导：完整设备、大轮廓、少量真实应用线索。
系统主导：用原资料支持的组成与关系组织场景；不能为了“完整”补画未披露设备。
服务主导：用户动作和服务设施主导，如借车、叫车；不要把复杂软件能力都画成科幻控制台。

同一设备在卡片、横幅、首页复用时分别检查裁切。16:10卡片、方形缩略图不能切掉太阳翼、船尾、机械臂等识别部位；必要时用contain或单独构图，不拉伸。
