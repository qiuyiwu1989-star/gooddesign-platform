自主重型燃气轮机热端部件高效长寿命防护涂层设计

完成单位
东方电气集团东方汽轮机有限公司
主要完成人
王伟,巩秀芳,李定骏,陈艺文,曹晓英
项目编号
202301087
项目简介 / OVERVIEW

重型燃气轮机是关系国家能源和国防安全的国之重器，广泛应用于发电、舰船驱动等领域，其核心技术长期受西方发达国家控制，透平叶片、燃烧器等热端部件是影响其性能和安全的核心部件，在热-力-化耦合恶劣工况下极易失效，将引发重大安全事故，严重威胁能源电力和国家安全。为了保障重型燃机安全运行，防护涂层是热端部件有效防护措施，该技术被GE、西门子、三菱等严格封锁，是典型的“卡脖子”难题，因此自主设计研发高效长寿命防护涂层技术对保障国家安全和能源安全至关重要。

重型燃机防护涂层面临3项主要挑战：（1）服役工况复杂苛刻，缺乏涂层材料和结构设计准则。（2）防护涂层失效演化形式多变，难以精准表征涂层性能劣化规律。（3）热端部件结构复杂，难以制备形性均一的高效长寿命防护涂层。面对以上挑战，项目组以国家973、两机专项等重点项目为支撑，历时十余年，攻克了涂层设计、性能评价、制备及工程应用等核心技术难题，取得重要创新成果如下：

【1】探明了热端部件基体/涂层材料界面相容性适配机理，构建了防护涂层材料、涂层结构设计准则，提出了基体/涂层热-力-化多参数耦合界面适配准则，设计了高效长寿命防护涂层材料成分和涂层结构，开发了满足工况的高性能防护涂层材料成分配方，形成了自主涂层材料牌号，建立了评价标准。

【2】阐明了防护涂层性能退化与失效演变规律，提出了模拟工况防护涂层性能加速考核评价方法，攻克了涂层性能劣化行为精准表征难题。自主设计研发了模拟工况的热循环、热冲击、微动磨损等试验台，揭示了防护涂层劣化行为和延寿机理，建立了涂层性能评价标准，突破了高效长寿命防护涂层评价手段缺失的技术瓶颈。

【3】研发了复杂异型构件喷涂轨迹规划与精确控制的柔性制备技术，建立了高速熔融粒子多参数耦合智能在线监控方法，攻克了复杂异型构件易变形、难均一的涂层制备技术难题。针对异型构件，开发了基于高速熔融粒子温度场和速度场冶金沉积过程精确控制技术，发明了柔性机器人喷涂用九轴系统，实现了长寿命防护涂层工程化批量生产。

成果应用于我国首台自主F级50MW重型燃气轮机（2次被评为“央企十大国之重器”），打破了国外技术垄断和封锁，攻克了国家在能源重大装备领域关键技术“卡脖子”难题。相关成果获授权发明专利10余项,参与制定国家标准2项，制定企业标准23项。并支撑企业获得3台50MW燃机国家示范项目，有效推动了自主燃机制造水平的提升，引领行业的发展。

设计阐述 / DESIGN FEATURES
3.1 项目背景

国家“十四五”规划和2035年远景目标纲要中指出，要加快培育先进制造业集群，推动航空航天、先进电力装备等产业创新发展。先进电力装备是国家经济命脉和战略安全的重要保障，是实现制造业强国战略的基础，是实现“碳达峰、碳中和”目标的基石。重型燃气轮机与航空发动机并称为装备制造业“皇冠上的明珠”，具有清洁、低碳、高效、灵活的特点，是先进电力系统的“调节器”，是高新技术密集的重大装备，是高效清洁发电系统的核心动力装备和先进船舰的驱动设备，是关系国家能源和国防安全的国之重器，具有极高的战略地位和巨大的市场前景。

透平叶片、燃烧器等是影响重型燃气轮机服役寿命的核心热端部件，长期以来，只有美国、德国、日本等极少数发达国家掌握重型燃气轮机核心技术，我国在役燃机2000余台，热端部件对外依存度高，严重依赖国外。重型燃气轮机的恶劣服役环境致使叶片、燃烧器等核心部件极易发生高温氧化、热腐蚀、磨损失效，将引发重大安全事故，严重威胁国家能源电力安全和国防安全。高效长寿命高温防护涂层是应对核心热端部件失效的必要防护措施，被GE、西门子、三菱等国际能源巨头严格封锁，是典型“卡脖子”技术，亟需突破，自主设计和研发重型燃气轮机高效长寿命高温防护涂层技术是保障重型燃气轮机安全可靠运行的必经之路。

重型燃气轮机核心热端部件服役工况苛刻，不同基体和涂层材料界面的相容性差异大，核心部件性能失效演化形式多样，复杂结构部件涂层均一性难控制，这些难题带来了“防护涂层材料和涂层结构设计准则缺乏”“防护涂层性能劣化规律难以精确表征”“形性均一的长寿命防护涂层难制备”三方面主要挑战，核心部件无有效防护或防护技术无法满足重型燃气轮机安全运行要求。因此，本项目紧密围绕制造强国发展战略，以保障重型燃气轮机的自主可控、安全可靠运行为目标，展开了自主重型燃气轮机热端部件高效长寿命高温防护涂层设计及工程应用研究。

3.2 项目主要创新特点

项目组在国家973、两机专项、四川省科技支撑计划等重点项目的支持下，攻克了涂层设计、性能评价、制备及工程化应用等核心技术难题，探明了重型燃气轮机热端部件基体-涂层界面的适配机理，构建了高温防护涂层材料与涂层结构设计准则，阐明了热端部件防护涂层性能退化与失效动态演变规律，提出了高效长寿命防护涂层多因素摩擦学性能加速考核评价方法，建立了高速熔融粒子多参数耦合智能在线控制方法，研发了复杂异型构件防护涂层喷涂机器人轨迹规划与精确控制的柔性制备技术。项目成果已应用于我国首台自主F级重型燃气轮机、某JG舰船、某型进口F级重型燃气轮机、某型高炉煤气用燃气轮机等多类产品，保障了重点型号产品长寿命（大于5年）安全服役与运行。项目成果打破了国外技术垄断和封锁，实现了自主F级50MW重型燃气轮机核心部件宽温长寿命耐磨涂层技术“0到1”的突破，总体技术达到国际先进水平，填补了国内重型燃气轮机耐磨涂层技术空白；实现了自主F级50MW重型燃气轮机热障涂层修复再制造技术的突破，总体技术水平达到国内领先水平，部分指标达到国际先进水平。总之，项目攻克了国家在能源先进电力装备领域关键技术“卡脖子”难题，保障了我国多种型号燃气轮机等重点高参数透平装备的安全、可靠、高效运行。

本设计充分考虑了重型燃气轮机热端部件运行工况，基于功能、性能、长寿命相容性原理，完成涂层需求设计；基于工况设计系列试验台，完成涂层需求设计可靠性验证；基于制造过程闭环质量控制，完成涂层容限设计，实现高效长寿命防护涂层在国内首台F级50MW重型燃气轮机的应用。

项目的主要创新特点如下：

创新点1：基于部件服役工况—涂层性能的防护涂层需求设计

透平动叶片、静叶片、燃烧器内筒、尾筒、透平轮盘等是影响重型燃气轮机核心热端部件，其可靠性和服役寿命将决定整机的性能和安全性，每类热端部件服役工况和环境不同，本项目首先针对重型燃气轮机热端部件运行温度场、应力场、腐蚀环境、摩擦磨损、微动磨损等复杂苛刻的服役工况进行了系统的分析。通过对燃机热端部件运行温度场、应力场、腐蚀环境、摩擦磨损、微动磨损等多状态耦合工况系统分析，结合热端部件对防护涂层隔热、抗热腐蚀、耐磨损、抗磨蚀等性能需求，开展了多种防护涂层的开发和性能测试，建立了涂层数据库。根据涂层数据库，综合燃气轮机不同热端部件设计和服役工况情况，完成自主重型燃气轮机热端部件高效长寿命防护涂层需求设计。

创新点2：基于热-力-化多参数耦合界面适配准则的防护涂层材料及结构设计

本项目针对重型燃机热端部件不同服役条件下的隔热、抗热腐蚀、耐磨损、抗磨蚀性能的需求设计，基于涂层材料热力学相图计算，对涂层材料与基体材料的物理化学参数（热导率、热膨胀系数、润湿性）匹配度等进行模拟分析，创建了基体/涂层适配性图谱数据库，探明了基体/涂层界面相容性演化与发展规律，并结合不同热端部件基体/涂层系统的应力及强度特性，提出基体/涂层材料热-力-化耦合界面相容性适配准则，构建了服役工况-性能匹配的基体/涂层材料系统，实现了核心部件基体/涂层材料的精准匹配。依据基体/涂层材料界面相容性适配准则，差异化设计了满足不同工况需求的高温防护涂层材料成分及涂层结构，完成了涂层材料及涂层结构设计。依据建立的基体/涂层材料界面相容性适配准则和涂层成分与涂层结构设计，研发了高效长寿命防护涂层材料成分配方，构建了铜镍铟粉末（6052B2）、碳化铬粉末（6201C3）、钴钼铬硅粉末（6002A1）、钴镍铬铝钇粉末（6000A1、6000A2）、氧化锆粉末（6134B1）等系列化涂层材料自主牌号，满足了重型燃机不同热端部件服役工况的需求。依据自主牌号涂层材料成分配方，提出了涂层材料化学成分、几何形态、微观结构、粒径分布、松装密度、流动性能等粉末特性关键技术指标，建立了高效长寿命防护涂层粉体材料评价标准和数据库。

创新点3：基于制备过程质量控制的防护涂层容限设计

项目主要采用超音速火焰喷涂（HVOF）和大气等离子喷涂（APS）方法制备高效长寿命防护涂层。燃料压力、燃料流量、氧气压力、氧气流量、送粉量、喷涂距离等是HVOF喷涂的主要工艺参数；氩气流量、氢气流量、电流、电压、送粉量、喷涂距离等是APS喷涂的主要工艺参数，针对以上诸多工艺参数，项目采用智能化热喷涂在线监测系统采集垂直和平行焰流方向的粒子束焰流温度、速度、粒径等参量数据，获取粒子束焰流参量的三维仿真数据动态云图，筛选优质粒子束焰流，通过调整喷涂工艺参数（气体流量、燃料配比、送粉量、喷涂距离等）控制优质粒子束占比，掌握了粒子束焰流特性与工艺参数之间的定量影响规律，建立了粒子束焰流参量、工艺参数、涂层组织结构、涂层性能四者之间的量化关系数据库，实现了长寿命耐磨涂层组织与性能的高效精准调控，有效缩短了喷涂工艺研发试验周期，提升了闭环控制涂层性能的效率。

针对复杂异型薄壁件（厚度约0.6mm）在粒子束焰流高温冲击作用下产生的热应力导致工件变形的问题，设计专用防变形柔性装置和涂层厚度测量装置，控制涂层厚度方向的工件变形量小于0.03mm。设计并开发了复杂异型薄壁构件防护涂层喷涂机器人轨迹规划与精确控制的柔性制备系统及技术，提出九轴联动调整喷涂速度和喷涂路径的柔性相对运动控制方法，通过仿真模拟方式构建了高精度喷涂过程轨迹，实现了喷枪与工件柔性化相对运动精确控制，涂层厚度公差小于0.02mm，实现窄厚度公差防护涂层制备。设计并实现基于多模态信息融合的防护涂层等离子体喷涂过程监测和诊断系统，实现制备过程涂层质量闭环控制，制备过程中关键设备功率波动≤2%，涂层抗热震寿命偏差≤5%，实现窄性能公差防护涂层制备，进一步优化涂层容限设计。

创新点4：模拟工况性能考核验证-防护涂层设计可靠性验证

针对重型燃气轮机核心热端部件多因素复杂服役工况和特性，采用本项目发明的多参数（接触应力、位移、振动频率、温度）微动磨损性能评价综合试验系统，运用摩擦耗散能和二类微动图理论，重构耐磨防护涂层在极限工况条件下的温度场与应力场、相对运动形式，加速了核心部件耐磨防护涂层失效过程考核，探明了耐磨涂层失效机制。项目建立了耐磨防护涂层材料关键性能评价指标，揭示了耐磨防护涂层在多因素耦合条件下摩擦副磨损行为，解决了高温长时的组织结构演化规律与热-力-化多场耦合条件下的摩擦磨损机制等关键科学问题，建立了模拟重型燃气轮机服役工况下的耐磨防护涂层设计-考核评价-优化方法。

同时，针对重型燃气轮机热端部件防护涂层真实服役工况，自主设计和开发了高温燃气热循环、联合热冲击、隔热测试、燃气热腐蚀等模拟重型燃气轮机真实服役工况测试系列试验台。利用自主设计和开发的试验台，开展了系列高效长寿命防护涂层模拟工况性能测试，并在燃烧器试验台、整机实验台实现了压气机、燃烧器、透平等关键部件在多重复杂服役环境、多种因素负载作用下的防护涂层工艺稳定性测试，实现了防护涂层性能在F级50MW重型燃气轮机整机试验台上的直接批量验证，对服役后防护涂层的缺陷进行了快速、精确识别与定量分析，形成了对热端部件防护涂层工艺稳定性的综合量化测定方法，实现了对防护涂层设计的效果、可靠性的系统考核验证。
