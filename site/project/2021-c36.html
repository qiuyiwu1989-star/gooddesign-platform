创意奖· 2021 · 第七届

多功能护理床椅一体机

完成单位
江西理工大学
主要完成人
刘福全,符江繁,饶大佺,刘静
项目编号
202104593
项目简介 / OVERVIEW

设计目的：

为助力国家智慧养老政策，本团队深入养老院进行实地调研，了解到下 肢残疾的老人都需要护理人员抱着实现床与轮椅的转移，且忘记吃药、 如厕困难等也是主要问题。为解决老人的生活不便，研发了一款融合物 联网技术的多功能理床椅一体机，目的是推进智慧养老服务，提高老人的生 活质量，减轻护理人员的负担。针对老人的生活问题以及现有轮椅的缺陷，满足老人们的基本生活需求，本作品将轮椅、床、如厕装置组合一体，解决老年人上下床困难、如厕不方便等问题。多个装置相互配合，省去护理人员将老人从轮椅抱到床上或从床上抱到轮椅上的过程，通过床椅结合，由老人自行挪动、独立操作，就能轻松实现换位。如厕装置可由老人自行操作，减轻了护理人员的负担。

设计创新：

（1）设计了新型床椅javascript:void(0)结合机构，通过电磁铁的吸附能力将轮椅与床结合为一体，老人通过挪动或翻身实现轮椅与床的换位，解决老人上下床困难的问题。

（2）设计了新型如厕装置，通过虹膜机构原理实现方便袋的开合，防止异味散出，使老人可以独立如厕，解决老人如厕难的问题。

（3）设计了融合物联网技术的监测装置，通过阿里云服务器实现轮椅的入网以及手机APP控制，帮助家人随时监控老人的动态，减少意外的发生。

设计价值：

本作品在设计完成后多次前往本地养生院、医院进行实地性能测试，得到了本市各养老院、敬老院和医院的认可，并与江西理工大学医院签订了轮椅试用协议。同时与精诚机械制造有限公司、上海庆诚自动化科技有限公司签订了代加工合作协议。

设计阐述 / DESIGN FEATURES

创新点：

床椅结合：床与轮椅的结合，老年人可实现独立上下床。轮椅的背板与腿板可自行调节，伸展成与床结合的平面，老年人可通过翻转或挪位实现独立上下床。

轮椅高度可调：轮椅高度可调，满足老年人的舒适度。升降机构使得智能护理轮椅床可以调节高度，既可以实现床椅高度一致，还可使使轮椅达到老年人吃饭、起居最舒适的高度。

如厕装置：如厕装置，方便独立如厕。如厕装置通过虹膜机构的原理，实现便袋随时收紧，并可与扎口装置相配合实现便袋的更换，解决了老年人如厕难的问题。

语音模块：语音模块，可提醒老年人吃药。轮椅配备语音模块，折叠小桌子处安装显示屏，可触摸控制，还可以提醒老人吃药，解决老年人记忆力衰退难题。

智能监测：采用阿里云的服务器，实现入网和app控制。智能轮椅和app实现数据交换，可以app检测老人是否处于睡觉状态以及轮椅是否倾斜，还可以测量老人体温和定位老人的位置，使年轻人可随时了解家中老人的行为。

设计的科学性 :

（1）本作品采用实地调查法、问卷调查法和文献检索法进行市场调研，了解下肢残疾老人的生活状况以及现有普通轮椅的缺陷。通过理论分析、机构设计、实体建模及装配、运动学仿真、有限元分析、实验与实际应用验证相结合的方法，确定合理的方案与结构，并在医院、养老院试用。

（2）与现有轮椅相比，该作品通过更简单的机构实现床椅结合和独立如厕。采用螺旋机构与连杆机构，实现椅面的平稳抬升；再通过电磁铁的吸附作用，将轮椅与床稳固的连接在一起，便于失能老人独自完成从床到轮椅之间的换位。采用虹膜机构实现方便袋的开合，防止异味散出。

设计的先进性 :

（1）该产品在保证功能性的前提下，最大程度降低结构的复杂性，采用六杆机构实现轮椅升降、四杆机构实现腿部旋转，使产品量产的实现难度大大降低，提高作品的性价比。

（2）运用物联网技术，将轮椅与家人的手机互联，实现数据交互，迎合了智能装备万物互联的发展趋势。手机APP实时监测装置可以使子女随时随地查看轮椅的状态，确保家人第一时间了解老人的安全性。

核心机构：

行走机构：行走机构是由控制器、电机、后轮、万向轮等部分组成。控制器控制电机转动，带动后轮行走，左右两个电机通过控制器同时进行转动，在转弯过程中利用差速原理进行转弯，转弯过程中快速、稳定。按下电源键，启动行走机构，通过控制器上的手柄控制行走方向，手柄可360°摆动，使车轮可以向各个方向转动。

升降机构：升降机构由升降连杆、伺服电机、丝杆、光杆、减速器、滑轨滑块组成，伺服电机驱动丝杆转动，丝杆带动升降连杆前后移动，进而轮椅可进行上下移动。伺服电机转动，驱动丝杆转动，驱动丝杆滑块套向前移动，丝杆滑块套与光杆相连接，带动光杆沿着滑轨向前运动，光杆带动升降连杆上下移动，进而实现轮椅上下移动。升降机构采用的是额定转速3000r/min，扭矩1.28N·m的伺服电机，与10比转速器相连接，升降连杆上升过程中具有自锁性，使升降机构稳定运行。

平躺机构：平躺机构由背板、腿板、座椅调节器、电动推杆组成。背部座椅角度调节器利用其汽车座椅调节原理实现背板平躺，腿部通过电动推杆实现腿板与椅面平齐，实现轮椅平躺。座椅角度调节器由弹簧、半个齿轮、凸轮等机构构成，机构简单，能够实现其相应的功能。平躺过程中，手动去扳动座椅调节器手柄，依靠使用者自重量，使背板可转动90°，实现其背部平躺的功能。

如厕机构：如厕机构由便盆、舵机、封口装置、扎口装置组成。如厕机构放置于座椅的下侧，在座椅上面有两块方便板，需要如厕的时候将方便板拉开即可。当需要如厕时，舵机控制齿轮转动，带动与方便板相连的齿条向轮椅两边移动，打开方便板，同时舵机控制封口装置打开。封口装置通过卡槽与方便盆连接，由6个小三角挡板构成，这6块小档板沿正六边形的边界轨道进行移动，实现如厕袋的开合。当如厕结束后，舵机控制方便板与封口装置的闭合，封住如厕袋，防止异味散出。更换如厕袋时，舵机推动扎口机构沿着滑轨运动，扎住如厕袋，将其与封口装置从轮椅后面取下，实现如厕袋的更换。

床椅结合装置：床椅结合装置由轮椅、床、电磁铁组成。轮椅实现平躺之后，与床结合，实现在轮椅上平躺着睡觉的功能。轮椅通过控制器移动的床的旁边，通过阻尼转轴扭矩铰链将右侧扶手转下，当轮椅在平躺机构的作用下完全平躺后，与升降装置相互实现床与椅高度一致，再由电磁吸附实现床与椅的固定，从而实现了床椅自动对接，使用者仅通过翻身动作便可完成从床到椅的转换。
