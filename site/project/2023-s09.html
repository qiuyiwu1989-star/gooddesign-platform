纤灵——多机协同的细纱接头智能机器人系统

完成单位
东华大学
主要完成人
汪俊亮,张洁,杨钟亮,盛裕洁,何晶
项目编号
202301263
项目简介 / OVERVIEW

我国的纺织规模占全球50%，环锭纺纱占全国纱线产量的80%以上，环锭纺过程中因纤维强力与张力不平衡易出现断纱，需要将断纱牵引接头以恢复正常生产。接头中纱线易断裂、扭结，自动接头成为行业难点。自上世纪60年代以来，全球纺织装备公司致力于突破自动接头技术，但是全球仅有瑞士立达公司于2019年推出了工程样机，且形成了技术垄断。

为突破这一瓶颈问题，项目提出了多机协同的细纱接头智能机器人系统：研发了视觉检测AGV，实现了断纱的高速巡游准确识别；设计了自动接头AGV的多合一末端执行机构和柔顺控制算法，解决了纱线接头过程中易退捻、易断裂难题；搭建了“云-边-端”一体化多机协同远程调度系统，提升了多机系统综合效率。项目实现从断纱检测定位到断纱自动接头的工作，接头速度可以达到30s，看台率5000锭，对比国外机器人提高了5倍以上，提高生产效率，减轻工人劳动强度，增加产量，节约用棉和用电。并且本设备解决了夜间无人接头的的问题，日产量提升约10%，每台设备节省人工2.5人，十万锭工厂日增收1万元，具有显著的经济效益和实用价值。项目打破了国外技术垄断，建立了柔性体灵巧作业机器人的新标杆，作为核心技术之一入选2021年中国智能制造十大科技进展。

设计阐述 / DESIGN FEATURES

（一）结构技术创新点：

（1）多特征融合的断纱视觉自学习检测技术。创新性提出了考虑背景颜色、空间梯度、纱线条干等多特征融合视觉检测算法，设计了断纱检测在线自学习机制，研发了环锭纺细纱长车巡游式断纱检测边缘端系统。实现了弱特征、高噪声、强动态环境下的高精度断纱检测，断纱检测准确率高达99%。

（2）多合一末端柔性执行机构。提出了基于单机械臂的绕纱、穿纱、引纱、喂纱、断纱一体化作业方法，设计了环形气流磁吸式钢丝圈定位机构、环形条柱涡旋稳流绕纱机构，实现了狭小空间环境下的单臂断纱自动接头。

（3）基于力反馈的高可靠断纱接头技术。设计了接头机器人力跟踪导纳控制模型，建立了动态环境下导纳控制器参数自适应调整策略，提出了基于状态反馈的交互力估计算法。实现了纱线易退捻、易断裂、易飘动、多涡流场情况下的高质量断纱接头，断纱接头成功率95%，接头速度30s。

（4）多机协同的高看台率机器人调度技术。提出了考虑环境状态、通道路径约束与多机共线约束下的路径生成算法，设计了“云-边-端”一体化通信架构，搭建了环锭纺工厂巡检AGV与接头AGV多机协同的云端调度系统。实现了多设备约束下的高效率云端调度，环锭纺工厂的实时监控管理。

（二）产品设计创新点:

（1）近原位预生头新接头工艺：近原锭位断纱纱管抓取，辅助纱纱头固定，环形气流装置穿钢丝圈，牵引运动张力协同控制，多功能气动剪。本工艺解决了现有引纱接头方法步骤繁琐的问题，能在断纱锭位狭小空间内完成整个接头动作，接头效率高。

（2）数字孪生技术驱动的设计方法：虚拟化物理场景，三维化装备设计，流场分析辅助参数设计，牵伸形变机理分析模型，张力控制动力学机理模型。本方法在设计建模阶段验证了产品适应性，在运行阶段保证了产品的稳定性。

（3）基于以人为本与绿色发展理念的产品外观设计：①设有五处指示灯，上部分用来提示较远用户，下部分用来不同方位的提示；②机器人中部设有减震缓冲带，可以减少运动过程中的颠簸；③伸缩门设计，可以讲机械臂完美隐藏起来，工作室自动伸出，使机体具有整体性；④机体设置了两部分的散热装置，利用热驱动形状记忆聚合物达到自动张开散热的效果。

（三）获得的主要知识产权：

8项发明专利授权，2项计算机软件著作权登记：

（1）发明专利：一种环锭纺细纱机自动接头装置及方法（授权号CN113174668B）

（2）发明专利：一种面向环锭纺细纱在线检测的视觉系统校准方法（授权号CN113802227B）

（3）发明专利：一种基于张力反馈的自动接头机器人柔顺装置（授权号CN113755978B）

（4）发明专利：一种用于环锭纺细纱自动接头的机器人末端执行机构（授权号CN113174669B）

（5）发明专利：一种用于环锭纺细纱自动接头的备用纱绕纱装置（授权号CN113604919B）

（6）发明专利：一种基于机器视觉的断纱找头装置（授权号CN11519293B）

（7）计算机软件著作权登记：棉纤维柔性作业机器调度云系统（登记号2021SR1280046）
