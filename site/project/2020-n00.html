提名奖· 2020 · 第六届

设计创新推动城市垃圾无害化处理产业发展及应用实践

完成单位
广东华南工业设计院,东莞市新东欣环保投资有限公司
主要完成人
熊彩虹,顾四海,黄智浩,唐宏志
项目编号
202003022
项目简介 / OVERVIEW

近年来，城市垃圾已成为影响生态环境、困扰市民生活和城市发展的一大难题，推进垃圾分类并实施垃圾无害化处理是解决城市垃圾污染的重要方式。推动垃圾无害化处理设施向公众开放，让公众形成对垃圾更为完整的认知，是提高全社会环境保护意识的有效措施。

作为世界制造业名城的东莞有800多万常住人口，每天产生垃圾总量约13700吨。目前东莞每天通过处理的垃圾量有11300吨，每天还有2400吨垃圾不能得到无害化回收处理，里面还存在大量的工业固废垃圾，且不能得到有效处理，这是东莞垃圾处理的短板。在东莞规划建设一个先进的垃圾处理及资源循环利用中心，是目前最佳的也是唯一的出路。东莞市海心沙资源综合利中心项目因此孕育而生。

本项目通过对东莞市海心沙资源综合利用中心理念和定位的理解及产线的梳理分析，在其现有垃圾处理产线环境和设备的基础上，以设计创新思维引领产业设计、技术协同、循环经济、集约发展等创新要素，以用户体验为中心，基于行业国际及技术规范标准，利用BIM信息模型管理模式，提出以技术标准为基础，以视觉效果为核心，采用模块化设计，将外观美化+视觉识别+标准化应用有机融合，构建形象识别系统规范产线用色、标识标贴的应用，推进城市垃圾无害化处理设施规范化管理的标准化应用，同步推进垃圾处理设施向公众开放，建设成无害化处理设施产业化示范工程、循环经济环保教育基地。

东莞市海心沙资源综合利用中心项目的规划建设，将打造“高标准设计、高质量建设、高水平运营”的集成模式系统的循环经济综合解决方案，能够解决东莞市26大类工业危险废物的无害化处理与回收，实现31.61万吨/年的危废无害化处理规模；处理生活垃圾1500吨/天，年产2亿千瓦时电能，节约标煤8.08万吨/年；每天处理餐厨垃圾300吨和地沟油10吨，每天产生约1.8万方天然气，可满足约1.5万户居民使用。该项目立足东莞，辐射湾区，补齐城市垃圾处理短板，提高市民的环境保护意识，加快城市垃圾处理模式的创新、示范和推广应用，推进城市垃圾处理产业高水平发展，促进城市可持续发展，成为了粤港澳大湾区特大城市资源利用基地集成示范项目，也是广东省唯一一家获得“国家资源循环利用基地”殊荣的资源循环利用基地。项目还获得了2020年广东省第十届“省长杯”工业设计大赛产业组银奖。

设计阐述 / DESIGN FEATURES

（1）项目的设计思想

随着社会的发展，城市垃圾无害化处理设施与资源化循环利用技术得到迅速推广和应用，垃圾处理中心及其处理设施社会化服务功能不断提升，面向公众开放的需求日趋增加，垃圾处理基础设施建设及其运营现状问题亟待解决：现场作业区域混乱、可视化管理不规范、设施与环境不相融合、垃圾处理社会化服务功能薄弱等。

本项目以产业助推城市品质提升、结合循环经济与社会责任相融合的发展思路，运用设计思维引领的模式，基于行业国际及技术规范标准，通过人员、环境、设施、信息等要素创新集成标准化管理体系，以用户体验为中心，采用用国内最先进的工艺设备及技术，通过高标准的产线系统设计，涵盖了从垃圾运输进厂开始，到厂区内产线的作业运行的区域规划、色彩管理、设备物件属性等综合应用管理的系统设计，让产线作业流程一目了然，分别形成对内和对外价值：提升标准化管理、提高作业效益、人机安全体验、生产维护点到点、信息模型同步等；从工业旅游、环保教育的角度树立行业形象，让公众更加直观地了解产线运作流程，从而提高公众环保意识。

（2）项目主要创新度

该项目以设计思维引领多方利益相关者协作共创，围绕“高标准设计、高质量建设、高水平运营”的三高目标，整合产业设计、技术协同、循环经济、集约发展等创新要素，实现以资源综合利用为核心，打造集成模式系统的循环经济综合解决方案，补齐城市垃圾处理短板，加快城市垃圾处理模式的创新、示范和推广应用，促进城市可持续发展。

1）高标准设计。该项目基于行业国际及技术规范标准，以视觉效果为核心，采用模块化设计，利用国内最先进的工艺设备以及高标准的产线设计，对区域进行科学布局规划、可视化设计、合理的色彩搭配，将外观美化+视觉识别+标准化应用有机融合，构建形象识别系统规范产线用色、标识标贴的应用，优化垃圾无害化处理设施并使之与作业环境的融合，规范垃圾处理行业标准化运用管理，展示规模化垃圾处理和规范化管理。

该项目产线设计呈现以下设计亮点：

A.工作区域规范化分区。按照垃圾处理流程、功能分区、合理布局，动态与静态的区分，目的在于规整内部环境中的各区域，达到快速地辨别出不同区域所归属的功能属性。

B.车间管理可视化。通过统一的视觉识别形象加强各作业区间的联系性，相同性质的功能区域通过标识标贴、色彩色系、区域划分等进行了归类，既统一了车间的视觉形象，又使操作者可以更直观的进行规范作业，提高工作效率。

C.标准化应用设计。通过对垃圾处理设备的色彩搭配、标识标贴等进行整体的统一规划设计和相关标准的规范应用，使得整体效果协调、美观。

D.人机安全体验。将模块化设计理念贯穿于垃圾处置产线及其配套设施等规划设计环节，确保安全标签、标识的正确使用及管线颜色、介质流向的正确标识，减少各种事故的发生，提高企业健康、安全和环境管理水平。

E.社会化服务。发挥垃圾处理中心及其处理设施社会化服务功能，组织公众进行参观，让公众零距离感受生活垃圾处理工艺流程、了解无害化处理现状，树立良好的环保意识，自觉推动垃圾分类，主动参与垃圾治理。

项目通过高标准产线设计，未来将成为一个集生态环保、岭南文化、水乡特色为一体的颜值极高的现代化环保项目。

2)高质量建设。东莞市海心沙资源综合利用中心项目建设内容主要包括了绿色工业服务项目、环保热电厂项目、餐厨垃圾处理项目，具有将城市的生活垃圾和工业固体废弃物协同处理，将各种资源综合回收利用的功能。

A.绿色工业服务项目设施包括焚烧处理单元、表面处理废物处置单元、物化处理车间、废矿物油综合处置单元、废线路板处理车间和废包装桶清洗回收车间，同时配套生产所需的其他公用辅助工程、储运工程和环保工程等，能够解决东莞市26大类工业危险废物的无害化处理与回收，实现31.61万吨/年的危废无害化处理规模，有效补齐东莞市固体废物处理处置基础短板。

B.环保热电厂项目是东莞首个现代化生活垃圾焚烧发电设施，处理生活垃圾1500吨/天，年产2亿千瓦时电能，节约标煤8.08万吨/年，满足城镇居民一年的用电需求，飞灰填埋填补了东莞市在焚烧垃圾飞灰处理终端设施的空白。

C.餐厨垃圾处理项目是东莞市首个餐厨垃圾无害化处理与资源化利用项目，收运范围覆盖东莞22个镇区，与600家机关与企事业单位签订合作协议，每天处理餐厨垃圾300吨和地沟油10吨，每天产生约1.8万方天然气，可满足约1.5万户居民使用。

高水平运营。东莞市海心沙资源综合利用中心项目是由投资单位、政府部门、环保机构、科研院所、市民等共同参与的一项民生工程，规划处置生活垃圾、餐厨垃圾、危险废物等各类固体废物是其最主要的基本职能，它同时还承担着“倡导环保、践行环保”的宣传重责。为更好地将海心沙资源综合利用中心打造为集废物处置与利用、环保技术研发与转化、环保产研教等为一体的现代化环保产业基地，中心配备采用先进的技术、引进行业领先的产品设备，从垃圾运输进厂开始，到厂区综合管理，均设计采用集成化智慧管理控制系统。目前与华为签订战略协议包含了物联网、云计算、GIS、5G等核心优势，实现了信息化、可视化、自动化。

（3）项目主要研究设计方法及特点

本项目在深入梳理与分析现有垃圾处理产线环境和设备的基础上，通过人员、环境、设施、信息等要素创新集成标准化管理体系，基于行业国际及技术规范标准，以用户体验为中心，利用BIM信息模型管理模式，在行业标准要求、空间规划、色彩管理、标识标贴管理、工程应用管理方面进行系统完善的项目工业设计规划。项目采用模块化设计，建立基础模型，

提出了以技术标准为基础，以视觉效果为核心，将外观美化+视觉识别+标准化应用有机融合，构建形象识别系统规范产线用色、标识标贴的应用，展示规模化垃圾处理和规范化管理。

1）标准化设计。行业要求标准化、用色系统标准化、识别系统标准化、施工应用标准化。

2）规范化标识。指令标识规范化、警告标识规范化、禁用标识规范化。

3）信息管理。作业系统智能化、建设工程信息化、管理系统信息化。

（4）项目实施过程、典型经验、品牌战略及团队优势等

1）项目实施。本项目的实施按照“高标准设计、高质量建设、高水平运营”的要求进行，设计团队多次赴现场勘验调研，与建设方项目主要负责人密切沟通,落实设计任务。在设计过程中集思广益,并向建设方进行了多轮成果汇报。项目所涉及的设计方案均经由专家评审会就设计方案的可行性、技术先进性、概算合理性进行论证，得到专家的认可，保证了项目顺利实施。

2）典型经验。垃圾处理设施在城市运转中扮演着重要的末端处理角色。但是在公众心目中，“垃圾处理”总是给人以脏乱差的印象，让人闻之色变、避之不及，这都是因为传统垃圾处理厂大多存在着作业区域混乱、可视化管理不规范、设施与环境不融合、社会化服务功能薄弱等问题。针对上述普遍存在的问题，新东欣公司联合广东华南工业设计院，为东莞市海心沙资源循环利用基地（以下简称“海心沙基地”）正在建设中的垃圾无害化处理设施设计了一套工程方案，不仅有效提高了环保设施的运营管理水平，而且还有利于环保设施对公众进行开放，打造环境教育的绝佳平台，并可在全行业进行推广应用。

3）品牌战略。本项目以设计创新思维引领的模式积极探索城市垃圾无害化处理产业发展，以提升品质为己任，树立湾区标杆项目，以技术实力为先到，整合一流技术资源，以社会责任为基石，将公众利益摆在首位，致力将东莞市海心沙资源综合利用中心打造为集废物处置与利用、环保技术研发与转化、环保产研教等为一体的现代化环保产业基地，对提升东莞城市综合承载力和区域竞争力、加快美丽东莞建设、推动东莞高质量发展具有重要意义。

4）团队优势。海心沙基地是东莞市委、市政府统筹部署的、补齐全市固体废弃物处理处置缺口的重要基础设施，由东实集团全资子公司——东莞市东实新能源有限公司具体负责投资、建设、运营工作。而为本项目正在建设中的垃圾无害化处理设施提供工程设计方案的广东华南工业设计院是东莞地区首家被评为中国工业设计十佳工业设计机构、广东省工业设计中心的专业设计机构，在产品设计、产线设计、品牌策划等领域有多项成功案例。
