# 形态学分析：把方案空间展开，再逐条说明为什么排除

当团队只有一个熟悉解法，或多种作用方式需要组合时，形态学分析帮助系统展开配置。Ritchey 2002、修订2013的General Morphological Analysis中GENERAL MORPHOLOGY和CCA选段是依据；配对一致性讨论共存，不是因果或优劣。机械功能矩阵是平台应用，不把它等同原文所有社会政策建模。

## 维度怎样选，才能真正打开方案

输入问题边界、需要/功能、约束、已有机制与证据。维度应表达需要作选择的相对独立方面，选项在同一维度语义层级相近且定义清楚。“弹簧/更轻/人工”混合零件、属性与组织方式，不便判一致性。也不能把每个维度写成当前产品一个零件，让组合只是换供应商。

先用功能抽象命名维度，再列不同原理。每个选项记作用方式、条件和不能承担的功能。若选项不是互斥，可拆维度或明确允许组合规则，不能假定每维只能选一个而隐含删掉有效方案。

## 从三维八组合到补证队列

沿用割胶构造子问题：表面参考为接触/非接触；相对约束为几何限位/反馈约束；停止退出为被动概念/受控概念。2×2×2=8个形式配置。其他作用仍在R14共同包，不能因只选这三维便忽略授权、运动和失效检查。

每一跨维配对写判断类型、条件、证据和理由。逻辑矛盾、实证限制与规范偏好分开；“团队不喜欢”不能写物理不兼容。当前12配对与8整体判断均unknown，因此8项保留研究，没有成熟候选。这是原割胶材料的真实边界。

另有资料充分的**构造协议练习**：形成介质纸/电子，归档介质纸/电子，协议明确禁止隐含转换。4配置中纸→电子和电子→纸违反协议被排除，纸→纸与电子→电子保留。这里排除来自规范条件，不是现实无法扫描打印；协议变更就应重开这两个配置。

## 为什么配对都过仍可能整体失败

既有另一个全构造资源练习：参考选项5/20W、约束0/25W、退出0/20W，上限50W。跨维二元和都≤50，但20+25+20=65W，整体不满足。其余7配置也只满足这一个假定资源限制，不证明机械可行。

所以中间产物应同时有形态场、逐配对理由、整体约束与状态。枚举不是搜索算法已经替人判断兼容；有unknown可以保留，却不能计作“相同/0分”。选一个展示基线只是方便阅读，不是推荐最优。

## 用输出安排下一步，而非停在漂亮矩阵

对关键unknown列最小区分性材料：作用条件、接口、量测或试验。若某条件会排掉大量配置，优先研究它；但真正优先级仍需成本、风险和价值依据。产生新证据时只重评受影响判断和组合，保留旧版本及理由，不能偷偷修改选项名让历史对不上。

两个失败反例是把偏好当不可能排除，以及忽略总资源/同步等高阶约束；还要防选项名称近义、实际机制相同造成“虚假多样性”。不同资料情境的介质规则有清晰协议，而割胶物理/生物兼容仍待研究，不能互相借通过状态。

交接给R36的是配置、判断引用和缺证，不是自动排名；给原型/试验方法的是能区分机制的问题。完整产物要使他人重建相同形式空间，并知道每项为何排除、保留或待证。
