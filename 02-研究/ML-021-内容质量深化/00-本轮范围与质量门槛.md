# ML-021 方法正文质量深化

## 用户目标

继续全部64项的方法内容深化，逐步解决剩余问题，达到高质量后再准备上线。上一轮64研究包/42修订和Agent技术复核是底稿，不视为本轮正文质量验收通过。

## 本轮范围

- 审读64项最新版研究、原典支持与完整教学产物，形成逐项真实缺口台账。
- 对每项定向补证、重写可专业阅读且可跟随的方法正文，保留区别、判断、完整实例和反例。
- 明确方法、框架、专题的不同性质，原作者与平台适配分开，不强行同一五步算法。
- 同一项可先补可做内容，原典/现实输入/专业审核不足分项保留，不能靠免责声明代替可完成工作。
- 独立Agent内容审核，按发现修正文及证据，不以测试/字段数自动验收。

## 非目标

不自动上线，不改变冻结库或现有六执行契约，不声称领域专家认证、真实现场试验、64原著全读或64通用求解器。不重复只修机械门禁来冒充内容深化。不复制受保护卡组/标准/图表全文。

## 质量门槛

每项逐维评议为不具备/局部/充分，附正文/证据定位，属于Agent评议而非客观校准分数。

1. 身份与边界准确：具体版本、层级和与近邻方法差异；没有错误或冒充出处。
2. 机制讲透：为什么此表示/操作可能推进设计，关键假设、推论范围及不支持什么。
3. 判断可操作：具体证据、选项、选择/排除/返回/停止点，未知与责任明确。
4. 完整示范：可从给定输入跟随到中间产物和输出；数值模型给方程/单位/条件，研究方法给记录与编码/解释过程。
5. 反例与迁移：至少两种实质失败/误用及另一情境的条件差异，不仅非法JSON测试。
6. 依据可追溯：关键主张绑定核读位置和实际范围，原典/平台解释/构造/公开数据/实测分别标明。
7. 阅读与交接：连贯中文、适当原创结构图/表、逐步产物和交接字段，不堆管理员术语或审计日志。

关键错误、假证据、伪造现场/客户批准、错误公式、不可复查示范均阻断“上线候选”。原典全文不是每项概念说明的统一必要条件；但原细则/算法若缺直接依据，不得声称重建完整原法。
