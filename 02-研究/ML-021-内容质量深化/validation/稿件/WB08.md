# 面向制造性能的可视优化设计：让模型暴露缺陷，再保留任务地改动

可视优化不是网页增加图标或动画，而是在能表示目标现象的工程模型中检查、分析和修改。孙伟等/闻邦椿2007论文PDF2刊386讨论模型、仿真、结果分析和缺陷修改，以及加工、装配、运动、动力、工作、控制等观察；2017专章尚未取得，不借论文选段冒称整章复刻。

先写要检查的现象与可复查量，再选模型。装配干涉需要几何/公差与装配路径；动态响应需要质量、刚度、阻尼、载荷/约束与求解；工艺过程需要工装、工具可达和加工假设。运动动画只能提供它建模范围内的运动关系，不会自动生成接触力、疲劳或制造能力。

完整构造例研究一维投影重叠，长度单位归一化。环境障碍[2.5,3.5]固定，移动件宽度2，要求作业位置可到2。原设计A在位置1时占[1,3]，重叠0.5；到2时占[2,4]，重叠1。缺陷定位为行程后段与障碍投影冲突。候选B把最大行程降到0.4，虽然右端2.4不重叠，却无法达到任务位置2，应拒绝把“无干涉”当整体改进。

候选C显式修改移动件几何，把宽度缩到0.4且保留行程到2；最大右端2.4，和障碍有0.1间隙，原作业位置保持。教学选择C进入结构/工艺检查，而不选B。改动是设计变量，外部障碍、作业范围与判断准则保持同版；若把障碍偷偷移走，则改变了问题。C的承载、最小制造尺寸、装配与公差尚未分析，不能据0.1间隙宣称可制造或安全。

接下来给检查量与模型边界：几何投影能回答重叠，不能回答实际三维装配和动态变形；0.1名义间隙若小于误差/变形总量，需扩大模型并回设计。产物保留原/改模型版本、相同工况、可视缺陷位置、数值量、修改理由、任务副作用及复查。展示颜色只是表达，必须能回查哪个条件触发判断。

两种误用是消除动画穿模后宣布动力安全，以及只比较改前/改后漂亮画面而没有同条件数值。另一种是用缩短行程掩盖必要任务损失，本例已明确排除。迁移到页面预览时宽度120/90与可用100的比较可以核溢出，却不能证明文字可读；它只是可视检查逻辑迁移，不等机械制造仿真。

交接R32运动、R34装配/制造、R42验证。模型应针对现象逐步加深，真实CAD、公差、工艺和标定资料不能由渲染补出；有依据的局部选择与未覆盖的工程性能同时保留。
