# 设计质量检验与综合评价：证据、指标、权重和价值各司其职

质量检验获取某些声明的证据；指标体系规定看什么；综合评价决定怎样描述/聚合；价值偏好决定变化对谁重要。2006三化评价论文首页、2010熵权广义质量论文摘要与2019五种检验自述是不同版本/用途的来源，不能混成一个万能打分公式。3A/三化与5A检验也不因字母相近就当同义。原2008模型和2010全公式仍未逐页重建。

操作先写评价对象、任务情境和硬约束，再给指标定义、方向、量纲、证据、层级及重复关系。没有物理依据的隶属度不因画成0—1图就客观；没有价值依据的权重也不因来自计算就代表客户重要性。若某硬要求失败或证据未知，先显示该状态，不进入可补偿平均分。

完整构造示范有三条记录，区分性指标为1/2/3，第二指标恒5。按列比例p计算熵H=−Σp ln p/ln3，离散度1−H，再归一化。第一列有差异，第二列比例均为1/3、H=1，离散权重为[1,0]。这只说明样本区分力；第二项可能是所有方案都必须满足的安全边界，不能因零权就删。

给三个构造方案硬状态[unknown,fail,unknown]，教学行动先排除第二项作为当前实施符合候选，第一/第三进入补证队列，不输出质量总排名。若另有完全构造的明确硬状态[pass,fail,pass]且任务只选择“区分指标更大者”，可在这一单指标教学规则下选第三项；这个决定来自人为给定目标/硬状态，不来自“熵权证明价值”。若要多指标聚合，还须补主观取舍与隶属定义，不能无缝替换成熵权。

应把主客观权重分别展示，并解释结合规则、敏感性和样本变化。几条数据中的差异可能是测量噪声，缺少样本时熵权尤其易变。评价意见与测量值分别记录；专家意见也应有问题、依据与分歧，不把“专家参与”当免证。

两种误用是把变异度叫客户价值，以及用大量容易提高的指标抵消硬失败。另一种是不同年代评价方法随意拼表、却仍署名原作者统一算法。迁移到文档质量时，文件大小变化不表示可读/权限更重要，恒定的访问要求也不可删除。

R37帮助形成可讨论价值尺度，R42帮助证据与要求，R38可研究指标响应。本专题输出的是指标/证据/检验方式/模型身份与有条件结论，原作者体系与平台构造清楚分层，未有依据时不填总体质量分。
