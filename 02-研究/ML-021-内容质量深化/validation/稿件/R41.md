# 机械风险评估与降低：围绕人员任务、危险区与能量路径设计措施

机器正常运行时看似无人接近，并不能代表清堵、换件、清洗、恢复和可预见误用时安全。风险研究应把人在什么任务下接近哪种能量、可能发生何种伤害讲清，再比较设计消除/降低、防护及使用信息。HSE公开指南提醒关注使用、故障与维护情境；本文用其一般工程提示，不提供某市场法规合格判断。[HSE，Introduction to machinery safety](https://www.hse.gov.uk/work-equipment-machinery/introduction.htm)

先声明设备/使用边界、人员角色、生命周期、任务和外部环境，再画危险区及能源路径。记录移动、重力、弹性、压力、电源等可能持续/恢复的作用，避免把“电源已关”当所有能量消失。风险估计需要后果、暴露、危险事件与避免/限制伤害可能性证据；缺资料先查证，不凭AI编风险分。标准适用由产品分类、市场和具体范围决定，农业标准不得自动套林业。

构造清堵例：夹具含上方可下落滑块、压缩回位弹簧与电驱。维护者想移除接触区残料。任务表分别列“发现卡阻—请求停止—隔离/约束—确认状态—介入—退出与恢复”；切断电驱不会消除重力/弹簧。候选措施A只贴“维修前断电”警示；B进一步研究消除悬挂载荷/降低储能的结构；C为必须保留的能量设置可验证约束与防护接近协议。教学决策是拒绝把A当完整风险降低方案，优先研究B，再为残余任务建立C及信息，而非比较警示牌价格。

给一份完全构造的桌面证据：D1动力断开记录，只支持电驱状态；D2模型中滑块仍可因重力移动，反驳“断电即可安全介入”；D3修改结构将维护位置外移并对残余能量建立约束设计，尚缺实际承载和失效证据。由此行动明确：暂停原介入方案，先完成维护结构/约束的专业设计与验证，再评价残余风险。这不是指导未确认设备的实际检修步骤，也不表示D3已通过安全验证。

每项措施要写覆盖哪个危险/任务、正常与故障行为、所需证据、责任和剩余未知。若措施妨碍必要维护或诱发绕过，要回任务与设计，而不简单追加培训。两种误用是用说明书代替能量/防护设计，以及用“停止请求应答”替代实际停止和残能状态。没有伤害记录不等没有风险；观察频次亦不能直接等同事故概率。

另一情境折叠展架仍有夹点与重力，只是能量/人员/环境变化，应重新建任务链。R40帮助找失效传播，R51帮助查控制与反馈，R42形成配置化证据；本法的输出是风险研究及降低方案、验证与残余事项，而非合规证书或使用放行。
