# 多准则权衡：让“更好”背后的证据与取舍可以讨论

当轻便、维护、性能与成本不能同时改善时，多准则权衡帮助团队说明谁在取舍、取舍发生在哪个范围、哪些结论依赖偏好。它不把所有争议化成一张总分表。NASA决策分析框架强调决策背景、准则、替代方案、知识/偏好以及假设限制；本文加性价值示范为平台构造，不冒称NASA认可某组权重。[NASA，6.8 Decision Analysis](https://www.nasa.gov/reference/6-8-decision-analysis/)

先确定决策与可行性。硬要求失败的方案不得靠高满意分补偿，硬要求未知应列补证。随后把性能事实转成明确范围内的价值尺度：质量从10降到5kg对谁有多重要，和“轻便很重要”不是同一问题。用最差—最好摆幅问法，请责任主体比较完整摆幅，而非脱离尺度给抽象重要性百分比。记录回答者、条件、分歧及范围；量纲归一化本身不产生价值。

完整构造例中，服务性与移动性已经是人工定义的0—1价值：A=[0.9,0.3]、B=[0.4,0.8]；C=[1,1]但违反构造硬约束，因此先剔除C。假设可加分离，服务权重w，移动权重1−w，则U_A=0.3+0.6w、U_B=0.8−0.4w。交点w=0.5。w=0.2时A0.42、B0.72，选B；w=0.8时A0.78、B0.48，选A。若教学决策主体确认w=0.6，则A0.66、B0.56，选择A进入后续实施审查；这是一项有条件的完整决定。若主体只接受w∈[0.2,0.8]，结论应是偏好不足以产生稳定胜者，应澄清取舍，而不是擅自取中点。

以上价值、偏好主体与回答全部构造，非割胶客户访谈。实际项目应把原始性能表、映射函数和偏好记录分开。如果维修价值取决于移动性，或两准则存在不可忽略互补，就应回到交互模型或分场景比较，不能继续用这个可加式。若某性能仅知道区间，可先比较在区间与偏好范围内是否支配；缺值不能当0或持平。

两种实质误用是重复计分与摆幅偷换。质量和由质量计算的搬运成本若承载同一偏好，分别赋权会放大它；相关不必然重复，须核具体价值含义。另一种是在展示时悄改最佳/最差范围却保留旧权重，取舍已经变了，旧权重不可照搬。

操作产物依次为决策与责任、不可豁免条件、备选及性能证据、价值尺度、偏好提问与回答、模型假设、解析/情景敏感性和行动理由。执行前回查关键假设；若结论只在狭小权重区域成立，先考虑R52研究哪些信息可能改变选择。R36主要组织概念比较/组合改进，R37明确价值取舍，R42形成配置与用途证据。迁移到文档工具时仍须重新定义准则尺度和责任主体，不继承本例权重。
