# 理想最终结果与资源：减少新增负担，同时把守恒算清

理想最终结果IFR把设计注意力从“再加一个部件”转向“必要作用能否由现有系统和资源完成”。它是问题特定的目标表达，不是声称整机可以无能量、无载体工作。问题IFR与理想系统概念应分开。[E24-1]

## 资源不是看见就能用
先写必要作用及边界，再列物质、场、空间、时间、信息和已有变化过程。每项资源记录位置、可用时段、数量/能力、允许改变程度以及谁还依赖它。已存在的重力势能不等于可随意提取；若行程或方向不对，就不能算有效资源。

## 构造算例：借已有下降行程退出轻载指示片
教学假设：设备每次操作后已有1kg质量下降0.1m；g取10m/s²；允许分流的传递效率η=.5；指示片退出需要0.2J，必须在1s内完成；下降动作持续0.4s且发生在退出允许的3s窗口内。该质量下落不承担另一安全保持作用。

原方案为退出另加电机。IFR表述改为：“在允许退出时，现有下降过程提供退出作用，且不破坏原下降职责。”先不指定绳索或连杆。资源账E=mgh=1J，可用E_u=ηE=.5J，余量.3J；时间.4s≤1s且位于窗口。可以选择“借下降行程传递退出能量”进入机构概念研究，暂缓新增电机。

|资源|位置/时机|能力|必须继续核查|
|已有下降质量|本循环尾段|.5J假设可用|力—位移曲线与冲击|
|退出窗口|下降过程内|3s容纳窗口|不同模式是否一致|
|连接路径|尚未实现|未知|反驱、卡滞和独立恢复|

这只是能量与时间必要条件满足，不能由.5J推导全程力足够。例如需要2N越过0.1m，但传动在某点力为零，能量够仍可能过不了死点。下一步必须把能量预算转成传力曲线和失效恢复。

## 失败与跨情境迁移
若安装转180°，原下降方向成为上升，重力对所需位移做负功，资源路线应拒绝。若可用能量恰等于所需而无不确定度余量，不能称稳健。若该势能本来用于断电安全回退，分流可能破坏安全支撑；先重建资源所有权。

迁移到数字工具可利用已经生成的版本差异提示复核重点，而非再做全量比对；但差异完整性与权限是新的约束，机械效率不能解释算法覆盖率。R24用于收紧理想作用和资源假设，R27寻找外部功能机制，R26则检验能否删去特定功能载体，三者目标不同。
