# 拓扑优化：把材料分布问题算清，再决定它能否变成结构

拓扑优化首先是一项有边界的设计计算：给定载荷、支撑、材料模型、设计域和约束，让材料分布朝某个目标变化。它能帮助发现承载路径；它不会自动证明载荷选对、密度图能制造或最终零件抗疲劳。本稿从一套已经实际运行的教育模型讲完整过程，明确指出哪里得到改进、哪里必须回返。

依据是Sigmund 2001年教育论文的静力柔顺度问题与滤波讨论【原典选段】；具体Python实现、悬臂边界、密度滤波和结果为【平台数学模型】。二者不是同一版本。[E35-1][E35-2]

## 先把设计任务写成一个可以求解的问题

本例要在二维长方形域中分配材料，支承一个单位向下载荷。设计域长2、高0.8、厚度1；全部是归一化教育量，没有对应机器的毫米、牛顿或材料牌号。左边所有节点的两个平移自由度固定；右边中点施加−1的竖向载荷。优化目标为最小柔顺度 (c=f^Tu)，约束物理密度平均值不超过0.45。

柔顺度衡量的是这组载荷下的变形代价；在相同载荷下，越小意味着整体越刚。它不是最大应力、重量、疲劳寿命或综合质量的另一名字。若实际目标是避开共振、抵抗屈曲或降低应力，应另建目标与约束，不能仅换一个图例标题。

| 冻结输入 | 本例取值 | 为什么必须保存 |
|---|---|---|
| 材料 | (E_0=1, 
u=0.3)，线弹性平面应力 | 材料模型改变，刚度与应力解释随之改变 |
| 网格 | 20×8个四节点单元；另算30×12 | 网格决定离散空间，不能凭单一网格宣布可信 |
| 刚度插值 | (E=10^{-6}+(1-10^{-6})\rho^3) | 最小刚度是数值残材，不是真空洞 |
| 设计变量 | 每单元一个密度变量，0.001至1 | 保持数值可解，同时引入中间密度解释问题 |
| 物理滤波半径 | 0.18；另算0.26 | 固定物理长度比只固定“几格”更便于网格对照 |
| 更新与停止 | 移动限0.1；最大160轮；最大变量变化<0.005 | 必须分清迭代上限与达到变化停止条件 |

【原典与变体区别】原论文Eq.1写体积等式，Eq.5—6说明敏度滤波。本平台使用体积不等式，并对密度先滤波、再按链式法则求导。不能将平台变体的结果当原99行程序的逐字复现。[E35-1]

## 从输入到一次迭代，究竟发生了什么

**1. 建立均匀起点。** 每单元设计密度先取0.45。这不是发现了结构，只是满足体积条件的一组初值。

**2. 把密度变成刚度。** 先用相邻单元距离构成归一化权重矩阵W，得到物理密度 (\rho=Wx)。再按上表插值形成各单元刚度。平台四节点单元采用2×2高斯积分，组装全局K后，对自由自由度求解 (Ku=f)。

**3. 看材料放在哪里更有用。** 每个单元的变形能 (u_e^Tk_0u_e) 进入柔顺度导数。对物理密度的导数为负：在此线弹性模型中增加材料会降低柔顺度，但体积预算不允许所有地方一起变实。密度滤波后，设计变量的导数需乘W的转置，不能直接把物理密度导数当x的导数。

**4. 在材料预算内重新分配。** 更新规则比较改善趋势与体积约束，通过二分寻找体积乘子，并限制单步变化。材料会从贡献较小处转向更有利的承载路径。下一轮再解平衡，不能只改颜色不重新计算。

**5. 同时保存三种不同的“误差”。** 平衡残差检查线性方程是否解好；体积残差检查材料预算；设计变化检查迭代是否稳定。它们回答不同问题，不能互相替代。平台还对一个选定变量做中心有限差分，检查导数实现是否与目标变化相符；它不是对全部变量和所有模型的证明。

```mermaid
flowchart LR
 A[设计域＋支撑＋载荷] --> B[设计密度x]
 B --> C[滤波得到物理密度]
 C --> D[组装K并求位移]
 D --> E[柔顺度与导数]
 E --> F[受体积约束更新]
 F --> B
 D --> G[平衡残差]
 F --> H[体积与变化账]
 H --> I[停止或保留未收敛]
 I --> J[几何重建后重新分析]
```

## 实际结果怎样改变设计判断

以下读取已冻结的实际计算输出，不是为说明方法临时补造的成功结果。[E35-2]

| 同载荷研究 | 首轮柔顺度 | 最终柔顺度 | 轮数/最大设计变化 | 可作的判断 |
|---|---:|---:|---|---|
| 20×8，半径0.18 | 767.188 | 243.920 | 160轮；0.00770 | 确有模型内改善，但达到上限而未满足0.005变化标准 |
| 30×12，半径0.18 | 774.128 | 242.397 | 160轮；0.01353 | 最终数值接近基线，不足以宣布网格收敛或设计收敛 |
| 20×8，半径0.26 | 767.188 | 305.216 | 91轮；0.00497 | 达到本次变化标准；较大滤波半径也改变了问题的可用设计空间 |

三者最终物理体积分数均为0.45。自由自由度相对平衡残差约(10^{-13})，说明给定离散模型的方程求解较精确。它不能取消前两组未收敛的事实，也不能证明模型代表真机。

现在形成一个有依据的**工作选择**：不要继续把基线243.920的密度图包装成最终结构；先选择已满足变化标准的0.26半径结果，专门研究“密度结果怎样转几何”的问题。选它是因为本轮要检查重建过程，不是宣布它比0.18问题的全部潜在解更优。

## 重建不是截图：一个足以让方案回返的结果

平台将物理密度按0.5阈值转为二值栅格，再重新组装求解。得到：

| 重建对象 | 二值体积分数 | 重算柔顺度 | 后果 |
|---|---:|---:|---|
| 基线0.18 | 0.4625 | 475.444 | 已超过原0.45体积预算；不能沿用原密度结果放行 |
| 细网格0.18 | 0.4500 | 314.088 | 体积满足，但响应变化；原迭代仍未收敛 |
| 半径0.26 | 0.3500 | 2,381,985.576 | 二值化后承载表现灾难性变差，必须回到重建/设计问题 |

第三行尤其重要：一个已经满足“设计变化停止”的密度场，阈值后仍可能失去关键传力路径。当前数值残材使模型仍能求解，但极大柔顺度清楚表明，不能把该栅格当可用结构。下一动作是检查细连接、中间密度依赖及重建策略，研究最小特征/投影或几何约束，再重算；这些改进尚未在原求解器实施。

这不是“优化方法无效”，而是指出原问题只优化连续密度，没有保证任意阈值后的结构性能。重建后的新几何就是新分析对象，应有自己的体积、载荷路径与验证记录。

## 两种常见误用，以及跨情境时怎么返回

**误用一：把小平衡残差当设计充分。** 即使K求得很准，支撑刚度、载荷方向或接触边界若错，结果也可能错。真实项目须取得边界证据并做敏感性，而不只收紧线性求解容差。

**误用二：把最深的黑色区域当最终零件。** 阈值会改变体积和连接；网格应力还受点载荷、残材及尖角影响。当前记录有归一化高斯点等效应力，但没有真实许用值或疲劳依据，因此不是强度认证。可制造CAD、独立软件复核、疲劳与屈曲均是明确的后续工作。

另一个实际计算把载荷移到右上角，得到不同密度与233.915的柔顺度。它是另一载荷问题，不能与中点载荷的数值直接排优胜；它说明展示支架等迁移场景必须重建力作用位置，而非复用一张“好看的梁”。

交给R33的是实际材料/方向/温度状态，交给R34的是制造方式、最小特征与支撑条件，交给R42的是重建版本、载荷工况、误差与验收问题。传递密度数组时必须同时传问题定义和求解状态，不能只交图片。
