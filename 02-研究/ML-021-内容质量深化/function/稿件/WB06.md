# 动态设计：把工况带入模型，静态变好不保证动态变好

2003论文讨论动态设计向非稳态、非线性、强耦合、高维、多参数方向发展；2019自述也表明振动不仅需要控制，也可能被利用。它不意味着所有产品都应压低振幅，更不意味着普通线性模型就是作者完整深层次动态设计法。[EWB6-1/2]

## 建模前的四个问题
作用是在稳态还是启停/冲击中？边界如何固定？哪些质量、刚度、阻尼和激励真正参与目标响应？用什么测量检验模型？模型必须绑定安装配置、频段和作用量；换配置不自动沿用。

## 构造例：增加刚度导致工作点共振
采用平台线性单自由度模型m x''+c x'+k x=Fsinωt。假设m=1kg、c=2N·s/m、F=1N、工作ω=√1000≈31.623rad/s；教学频段1–50rad/s，非实测有效带宽。候选A k=500N/m，候选B k=1000，修订C k=2000。用X=F/√[(k−mω²)²+(cω)²]、ωn=√(k/m)、ζ=c/(2√km)。

|候选|静位移F/k m|ωn rad/s|工作幅值X m|ζ|
|---|---:|---:|---:|---:|
|A|.002|22.361|.001984|.04472|
|B|.001|31.623|.015811|.03162|
|C|.0005|44.721|.000998|.02236|

若教学工作幅值要求≤.003m，A满足、B失败、C满足。B静态位移更小却把固有频率移到激励处，形成反例。选择C作为进一步结构研究方向前，必须确认刚度可实现、质量变化和新模态；不能只把k改数。若选择保留B而提高阻尼，在ω=ωn处X=F/(cω)，需c≥1/(.003×31.623)=10.541N·s/m；这给出另一个可比较的参数目标，但阻尼件温升/行程/代价仍待证。

完整动作是：建模→算工作点与频扫→比较约束→提出增刚或增阻尼两个参数路线→检查实际结构耦合→设计辨识/验证。原教学做过有限差分核一个频率导数，它只检查局部计算，不证明真实参数辨识或完整模型有效。

## 失败与不同场景
激励频率未知不能取0作静态；应先测谱。已知撞击/摩擦接触强非线性时，不能用稳态正弦幅值判定安全；需更合适模型。单自由度响应小也不保证其他模态/应力低。

迁移到展示支架，重新确定安装和激励，若激励是观众碰撞而非持续谐波，应做瞬态与限位研究；不继承本例.003m边界。与R32相比，本项研究运动响应/载荷，R32先研究几何运动；R35配置材料也要把动态目标另列，静态柔顺度不是振动性能。
