# DFMA：减少装配负担，不用零件数代替生产表现

DFMA把可制造性与可装配性纳入设计早期。先问每个独立件为什么必须存在，再看抓取、定向、插入、连接、检测与维修。它不等于“件越少越好”，也不能用未经授权的时间表算出认证式DFA指数。[E34-1]

## 从功能必要性到操作序列
对每个零件核三类问题：相对运动是否要求独立、材料/隔离要求是否不同、装拆服务是否必须分离。不是三个“否”就自动删除，还要检查功能接管、工艺、公差及维护。然后画实际装配顺序，记录动作和等待；单次装配工时不同于流水线节拍、产能和良率。

## 构造例：三件式反而比两件式易装
对象为桌面非承压外壳，件H壳体、S密封圈、C盖。教学要求密封圈可单独更换，装配操作必须单面可达。方案A三件：放圈4s、定位盖4s、闭合2s，共10s。方案B把圈与盖整合成两件：插入整合件10s、调整10s，共20s。时间为人工设定的教学动作值，没有现场计时或专有数据库支持。

|比较|A三件|B两件|决定依据|
|---|---:|---:|---|
|件数|3|2|不能单独决定|
|装配动作总时|10s|20s|A较少|
|密封圈独立更换|可以|不可以|B违反教学硬约束|
|制造/采购代价|未知|未知|不得补零算总成本|

因此在已给条件下保留A，拒B原整合方案。接着提出B2：仍使用可更换圈，但盖增加导向，假设放圈4s、定位2s、闭合2s=8s。B2并未减少件数，却有可解释的动作改进，选入装配样机对照。导向是否增加模具成本、会否卡圈，需要后续制造与公差研究。

## 失败、迁移及邻近法
件数减少而需要双手翻转、盲插或额外返工，可能使装配更差；必须看序列。把10s工时叫生产节拍会忽略并行工位、设备等待、换线及不良返修，不能据此承诺每小时产能。把密封件永久整合会损失维护作用，应回R26核功能接管。

迁移到文件打包，可以合并重复附件来减少查找，但若不同附件有独立版本/权限职责，合并反而增加误用；重新记录生成、核对、发布与回滚步骤，不照搬秒数。DFMA评价制造和装配机制，R26研究载体是否可去除，R33研究材料与自由形状，两者可提供输入但不替代动作研究。
