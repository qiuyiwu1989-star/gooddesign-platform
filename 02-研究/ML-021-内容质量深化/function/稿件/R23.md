# 物理矛盾与分离：把相反要求安放到准确的条件中

物理矛盾不是“希望成本低、性能高”。它要求同一对象的同一参数，在明确条件下分别需要相反状态。若相反状态其实指不同对象，先重写模型；若只是连续参数优化，不要强套分离。[E23-1]

## 从口号到可检查的分离
先锁定对象、参数、单位、需要高/低的原因、对应区域与时间。再问：两种要求是否同时同地？若不是，可探索时间或空间分离；若与外部条件有关，要定义触发条件和状态切换；若同一局部要求不能解开，可研究系统层次。分离方向是探索路线，不能代替机构响应和安全证明。[E23-2]

## 完整构造例：推送夹持与退出释放
假设桌面惰性工件夹持装置：推送段t∈[0,2]s，需法向力N≥10N以抵抗最大滑动载荷；退出段t∈[2.2,3]s，N≤1N以便取件；[2,2.2]s是允许切换窗口。两个区间不重叠，负载只在推送段出现；这些均为教学假设。

固定12N夹持满足推送但取件失败；固定0.5N满足取件但推送失败。物理矛盾为同一夹持界面的N需要高与低，但分别在两段时间。选时间分离，候选凸轮控制夹爪：推送12N，释放0.5N，假设实际切换耗时0.1s。

|中间检查|算式或条件|裁决|
|推送|12≥10N|满足模型下限|
|退出|0.5≤1N|满足模型上限|
|转换|0.1s≤0.2s窗口|可安排|
|单次循环|3s内两个稳定段及过渡均有定义|候选完整|

选该候选进入台架，不是因为“分离必有效”，而是相反要求有非重叠条件，且假设响应能放入窗口。补充研究是响应散布、重复定位、断电态和负载消失证据。若真实响应0.3s，方案不满足窗口，应扩大允许窗口、改驱动或重建条件；不能将窗口填大来通过。

## 失败反例与迁移
若同一时刻同一接触区域既要N≥10又要N≤1，以上时间分离无效。必须检查功能是否能转移到不同接触区或层次，不能偷偷给其中一个要求换时间。若切换所需输入是未知，写成0s是假完成；维持未证并安排测量。

迁移到文档发布，可把草稿阶段可编辑/冻结阶段不可编辑分离；但要定义状态转换权限和并发窗口，不能仅凭“前后阶段”消除同时协作冲突。物理分离不是R22两个参数权衡，也不是R24理想结果宣言：它给出相反状态条件化的机制入口。
