# 材料选择：性能指数只在对应约束和自由几何下有效

材料选择先确定功能、硬约束、优化目标和可改变的几何。脱离形状和载荷，“某材料性能最好”通常没有意义。性能指数把目标中的材料项提取出来，帮助筛选；前提是相应约束确实控制设计。[E33-1]

## 同一对材料，为什么排名会反转
以下是明确假设的虚构点值，不是任何合金的设计许用值：A的E=70GPa、ρ=2700kg/m³、许用应力300MPa、最高服务温度120°C；B分别210GPa、7800kg/m³、900MPa、80°C。任务F=100N、L=.3m、位移≤.001m，目标最小质量，几何可连续变化；先忽略制造最小尺寸、自重、屈曲、疲劳和连接。

### 情境一：轴向拉杆
自由截面积S，位移FL/(ES)，强度F/S。所需S=max(FL/(Eδ),F/σallow)。A得S=4.2857×10⁻⁷m²（刚度控制），m=ρSL=.00034714kg；B得1.4286×10⁻⁷m²，m=.00033429kg。B略轻。对应刚度控制指数E/ρ越大越好，但若强度或制造尺寸控制，必须换式，不能继续按E/ρ选。

### 情境二：方截面端载悬臂
自由边长b，I=b⁴/12；δ=FL³/(3EI)=4FL³/(Eb⁴)，σmax=6FL/b³。b=max[(4FL³/Eδ)^(1/4),(6FL/σallow)^(1/3)]。A刚度边长约.019819m、质量约.31816kg；B约.015059m、质量约.53066kg，仍由刚度控制。此时A更轻，对应指数√E/ρ。排名反转来自力学与自由几何不同，不是数据库不一致。

|选择步骤|轴向杆|悬臂梁|
|---|---|---|
|筛除硬约束|温度与环境先查|温度与环境先查|
|推导尺寸|S取刚度/强度最大|b取刚度/强度最大|
|比较目标|B略轻|A较轻|
|下轮待补|细杆制造/屈曲适用性|连接/疲劳/最小厚度|

若服务温度100°C，B的假设80°C上限使其先被排除，不能因轻量排名更高而保留。若材料服务温度未知，则进入补证，不当无限大。温度筛选优先于软目标排名。

## 失败与迁移
固定外形不能按可自由缩放截面的指数排名；应直接计算真实外形性能。把目录中的强度当疲劳许用值，会把材料筛选变成危险的设计结论。缺成本数据却将成本置零，也会扭曲选择。

迁移到软件存储方案，可保留“先硬约束、再目标、复核控制条件”的逻辑，但E/ρ等物理指数不能迁移，必须重建容量、时延和持久性的模型。与VE相比，本法聚焦材料/几何性能筛选；VE还要在功能及全寿命代价上比较系统方案。
