# ARIZ-85V：用严格重述和回返推进难题

ARIZ是一套求解发明问题的思维流程，适用于通常改良仍被冲突束缚、且能明确技术系统边界的任务。它不是把九个栏目填满的模板，也不是软件已经实现的九步求解器。本稿使用基金会西语**ARIZ-85V**（1985署年，Tatiana Zagorodnova译，Juan C. Nishiyama与Carlos E. Requena审），不自动与85C及其他译本合并。

## 九部分怎样连接
下表是职责概述，不是全文翻译，也不包含附属标准/物理效应库的完整执行规则。每一部分保留自己的输入与回返意义。[E28-1]

|部分|要形成的中间产物|不能跳过的判断|
|1 问题分析|最小问题、冲突双方与相反状态、主过程、强化模型|模型是否仍对应原任务；1.2/1.3后重查1.1|
|2 问题模型分析|作业区、作业时间、物质场资源清单|资源是否在需要的地点/时段可得|
|3 IFR与物理矛盾|宏/微状态要求及IFR2|同一作用区相反状态是否准确；不是早早宣布解|
|4 资源动员|现有/派生资源的变换探索|小人建模是辅助，不是物理可行性证据|
|5 知识库使用|标准、类似难题、分离及效应的有据探索|匹配前提；不能凭空声称标准命中|
|6 改变/替换问题|技术方案，或拆分问题/换冲突/上移超系统|无解时允许改问题，但须保留理由|
|7 解的质量检查|与IFR、物理矛盾、真实多循环的对照及新子问题|自检不满意可返1.1；专利新颖性需另外查|
|8 使用所得答案|超系统变化及其他用途、原理泛化|迁移是再次考察，不是普遍有效认证|
|9 求解过程复盘|实际与理论路径差异、新知识/方法登记|不能把一次特殊捷径改成通用算法|

原文部分3已有解可向7推进但建议继续4；部分5说明4未解再用知识库；这些是有分支的循环，不是九项必须等时顺序填完。本轮补读P4/5/7/8/9，消除旧稿只读1/2/3/6的限制，但**软件教学仍未完整实现九部分**。

## 构造一段有实际回返的求解链
输入沿用独立桌面夹持例，非真实割胶载荷。假设推送段需要N≥10N，释放段N≤1N，切换窗口.2s；原固定夹持12N。最小问题是“保留推送可靠保持，降低退出阻力”，而不是“买新智能夹爪”。1的两状态图分别为高力保持好/释放差、低力反之；2把接触区、两段时间及现有凸轮资源列出；3形成按时间改变接触载荷的IFR方向。

4优先研究现有凸轮能否提供切换；假设首轮估算切换需.3s，超过.2s，不能在此停下称解决。5可以查分离/效应知识，但这里没有取得匹配效应条目，不填命中。6回查最小问题，发现原来把“释放”和“取件”捆为同一事件；若工艺允许将取件前的空闲段延长至.4s（**这是新教学假设，不是客户批准改要求**），则新版本得到.3≤.4s，形成新的条件方案。

|版本|改变了什么|结果|尚未闭合|
|P1|窗口.2s，现有凸轮.3s|失败并返问题|不能偷偷改输入|
|P2|明确申请/设定空闲窗口.4s|时间必要条件满足|断电态、循环散布和接触负载|
|P2质量自检|只证明一次模型循环|不能称多循环通过|第7部分要求列多循环问题|

若窗口为不可改硬约束，就不能选P2，应保留unsolved并找更快机制。正向结果是找到“可申请改变作业节拍”的有条件设计路径，同时清楚标出谁需作决定；不是凭术语给工程解盖章。

## 失败、邻近方法与迁移
把两个不同参数写成物理矛盾，会把后续资源搜索带偏；应退回1重述。找到“分时”一词就停在3，不计算转换和真实多循环，会遗漏实施问题。另一个失败是用一个成功故事倒改ARIZ流程，第9部分的比较与积累不能被一次故事取代。

迁移到文件分享：便利访问与未授权暴露可以整理为不同角色/时段要求，但必须重新定义身份校验、撤销和缓存，不可照搬夹持力。ARIZ组织长期求解与问题重述；R23是其中可能用到的局部矛盾处理；R27负责外部机制来源，不等于整套ARIZ。
