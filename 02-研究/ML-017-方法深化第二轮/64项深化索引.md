# 64项逐法深化索引

52个方法档案与12个闻邦椿谱系专题，均有单独分析。此表为第二轮深化研究与具体补强设计，不是64项完整原典研究或64项执行器交付。

|R03|[设计思维](逐法档案/R03.md)|按学习目的选择具体研究动作，拆开同理、定义、生成、原型和测试的作用。|同一概念做纸面交互原型和机制台架，分别记录任务、观察、解释及设计修订。|
