# 方法库深化第二轮 · ML-017

阅读入口：[深化方案与结论](00-深化方案与研究结论.md) → [64项逐法索引](64项深化索引.md) → [重点补证与复算](01-重点补证与复算.md)。

本轮交付是64项有区别的深化研究与补强设计、来源复核和两项实际数学复算。并不是64项完整原典重建或专家认证；线上方法页、冻结原库与MCP契约未改。

## 文件用途

- `逐法档案/R01.md`至`R52.md`、`WB01.md`至`WB12.md`：逐项分析、专家判断点、研究包、反例、交接与来源状态。
- `逐法研究判断.tsv`和`逐法推演片段.tsv`：本轮逐项原创分析及判断推演真源，供后续继续研究，不是自动评分表。
- `来源复核台账.json`：80个公开URL的取得状态、实际核读范围和身份问题。64次机器取得中包含无效内容，不等64部有效全文。
- `研究清单.json`：64报告与第一轮来源SHA绑定，未决项保留。
- `教学复算/`：两个局部数学复算的输入/输出。构造材料参数与NIST公开数据严格分开。
- `检索取证.py`：仅抓公开来源；新取件保存到外置盘`output/method-deepening-ML017/private-sources/`。取得成功不自动晋升证据。重新运行会生成新时间的取得清单，网页内容可能变化。
- `生成研究档案.py`：将人工编制判断与现有取证记录渲染为64报告；不自动生成专业结论。需保留本次取得清单或重新取证后人工复核。

## 复算

在项目根目录执行：

```sh
python3 '02-研究/ML-017-方法深化第二轮/R38-公开数据复算.py'
python3 '02-研究/ML-017-方法深化第二轮/R33-指数适用性复算.py'
```

R38需要NumPy；输入已附NIST原始公开数据文件，通常不再联网。R33只用Python标准库。工具及BLAS差异可能改变末位，不保证跨机器输出文件字节完全一致；论文对照采用已写明的数值容差。两者都不是工程选型器。

PDF公开原件、提取全文及核读截图只留在外置盘的output私有取证目录，不打包进入公开网站，不因本地可读就默认为可商业转载。
