# 产品与机械创新方法论研究包

日期：2026-10-22｜0.1.0

**建议先读 [调研报告](01-调研报告.md)，再看 [首批12项研究笔记](04-首批12项封装研究笔记.md)。**

本包包括48个研究候选和47条来源记录。方法、框架、工具及计算方法分层；公认依据与实际核读深度分开。研究候选未自动注册到现行方法库。

| 文件 | 用途 |
|---|---|
| [01-调研报告.md](01-调研报告.md) | 结论、全景目录、优先级与研究边界 |
| [02-来源与核验范围.md](02-来源与核验范围.md) | 查看原典与每条来源的读取范围 |
| [03-方法库调用结构与建设路线.md](03-方法库调用结构与建设路线.md) | 后续结构、调用与评估建议 |
| [04-首批12项封装研究笔记.md](04-首批12项封装研究笔记.md) | 首批输入、步骤、产物及反例 |
| [方法研究目录.csv](方法研究目录.csv) | 用表格工具筛选分类、优先级、输入输出 |
| [方法研究目录.json](方法研究目录.json) | 机器读取的研究清单，非可执行方法卡 |

| [文件校验清单.json](文件校验清单.json) | 文件SHA256与结构检查 |

P0是平台建设建议。部分P0仍缺直接方法步骤原典；没有专家审核或工程有效性验证。标准付费正文、商业卡片、专有数据库和矩阵数据未默认取得许可。JSON/CSV可供后续入库整理，不代表现行引擎能够执行它们。
