# R25 物场分析与标准解 v0.1.0

本包真正核读并实现的是一条有版本定位的局部门禁，不能称76条标准解求解器。已取得MATRIZ机构21页英文列表，PDF第1页文字及图形均核读。1.1.1针对对象难按要求改变且不限制引入物质/场的情境，考虑补缺失要素；不将未知限制当作允许。原典书目与译者没有在取得页面确认，不能仅凭2025上传目录声称原著年份。

建模首先明确S1作用对象、S2作用载体、F作用场及实际参数变化，随后判断是缺要素、有害、作用不足还是未知。两种物质存在并不证明作用充分；反过来，生物边界未知也不意味着物场不完整。割胶声明图已经有树体、工作件与机械作用，不能为了套补全规则虚删一项。缺证据时先补作用图和测量，不自动加传感器、能量场或化学添加剂。

独立抽象教学仅有对象角色，明确假设对象难改变、允许增物质与场，返回缺S2与F的研究提示。变换图保留原对象，补两个未知角色；这还不是机构或有效作用。另一情境已有惰性试块和加热件但未定义能量耦合，得到缺场角色提示；并未证明加热均匀、可控或安全。不能把图中F写成某个词就说物理机制已证。

代码先查难改变条件与分类，再查引入限制显式布尔值，最后比较S1/S2/F集合。禁止引入或限制未知都不能用这条规则推进。仅声明不完整但三角色都在则退回模型分类。选择别的标准必须另核原文与适用前提，未将其余75条臆造补齐。

流程：作用对象与参数 → 实际作用图 → 问题状态 → 选定标准及前提 → 变换角色 → 可解释物理机制 → 禁止改变项/副作用 → 试验。本包只到角色提示和取证问题；加入物质的生物污染、改变场的组织损伤、残留物和原有有用接触均需独立核查。交接给功能/材料/验证研究，不是下发制造指令。
