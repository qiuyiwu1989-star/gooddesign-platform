# R23 物理矛盾与分离：受限深化研究 v0.1.0

核心先是重写问题，之后才生成分离候选。对象、同一属性、两侧方向、各自理由与条件必须逐项列明。“精度高而成本低”是两个参数，并不能直接当作同一物理参数的两种状态。本包没有把参数自动抽取当作已实现功能。

来源核读：MATRIZ Level1手册PDF第53页区分单参数物理矛盾与双参数工程矛盾；54页列空间、时间、关系及系统层级方向；56及59页分别限定不同位置、不同时间。62及64页核了关系对象和层级差异。仅总结这些事实，不复制手册图例、规则全集或课程内容。第一页有会员使用及商业衍生限制；取得公开URL不等于取得商业内容再发布许可。原件留private-sources，不上线。欲将完整课程或规则原文作为商业库内容，须另核授权；本包原创条件检查并非手册复刻。

教学输入是独立夹持问题，不来自割胶现场：同一夹持力在作业与换件阶段有高低方向要求，阈值仍null。构造时段[0,4]与[6,8]秒、切换1秒只用来复算窗口；不表示机器人实际时序。正常例得到时间分离研究候选。这里“候选”只意味着声明的时段有正余量，未测夹持力、误差、余能和失效。

判定过程：核对象/属性/单位→核方向是否相反→核条件和切换量是否已知→算区间重叠与空窗→空窗必须严格大于构造切换时间，否则返回不足。相等边界也不标通过，因为未留任何不确定性余量。实际工程尚需另订可接受裕度；程序没有擅自生成客户阈值。

同时同地两侧要求重叠时，时间分离不能成立，须重新查空间、交互对象或层级可否区分；不是自动宣告无解。三种非时间方向仅形成待核候选，未实现自动分离机制选择。把部件一拆为二也不证明原功能均保留，应交R14/R26做作用和接管闭包。

图示：同参两方向 → 条件表 → 重叠/切换窗口 → 待研究候选 → 机构/过渡工况验证。状态未知→补材料；重叠→返回重新表述；有窗口→仍待工程研究。

交给R32的是结构实现问题，交给R38的是切换时间、误差和工况实验设计，交给R41的是残余能量与异常状态风险。不把这三项交接说成已经执行。自动程序仅审明示区间，不能判人填写的对象属性是否真的同一属性。
