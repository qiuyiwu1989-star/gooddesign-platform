# VOI教学算例独立核对

2026-10-27。核对scripts/method_depth_voi_demo.py及教学演算/VOI-二行动二状态.json；仅独立Agent的精确算术与边界核对，非领域专家审核。

## 独立重算

教学先验两个状态各1/2；M两状态损失0、100，S为30、40。当前E[L(M)]=50、E[L(S)]=35，故当前期望损失35。完全信息后分别选M与S，期望损失20，EVPI=35−20=15。

灵敏度/特异度均4/5时，正、负观测概率各1/2；正观测后困难态概率4/5，M损失80、S损失38，选S；负观测后困难态概率1/5，M损失20、S损失32，选M。因此研究后期望损失(38+20)/2=29，EVSI=35−29=6，研究代价4后净学习价值2。独立Fraction算术与生产者已落盘JSON逐项一致。

## 实际边界核对

在不调用生产者run()、不重写其输出的情况下，读取模块并单独检查analyse：无信息研究(灵敏度/特异度均1/2)的EVSI为0；完美研究的EVSI为15=EVPI；先验6/5被ValueError拒绝。三个边界通过。

## 解释限制

概率、损失、代价均为明确编造的教学假设，单位不是货币。结果不是割胶机械/传感路线实际比较，也不说明真实传感器的灵敏度或特异度。此算例没有把安全约束货币化，因此不能以净值为正取消必需验证；一般VOI还需研究观测模型、损失定义与适用条件。该核对证明的是这一个二行动二状态算例的算术和三个边界，不是通用VOI求解器认证。
