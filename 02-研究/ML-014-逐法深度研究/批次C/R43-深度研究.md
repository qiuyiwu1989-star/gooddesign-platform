# R43 生命周期评价与生态设计：第一轮深度研究

日期：2026-10-27。性质：来源核对与平台研究分析；非领域专家审核、工程验证或新执行契约。

## 核心机制：真正应深入的是什么

LCA首先定义要比较的服务，再确定为提供这项服务所需的参考流。EPA的功能等效说明意味着“每台设备更轻”不等于“同样任务更环保”；寿命、利用率、耗材和失败返工都可能改变分母。

## 关键决策与返回点

关键决定依次是功能单位、系统边界、数据代表性、分配/系统扩展和影响类别。碳排只是一个指标，低碳不自动等于低毒或低资源负担；不可把不同功能产出直接按设备重量比较。

## 可复查的教学推演

教学比较设想：以完成相同质量口径的一定服务量作单位，再记录设备制造、能源、刀具/清洗耗材、维护、报废和失败任务的参考流。当前合格割胶服务量的定义尚未客户确认，不使用真实数值，不宣称机器人比人工环保。

除明确注明已执行的数学教学计算或既有教学程序外，上述是**设计与推演，不是本轮实测**。真实工程仍须补对象、工况、资源与专业确认。

## 与邻近方法的区别

R45讨论功能与全寿命成本，R43讨论环境影响，边界可以协调但价值口径不同。两者都不能由采购价或设备质量单指标替代。

## 方法引擎可用的输入、产物和拒绝条件

输入：功能单位、边界、BOM/能耗/寿命、地区年份、数据质量与评价方法。输出：清单和影响解释、敏感性及缺失数据。功能不等效或关键阶段缺失时拒绝比较性环境优胜结论。

这部分是平台接口建议，不能据此声称已有运行实现、已核全原算法或可直接控制设备。
