# WB10 设计质量检验与综合评价：第一轮深度研究

日期：2026-10-27。性质：来源核对与平台研究分析；非领域专家审核、工程验证或新执行契约。本条是闻邦椿谱系专题，不计为已还原的独立算法。

## 核心机制：真正应深入的是什么

本轮目读2006原文印刷533页，确认其两层模糊评价是每组B_d=A_dR_d再上层B=AR。权重、等级与隶属矩阵必须先定义。2010论文检索摘录提到3A及熵权，但正文请求内容类型不支持，不能据其摘要升级成完整熵权算法。

## 关键决策与返回点

先区分效用、等级隶属和概率；再检查权重是否归一、指标是否重复、等级方向是否一致，以及最大隶属判定是否掩盖临界差异。所谓数据“客观赋权”衡量离散度，不自动代表用户价值或安全重要度。

## 可复查的教学推演

本批实际计算纯教学矩阵A=(0.6,0.4)，R两行为(0.8,0.2,0)、(0.1,0.6,0.3)，得到B=(0.52,0.36,0.12)，见教学演算.json。它只证明给定矩阵的算术，不能说产品有52%概率优秀，也不能把某项安全失败被其他指标补偿掉。

除明确注明已执行的数学教学计算或既有教学程序外，上述是**设计与推演，不是本轮实测**。真实工程仍须补对象、工况、资源与专业确认。

## 与邻近方法的区别

模糊综合、物元、AHP和熵权是不同模型或赋权环节，不能混接公式。R37是更广的多准则决策框架，WB10保留原作者相关评价路线，但需拆成有出处的子模型。

## 方法引擎可用的输入、产物和拒绝条件

输入：等级定义、指标/组层级、权重依据、隶属规则及数据。输出：向量、敏感性和未补证。零离散、缺值、非法归一或硬门槛失败应停止/单列；不将综合分当符合性认证。
