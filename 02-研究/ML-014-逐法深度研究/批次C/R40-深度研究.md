# R40 失效模式与影响分析：第一轮深度研究

日期：2026-10-27。性质：来源核对与平台研究分析；非领域专家审核、工程验证或新执行契约。

## 核心机制：真正应深入的是什么

FMEA从被分析对象的功能出发，依次区分失效模式、影响、原因与当前控制。ASQ过程强调先界定范围和功能，再识别失效；因此直接从零件清单批量填“损坏”会把有意义的失效情境抹平。

## 关键决策与返回点

决定条目粒度：同一模式在不同运行模式或对象层级可能有不同后果。将预防控制与检测控制分开，检测存在不代表能及时阻止后果。行动后应重新核证控制有效性，而不是人工把风险分改低。

## 可复查的教学推演

教学条目：功能是保持刀具参照，模式是参照相对树表滑移，局部影响是位置误差，上层影响可能是切入偏差；原因假设包括夹持松动、污染、复装误差。各原因暂未证实，发生度、检出度和严重度量表均不伪填。产物是待核条目及针对原因的调查。

除明确注明已执行的数学教学计算或既有教学程序外，上述是**设计与推演，不是本轮实测**。真实工程仍须补对象、工况、资源与专业确认。

## 与邻近方法的区别

R16根因分析通常追查已发生问题；FMEA前瞻性处理潜在失效。R51从控制情境和反馈分析交互，即使部件未失效也可能有风险；两者应互补。

## 方法引擎可用的输入、产物和拒绝条件

输入：层级、功能、工况、设计/过程版本、历史与控制证据。输出：模式—影响—原因—控制—行动—复核链。没有行业量表与证据时保留定性/未知，拒绝编RPN/AP和宣称风险已降。
