# WB12 国内外设计方法分类研究与出处去重：第一轮深度研究

日期：2026-10-27。性质：来源核对与平台研究分析；非领域专家审核、工程验证或新执行契约。本条是闻邦椿谱系专题，不计为已还原的独立算法。

## 核心机制：真正应深入的是什么

方法分类首先是知识治理问题。2019自述“70多种归七大类”是一项来源主张；2003论文图2按步骤、内容、方法、思想四种视角组织，并另有七种代表方向。数字相同不能推出同一七类对应表。

## 关键决策与返回点

判断两个条目是否同一实体，要比较定义、动作、输入输出、版本和出处，而不是只比较译名。一个专题可以包含多种算法，一个算法可从多个视角分类；分类图不应强制成为互斥树。

## 可复查的教学推演

教学去重：将“智能设计”先拆成AI辅助设计与产品智能控制两个含义，分别记录来源；将“制造性能”与“可视化设计”保留性能域/设计手段两类型。此次只设计实体与主张的分离示例，没有宣称完成70余方法的权威映射。

除明确注明已执行的数学教学计算或既有教学程序外，上述是**设计与推演，不是本轮实测**。真实工程仍须补对象、工况、资源与专业确认。

## 与邻近方法的区别

这是目录与出处治理专题，不是用来直接生成产品方案的独立方法。与R46专利去重有相似数据治理动作，但实体、用途与证据要求不同。

## 方法引擎可用的输入、产物和拒绝条件

输入：术语、来源位置、定义/版本、分类视角和关系。输出：可撤销的同义/包含/相关判定及冲突记录。原文未给完整表不得补齐；同名不强制合并，宣传数量不自动化为方法数量。

这部分是平台接口建议，不能据此声称已有运行实现、已核全原算法或可直接控制设备。
