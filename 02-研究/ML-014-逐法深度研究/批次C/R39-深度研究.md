# R39 稳健参数与公差设计：第一轮深度研究

日期：2026-10-27。性质：来源核对与平台研究分析；非领域专家审核、工程验证或新执行契约。

## 核心机制：真正应深入的是什么

稳健参数设计改变设计设置，使服役噪声对输出的影响较小；公差设计选择值得收紧的变动界限。二者解决不同问题。NIST内外阵列示例明确：实验室能操纵的温度/电压仍可对应服役噪声，且最大均值与最小变异未必出现在同一设置。

## 关键决策与返回点

先划分阶段与因子角色，决定目标是靠近目标值、减小变异还是兼顾成本。若均值更佳但波动更大，必须回到损失函数；仅比较平均偏差会漏掉越界风险。收紧公差前先判断敏感度、制造能力与测量不确定度。

## 可复查的教学推演

教学设计比较两种限深结构在替代材料厚度、曲率和装配复位误差下的表现，分别记录均值/散布/越界情况。不得把所有服役噪声固定在理想水平后宣布“稳健”。未指定可接受阈值，故本轮无合格判定。

除明确注明已执行的数学教学计算或既有教学程序外，上述是**设计与推演，不是本轮实测**。真实工程仍须补对象、工况、资源与专业确认。

## 与邻近方法的区别

R35优化名义结构不等于稳健；R38提供试验与统计工具，不自动决定哪些变量是服役噪声。GD&T是另一个规范与几何语言层，不能由本方法名替代。

## 方法引擎可用的输入、产物和拒绝条件

输入：目标、控制/噪声定义及范围、响应模型、工艺/量测能力、成本口径。输出：均值—变异权衡和关键公差补证。缺生产分布时禁止直接将公差界限换成标准差；相关误差不自动按独立RSS合成。
