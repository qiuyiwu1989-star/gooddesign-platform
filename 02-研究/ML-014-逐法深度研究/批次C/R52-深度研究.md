# R52 信息价值与验证优先级（VOI）：第一轮深度研究

日期：2026-10-27。性质：来源核对与平台研究分析；非领域专家审核、工程验证或新执行契约。

## 核心机制：真正应深入的是什么

VOI的核心不是测量未知多少，而是在允许根据新信息改变行动后，预计损失能减少多少。作者预印本第6—9页还区分决策损失与估计方差目标。模型、先验、观测机制和决策规则是计算的一部分，不能由通用评分替代。

## 关键决策与返回点

决定是否具备定量条件：损失表、概率和研究观测概率来源都可辩护才可算EVSI。还要区分完全信息上界与特定试验的学习收益，并扣成本/等待；安全与法规强制验证不由商业学习收益豁免。

## 可复查的教学推演

根Agent本轮已实际执行独立数学教学程序，结果见../教学演算/VOI-二行动二状态.json：显式虚构二行动二状态数据得到EVPI=15、EVSI=6、扣研究成本净2任意教学单位；另执行无信息、完美信息及非法概率检查。它证明该有限教学计算和边界处理，不证明真实割胶概率、成本、收益或路线优劣。

除明确注明已执行的数学教学计算或既有教学程序外，上述是**设计与推演，不是本轮实测**。真实工程仍须补对象、工况、资源与专业确认。

## 与邻近方法的区别

R37在当前知识下表达偏好与取舍；R38设计具体干预；R52桥接“哪项学习值得做”。高方差参数未必高决策价值，只有可能改变决策或改善所定估计目标才有对应价值。

## 方法引擎可用的输入、产物和拒绝条件

输入：行动、损失/效用、先验、观测似然、研究代价和强制约束。输出：分析目标、EVPI/EVSI或定性模式、假设和敏感性。非法概率、口径不一致或缺模型时拒绝精确数字；概率未知不得默认为均匀真实先验。
